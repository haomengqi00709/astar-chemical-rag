### 6. VENDOR REQUIREMENTS

**6.1. Vendor Confirmations**

The vendor shall confirm the following in their proposal:
*   Pump performance meets or exceeds the specified Rated Flow (54 m³/h) and Total Dynamic Head (24.14 m).
*   Confirmed NPSHr from pump curves is less than the specified NPSHa (25.6 m) with adequate margin.
*   All wetted materials of construction are fully compatible with 95% Monoethylene Glycol (MEG) at 65°C and 10 bar.
*   Proposed motor sizing (kW) and efficiency meet or exceed the calculated requirements, including the API 610 margin.
*   Compliance with API 610 (latest edition) for centrifugal pumps and API 682 for mechanical seals.

**6.2. Vendor Submittals**

The vendor shall submit the following documents for review and approval:
*   Certified pump performance curves (Head vs. Flow, Efficiency vs. Flow, NPSHr vs. Flow, BHP vs. Flow).
*   General arrangement drawings of the pump and driver assembly.
*   Detailed mechanical seal drawings and data sheets, including material breakdown.
*   Motor data sheets (including voltage, enclosure, service factor, efficiency, frame size).
*   Material certificates (MTRs) for all pressure-containing and wetted parts.
*   Installation, Operation, and Maintenance (IOM) manuals.
*   Barrier fluid system P&ID and data sheet for API Plan 53B.

**6.3. Testing Requirements**

The following tests shall be performed and witnessed by B Star Chemetics or their representative:
*   Hydrostatic test of pump casing (per API 610).
*   Performance test (per API 610, Type 2 or 3, as applicable).
*   Mechanical run test (per API 610).
*   NPSH test (if deemed necessary by B Star Chemetics based on final pump selection and NPSH margin).
