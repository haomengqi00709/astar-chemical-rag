# Transformer & Short-Circuit Calculation — Y-Office Tower — Detailed Design

## 1. Method
IEC 60909 short-circuit (supply + transformer impedance in series). Supply and transformer impedances in series; Isc = U20 / (√3 × Z_total).

## 2. Inputs

| Parameter | Value |
|---|---|
| System voltage U20 | 400 V |
| Utility SC power Psc | 500000 kVA |
| Transformer rating Sn | 1000 kVA |
| Short-circuit voltage Usc | 6 % |
| Copper loss Pcu | 9400 W |

## 3. Results

| Quantity | Value |
|---|---|
| Rated current In | 1443.38 A |
| Transformer impedance Z | 9.6 mΩ |
| Total impedance Z_total | 9.92 mΩ |
| **Short-circuit current Isc** | **23.28 kA** |

## 4. Calculation notes

- Transformer loading 87.74% (> 80%) — limited spare capacity.
