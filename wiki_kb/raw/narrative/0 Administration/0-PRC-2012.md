# 0-PRC-2012 — Procedure


[TABLE: 0-PRC-2012_table_1]


## Purpose
This procedure outlines the requirements for formal reporting both internally and, externally to the Client.
Reporting communicates the current state of the project and provides a record of project progress, cost and risks.

## Progress Report
The project progress report to be issued to the client will follow the format as outlined in template:
0-REP-2001: Monthly Progress
This format can be modified to suit the client’s reporting requirements where required by contract.  For small projects, the report can be simplified; however major headings shall be retained.
Each monthly report will be published as a new sheet of the same document number.
Timing for the report will as stated in:
0-PRC-2004: Project Coordination Procedure
The Progress Report requires the following input from others:
Safety Report – HSE Manager or Construction or Commissioning
Discipline Reports – See Section 3
Procurement Report and narrative – Procurement/Logistic Lead
Quality Management Report and narrative – Quality Manager
Progress Curves and narrative – Project Controls
Updated Schedule and narrative – Project Controls
Cost and Manhour Reports – Project Controls/Project Accounting
Accounts Receivables Report and narrative – Project Accounting
Change Order Log and PCN Log – Project Controls

## Discipline Reporting
Disciplines shall prepare a monthly “Discipline Report” covering the following items in bullet point form:
- Achievements this month
- Planned activities for next month
- Areas of Concern (items on hold, information required from others, manpower etc)
This shall be submitted by email to the Project Manager/Project Engineer/Project Controls prior to the preparation of the client report.

## PMR Report
The internal project report will be the PMR report prepared by Project Accounting with input from the Project Manager and Project Controls.
PMR report will be produced based on the same reporting period used by the project and will be issued at least 2 days prior to the project review meeting.
The following documents (most of which are prepared as part of the Progress Report) will be included with the internal distribution of the PMR.
Master Schedule – Level 1
Progress Curves
Change order and project change logs
Risk and Opportunity Register

## Project Review Meeting
The PMR report will be reviewed with Senior Management on a monthly basis at the project review meeting.
The review will include a verbal summary by the roject anager covering:
Project Status - current activities and issues.
Changes in costs, contingencies and margins.
Status of invoices and payments.
Areas of concern or opportunity.
