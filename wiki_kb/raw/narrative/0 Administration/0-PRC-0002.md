# 0-PRC-0002 — Procedure


[TABLE: 0-PRC-0002_table_1]


## Purpose
This procedure describes the requirements for the numbering of documents.
Where project documents are required to contain the Owner’s document numbers then they will be used together with the numbers described by this procedure.

## Number Format
98C12300-4-DTL-7801-5-R2
98C12300:	Project Number
4:	Major Work Division
DTL:	Document Type Code
7801:	Identification Number
5:	Sheet / Section Number
R2:	Revision Number

## Project Number
The eight-digit proposal or project number.
In the case of standard documents, “Standard” will be used.

## Major Work Division
A one-digit code designating the subject of the document as follows:
0:	Administration
1:	Process Technology
2:	Civil & Site Preparation
3:	Structural & Buildings
4:	Equipment
5:	Piping & Layout
6:	Insulation
7:	Coatings
8:	Instrumentation & Control
9:	Electrical

A three-digit code designating the type of document as listed below:
CAL:	Calculation
DAT:	Data (View of data files such as Schedules, Expediting, Document Status)
DST:	Data Sheet
DTL:	Detail Drawing (Equipment, Instrument Installation, etc.)
GAD:	General Arrangement Drawing (Layouts)
HAZ:	HazOp Record
ISO:	Piping Isometric
LOP:	Loop Diagram
LST:	List
MAN:	Manual
NCR:	Non-Conformance Report
OTL:	Outline Drawing
PDS:	Process Data Sheet (Equipment)

## Identification Number
In the case where a document is associated with a single equipment item the identification number will be the 4-digit standard equipment number (4-PRC-0001: Plant Equipment Identification).
In the case where a document is associated with an equipment package the identification number will be the 4-digit standard equipment number of the primary equipment item.
In the case where a document is associated with a single line (piping) the identification number will be the standard 6-digit line identifier (5-PRC-0001: Plant Pipe Numbering).
In the case where a document is associated with a single instrument item the identification number will be the multi-digit standard instrument number (8-PRC-0001: Plant Instrument Numbering).
In the case where a document is associated with an instrument loop the identification number will be the standard 6-digit loop identifier (8-PRC-0001: Plant Instrument Numbering).
In the case of documents within major work division 0: Administration the identification number will be a 4-digit sequential number where the first one or two digits provide further work breakdown:
0XXX:	Documentation
1XXX:	Sales and Proposals
2XXX:	Project Administration
3XXX:	Planning
4XXX:	Cost Control
5XXX:	Procurement
6XXX:	Construction
7XXX:	Quality Assurance
8XXX:	HSE (Health, Safety & Environment)
9XXX:	Corporate
90XX	General
91XX:	Human Resources
92XX:	Finance
93XX:	Information Technology
In the case where a document is associated with a particular process area the identification number will be a 4-digit number with the first two digits the process area identifier, and the last two digits a sequential series beginning with 01. E.g. 1-PID-6502 would be the second piping and instrument diagram for the Gas Cleaning area of an acid plant.
In the case where a standard document is a generic template intended for the creation of a number of project documents by the insertion of applicable design data, the identification number will be “XXXX”. The associated equipment, line, or instrument number will replace this when it is used to create the project document.
For documents not assigned an identification number by this or any other procedure, the identification number will be a 4-digit sequential number beginning with 0001. The first digit will always be 0. It is the intention that the identification number for a document used in a project will be the same identification number as the standard document from which it is derived, or which deals with the same subject matter.

## Sheet / Section Number
Used where necessary to break a document into a number of sheets or sections.
For example, a number of drawings may be created showing details for the fabrication of a vessel. This procedure only allows for a single document number for the drawings. Each drawing is then considered to be a separate sheet of that single document, and will be assigned a sheet number accordingly.
If only a single sheet / section exists for a document, then the number is omitted.

## Revision Number
Drafts of Standards will be numbered R0 (0-PRC-0001: Approval and Use of Standards), and subsequent revisions will be numbered sequentially (R1, R2….).
Revisions of project documentation will be designated as letters (RA, RB….) when status is as follows (0-PRC-0006: Control of Project Documents):
Issued for Owner Review
Issued for Quotation
Approved for Design [by Aker Kvaerner Chemetics or Subcontractors]
Revisions of project documentation will be designated as numbers (R1, R2….) when status is as follows (0-PRC-0006: Control of Project Documents):
Approved for Fabrication
Approved for Construction
Approved Instruction
As Built

## Exclusions
Correspondence, minutes of meetings, memoranda, project reports etc. are not covered by this procedure. They will be numbered in accordance with 0-PRC-2002: Project Instructions and/or 0-PRC-2004: Project Coordination.
Purchase Orders are not covered by this procedure. They will be numbered in accordance with 0-PRC-5001: Form of Purchase Order.
Owner-issued documents are not covered by this procedure. They will retain the Owner’s document number (and revision number).
Commentary
The objectives of the numbering system are as follows:
To provide a consistent system for all types of document
To allow for filing by subject, not by originating department
To provide an intuitive sense to allow a user to easily find a desired document
To have documents (particularly lists, specifications and standards) of the same subject with the same number for all projects
To maintain cross-referencing while meeting the requirement for validation of standards for individual projects
To Section 1: The term “document” is a generic one, and refers to drawings, specifications, procedures, lists, data sheets, etc.
To Section 4: Subject matter falling within major work division 7: Coatings are paint, galvanising. Linings fall within major work divisions 4: Equipment or 5: Layout and Piping as appropriate, and concrete coatings fall within 2: Civil & Site Preparation.
To Section 5: Note that document type PRP (Equipment Proprietary Detail Drawing) will generally only be used where we wish to prevent the Owner from obtaining the design details of equipment e.g. sodium chlorate electrolyser components, etc.
To Section 6: Technology-specific versions of standard documents will be given the same identification number. Title wording will differentiate them.
