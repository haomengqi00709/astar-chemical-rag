# 0-PRC-0003 — Procedure


[TABLE: 0-PRC-0003_table_1]


## Purpose
This procedure describes the structure to be used for the storage of project documentation, either as paper files or for computer directory structures (P Drive).

## Major Work Division
The first level of division is arranged by major work subject as follows:
0 Administration
1 Process Technology
2 Civil and Site Preparation
3 Structural and Buildings
4 Equipment
5 Piping and Layout
6 Insulation
7 Coatings
8 Instrumentation and Control
9 Electrical

## Minor Work Division
Only the 0 Administration folder is provided with a further series of subject divisions as follows:
0 Documentation
1 Proposals
2 Project Administration
3 Planning
4 Cost Control
5 Procurement
6 Construction
7 Quality Assurance
8 HSE (Health, Safety & Environment)
9 Corporate

## File Categories
Within each major and minor work division described above, further categorisation is made for each relevant document type (0-PRC-0002: Document Numbering). Other file categories will be established where necessary.

## File Names
As a minimum, file names for documents will be the entire number sequence of the document (0-PRC-0002: Document Numbering), omitting the project number and inserting the sheet / section number (if used) e.g. 4-DTL-1035-1-R2.
File names may have the document title appended to aid in retrieval as directed by the project job instructions.
File names for Vendor-issued documents will be identical to the assigned document number (0-PRC-0007: Control of Vendor Documentation).
File names for Owner-issued documents will be identical to the Owner’s file number if applicable, or will be identical to the Owner’s document number (including the Owner’s revision number), as directed by the project job instructions.
File names for documents not covered by 0-PRC-0002: Document Numbering will be assigned in accordance with project job instructions.

## Standard Project Directory Structure
When creating a new project or proposal directory, folders and sub-folders will be set up in accordance with the attached listing.
Commentary
To Section 1: This procedure describes the file structure for the storage of project documents and data files. This includes published documents, documents in native format, and work in progress.
It is recognised that other subdirectories are needed for administrative purposes as shown in the attached list.
To Section 5: Note that the file structure mirrors the document number itself. The printing of file paths on documents is redundant.
File names for DOS-based programs that do not allow file names longer than 8 digits must be abbreviated as necessary to fit. Note that the type and subject of the document will normally allow it to be located within the directory structure.
To Section 6: Top-level directory names should be set up with no spaces.
