# 0-PRC-4001 — Procedure


[TABLE: 0-PRC-4001_table_1]


## Purpose
This procedure establishes Cost Codes to be used for all work.

## Cost Code Format
98C12300-MAT-4-7801
98C12300:	Project Number
MAT:	Cost Type
4:	Major Work Division
7801:	Detail Code

## Project Number Format
98C12300
98:	Year of Initiation
C:	Technology Identifier
123:	Sequential Number
00:	Breakdown Code

### Year of Initiation
In the case of proposals and projects, the year of initiation is assigned when the first proposal is initiated.
In the case of internally funded projects, project numbers are re-established annually, so the year of initiation is always the current year.

### Technology Identifier
The technology identifier is as follows:
C:	Chemicals
H:	Sulphuric Acid
V:	Internally Funded Projects

### Sequential Number
In the case of proposals and projects, the Sales Group assign this number when initiating the first proposal. In any calendar year, a unique series of numbers beginning with 001 are assigned across all technologies.
In the case of internally funded projects, this number is assigned in range  for each calendar year as the project is approved

### Breakdown Code
In the case of proposals, the Sales Group assign this code as either “PC” for prospect cultivation, or as “BP” for bids and proposals.
In the case of projects, 00 will generally be the only code that is used during execution, with additional codes used for spare parts supply, remedial work, etc.
In the case of internally funded projects, 00 will be the only code used.

## Cost Type
A three-letter code designating the type of the cost as follows:
ENG:	Engineering
MAT:	Materials
CST:	Construction
FLD:	Field Services
RES:	Reserves

## Major Work Division
A one-digit code designating the work grouping as follows:
0:	Administration
1:	Process Technology
2:	Civil & Site Preparation
3:	Structural & Buildings
4:	Equipment
5:	Piping & Layout
6:	Insulation
7:	Coatings
8:	Instrumentation & Control
9:	Electrical

## Detail Code
A four-digit code designating the specific work item. These codes will be unique only when used in conjunction with the Work Type code and the Major Work Division code. The codes are listed on the following documents:
ENG:	0-LST-4001: Engineering Cost Codes
MAT:	0-LST-4002: Materials Cost Codes
CST:	0-LST-4003: Construction Cost Codes
FLD:	0-LST-4004: Field Services Cost Codes
RES:	0-LST-4005: Reserves Cost Codes
