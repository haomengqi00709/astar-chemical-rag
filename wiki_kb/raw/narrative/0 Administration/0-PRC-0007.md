# 0-PRC-0007 — Procedure


[TABLE: 0-PRC-0007_table_1]


## Purpose
This procedure describes the steps by which Vendor-issued documents are received and disseminated to the Project Team, and where required, are reviewed and returned to the Vendor with appropriate instructions.

## Vendor Requirements
Vendors will be issued the following documents to set out the requirements for documentation relating to the goods that they are supplying:
0-VDR-0XXX: [Template] Vendor Document Requirements
0-SPC-0001: Vendor Document Supply

## Vendor Document Requirements
Vendor Document Requirements will be prepared for each equipment type listed in the Purchase Order or for each type or class of bulk materials listed in the Purchase Order.

### Content
The Vendor Document Requirements will contain the following:
List of documents or document packages to be supplied
Required delivery dates of the documents (packages)
Identification of hold documents (packages)
Documents to be bundled as manuals

### Responsibility
The Vendor Document Requirements are prepared by the requisitioner of the goods, checked by Quality Assurance, and approved by the responsible Discipline Approver (0-PRC-2001: Assignment of Project Responsibilities).

### Numbering
The Vendor Document Requirements will be numbered (0-PRC-0002: Document Numbering) with the identification number identical to that of the Purchase Order (0-PRC-5001: Form of Purchase Order).
In the case of multiple Vendor Document Requirements for the same Purchase Order, they will be numbered as multiple sheets of the same document. The sheet title will describe the type of equipment or bulk material to which it applies.

### Revisions
Vendor documents will be expedited based on the contents of the Vendor Document Requirements. It is important therefore to revise them to incorporate any changes agreed with the Vendor during bid evaluation.
This revision will include converting document delivery dates from “Weeks ARO (After Receipt of Order)” to fixed calendar dates.

### Expediting
A Vendor Document Expediting Report (0-PRC-0006: Control of Project Documentation) listing the Vendor documents overdue or scheduled to be received in the upcoming period will be reviewed weekly by the Project Engineer. The Project Engineer will consult with the responsible Discipline Leads to verify that the documents have not been received, and will direct Procurement to expedite their delivery.

## Actions on Receipt
Vendor documents will be directed to Document Control who will carry out the following actions:

### Publishing
If Vendor Documents are not already in Adobe Portable Document Format, convert them in the case of native digital format documents, or scan them in the case of printed paper documents.

### Numbering
Affix Aker Kvaerner Chemetics document numbers to the Adobe Portable Document Format versions of the Vendor documents. Number format is as follows:
98C12300-4-VEN-7801-5-R2
98C12300:	Project Number (0-PRC-0002: Document Numbering)
4:	Major Work Division (0-PRC-0002: Document Numbering)
VEN:	Document Type Code for Vendor Documents
7801:	Identification Number
5:	Document Number
R2:	Revision Number
For tagged items the identification number will be identical to the Aker Kvaerner Chemetics standard tag number. Where a document is common to a number of tagged items then it will be assigned the numerically smallest of the tag numbers. For bulk materials the identification number will be identical to that of the Purchase Order.
The document number will be a sequential number assigned by Document Control.
The revision number will be applied incrementally as different versions are received, beginning at R1.

### Filing and Printing
File the Adobe Portable Document Format versions of the Vendor documents in the project electronic file (0-PRC-0003: File Structure).

### Logging and Transmittal
Log the Vendor documents into the Document Control Database, and create an Incoming Transmittal (0-PRC-0006: Control of Project Documentation).  Documents will be given a document status of “Issued for Review”.
Where a document is common to a number of items on the Purchase Order, it will be logged as received for all items, with a reference to the actual document number assigned.

### Printing and Distribution
Print two paper copies of all documents received and deliver them to the Project Engineer with two copies each of the Incoming Transmittal and the Vendor Document Status Report.

## Review of “Hold” Documents
Vendor may not commence any work shown on a document marked as “hold” on the Vendor Document Requirements until the document has been reviewed by Aker Kvaerner Chemetics for compliance with the requirements of the Purchase Order and approval given to proceed.
The Project Engineer will assign primary responsibility for the review to the requisitioning Discipline Lead, assigning secondary responsibility to other Discipline Leads as required. These assignments together with sequence of reviews will be hand written on the Internal Transmittal.

### Discipline Review
The requisitioning Discipline Lead will review the Vendor Document Status Report, ensuring that the correct VDR Package has been marked as received and that all documentation due has been received. If not, he will advise Document Control of the correct status of the VDR Packages, and advise the Project Engineer of the need to expedite the missing documentation.
The requisitioning Discipline Lead will review the documents first, marking comments / requested changes in red pencil, and place them in the central project vendor document review file. Other Discipline Leads will review and add their comments on the same documents. All persons making comments will initial and date them. The process will be monitored by the requisitioning Discipline Lead to ensure deadlines are met.
Guidelines for the scopes of reviews for different classes of equipment are appended to this procedure.
The review process will not be used to change the scope of Vendor’s supply. This may only be done by issuing a revision to the Purchase Order.

### Consolidation and Resolution
The requisitioning Discipline Lead will review all comments / requested changes and collate and edit them, and will assign the appropriate instruction to the Vendor as follows:
No Revisions Required; Proceed with Work Shown
Revise as Marked and Reissue; Proceed with Work Shown
Revise as Marked and Reissue; Do Not Proceed with Work Shown
The Project Engineer will resolve any conflict between the comments / requested changes of different disciplines, and where necessary direct that a comment / requested change be omitted. In such a case the originating Discipline Lead may request an appropriate change to the Purchase Order by means of a revision of the relevant documents.
A final mark-up will be prepared by one of the following:
electronic mark-up of the Adobe Portable Document Format Vendor document file
hand mark-up a paper copy of the Vendor document followed by scanning to create an electronic file

### Checking and Approval
The requisitioning Discipline Approver will review the marked-up document and affix his digital signature as having approved the mark-ups and the direction to the Vendor.
The requisitioning Discipline Lead will then advise Document Control that the Vendor document is ready to be returned to the Vendor.

### Logging and Transmittal
The Vendor document will be logged into the Document Control Database, an Outgoing Transmittal created and copies issued (0-PRC-0006: Control of Project Documentation).  The document status and reason for issue will be the instruction to vendor assigned in section 5.2.

### Return to Vendor
Document Control will return either a digital copy of the marked-up Adobe Portable Document Format Vendor document or a printed paper copy of the same (0-PRC-0006: Control of Project Documentation) together with a copy of the Outgoing Transmittal.

### Expediting
A Vendor Document Return Report (0-PRC-0006: Control of Project Documentation) listing the Vendor documents overdue or scheduled to be received in the upcoming period will be reviewed weekly by the Project Engineer. The Project Engineer will expedite the review process with the Discipline Lead assigned primary responsibility, and with other Discipline Leads as necessary.

### Resubmission
Should the Vendor be instructed to revise the document and re-issue it, the same procedures for review as set out in this Section 5 will be repeated.

## Review of “Non-Hold” Documents
“Non-hold” Vendor documents will be reviewed as described in Section 5. Such documents will only be returned to Vendor if they are found not to be in compliance with the Purchase Order, in which case the instruction given will be:
Revise as Marked and Reissue; Proceed with Work Shown
