# 0-PRC-5001 — Procedure


[TABLE: 0-PRC-5001_table_1]


## Purpose
This procedure describes the format to be used for a Request for Quotation or Purchase Order and assigns responsibility for providing the information and documentation required.

## Content
The information required will be as shown on the attached sample. The responsibility for providing the information is as follows:
Line Items 1.x (Scope of Supply)	Requisitioner
Line Items 2.x (Documentation)	Requisitioner
Line Items 3.x (Delivery)	Logistics
Text Section 1: Scope of Supply	Requisitioner
Text Section 2: Documentation	Requisitioner
Text Section 3: Delivery	Logistics
Text Section 4: Quality Assurance	Quality Assurance
Text Section 5: Commercial	Project Buyer
Text Section 6: References	Project Buyer
Text Section 7: Contact	Project Buyer

## Line Items
Will contain descriptions of all deliverables with tag numbers, cost codes, and pricing.

## Text Section 1: Scope of Supply
Will list all documents that define the technical requirements of the Goods and Services.

## Text Section 2: Documentation
Will list all documents that define the requirements for documentation to be supplied by Vendor.

## Text Section 3: Delivery
Will list all documents that define the requirements for packaging. Will state the Delivery Date(s).

## Text Section 4: Quality Assurance
Will list all documents that define the requirements for Vendor’s quality assurance, and the requirements for review, inspection and verification.

## Text Section 5: Commercial
Will list all documents that define the commercial conditions. Will also contain Order-Specific Conditions (0-PRC-5004: Commercial Terms for Purchase).

## Text Section 6: References
Will list all pertinent Vendor documents, such as the original quotation, any clarifications or modifications, etc.

## Text Section 7: Contacts
Will state the name and details of the Aker Kvaerner Chemetics contact persons (the Project Buyer, the Lead Engineer and the Inspector). Will state the name and details of the Vendor contact persons and any Vendor Key Personnel.

## Request for Quotation
Other than the title, a Request for Quotation will look identical to a Purchase Order. To ensure no errors are made, a Request for Quotation will have the text “This Is Not An Order” watermarked across the body.
Text Section 3 of a Request for Quotation will state “TBA” for the delivery date.
Text Section 6 of a Request for Quotation will be used to refer the Vendor to 0-SPC-5006: Instructions to Bidders.

## Numbering
98C12300-4021-R2
98C12300:	Project Number (0-PRC-0002: Document Numbering)
4021:	Identification Number where:
4 is the Major Work Division (0-PRC-0002: Document Numbering) and
021 is a sequential addendum
R2:	Revision Number
A Request for Quotation and its subsequent Purchase Order will have the same document number as allocated in the Procurement Plan (0-PRC-3001: Project Planning), and with the exception of the revision numbers as for example:
the Request for Quotation will have letter revisions (RA, RB….)
the Purchase Order will have number revisions (R1, R2….).
