# 0-SPC-2204 — Specification


[TABLE: 0-SPC-2204_table_1]


## Purpose
This specification describes the means by which Subcontractor and Aker Kvaerner Chemetics will communicate and coordinate with each other during the execution of an Engineering Subcontract.

## Communication
Communication will be by e-mail in accordance with the requirements of 0-SPC-01: Standard Conditions for Engineering Subcontracts and 0-SPC-02: Special Conditions for Engineering Subcontracts.
Communication from Aker Kvaerner Chemetics to Subcontractor will be sequentially numbered using the format -[SUB]-XXX where XXX is a sequential number.
Communication from Subcontractor to Aker Kvaerner Chemetics will be sequentially numbered using the format [SUB]--XXX where XXX is a sequential number.
The subject line of e-mails will contain the communication number followed by a brief description of the content.

## Meetings
Progress review meetings will be held [biweekly]. Other meetings will be held as requested by either party.
Meetings will be held by teleconference whenever possible, or at either parties office as directed by Aker Kvaerner Chemetics. Minutes will be kept, transcribed, and issued by Aker Kvaerner Chemetics.
Attendance at meetings by Subcontractor personnel is considered to be part of the services of the Subcontract.

## Document Transfer
Documents will be transferred between Aker Kvaerner Chemetics and Subcontractor through a File Transfer Site. The File Transfer Site contains two sub-directories, incoming and outgoing, defined from Aker Kvaerner Chemetics’ point of view. That is, documents transmitted by Aker Kvaerner Chemetics to Subcontractor will be placed in the outgoing directory, and documents transmitted by Subcontractor to Aker Kvaerner Chemetics will be placed in the incoming directory.
For security reasons, it is not possible to see files in either directory, they can only be retrieved by a party in possession of the filename. Additionally, files placed in either directory will be deleted after 24 hours, so file transfer must be scheduled to allow access by the receiving party during normal working hours.

### Uploading Files to the File Transfer Site
Files are uploaded into the File Transfer Site using an FTP client program. Windows NT comes with a client program called “ftp” which is a command line program that is fit for the purpose. If a graphical user interface is preferred, one of a number of free or shareware FTP clients available on the Internet may be used such as WS_FTP from www.ipswitch.com.
Files to be transferred will be placed into a single ZIP archive using WINZIP.
Log into the File Transfer Site using the FTP client program with the following login information:
FTP address: ftp.kvaerner.com
Username: anonymous
Password: <your e-mail address>	(Example: j.smith@anycompany.com )
Once logged in, transfer the ZIP archive into the incoming directory using the “binary” transfer mode of the transfer program.
Send an e-mail message advising that a file has been placed in the File Transfer Site, with the transmittal attached as described in Section 5, to Aker Kvaerner Chemetics Document Control at:
Aker Kvaerner Chemetics.doccontrol@akerkvaerner.com
In the e-mail message include a link to the file in the form:
ftp://ftp.kvaerner.com/incoming/uploaded_file_name.zip

### Downloading Files from the File Transfer Site
Upon receipt of an e-mail message from Aker Kvaerner Chemetics advising that a file has been placed in the File Transfer Site, click on the link contained in the e-mail message to initiate downloading using Internet Explorer. Alternatively, the link may be cut from the e-mail message and pasted into the address box of any Internet Browser.
If the browser issues an error message, this means that either the wrong link to the file has been used, or the file has been deleted from the File Transfer Site due to excessive elapsed time. In either case contact Aker Kvaerner Chemetics Document Control.

## Document Transmittals
Documents delivered to Aker Kvaerner Chemetics will be described by Subcontractor in a Transmittal in the form of a Microsoft Excel file named “Transmittal” containing the following information in tabular form:
Subcontract Number
Document File Number
Document Title
Document Number
Document Revision Number
Document Status
Documents delivered to Subcontractor will be described by Aker Kvaerner Chemetics in a Transmittal in the form of an Adobe Portable Document Format file.
