# 0-PRC-0006 — Procedure


[TABLE: 0-PRC-0006_table_1]


## Purpose
This procedure describes the means to record and report on the status of published project documents, and to record and report on the distribution of project documents to Owners, Vendors, Subcontractors, and Aker Kvaerner Chemetics field supervisors.

## Document Control Database
The Document Control Database will be used for all recording and reporting as described in this procedure. The personnel of the Document Control Department will make all entries into the Document Control Database.

## Document Status

### In Preparation
Immediately upon commencing preparation of a new document the person doing the work will insert their name in the document revision log as the preparer, will denote the revision number as either “A” or “1” as appropriate, will denote the status as Draft in Progress, and will assign the document file name (0-PRC-0003: File Structure).

### In Revision
Immediately upon commencing revision of an existing document, the person doing the work will insert their name in the document revision log as the preparer, will increment the revision number, will denote the status as Revision in Progress, and will change the file name to include the new revision number (0-PRC-0003: File Structure).

### At Publication
When published, a document will have its status marked in the revision log. The status describes the permitted use of the information provided in the document as follows:
Issued for Owner Review: Published specifically for this purpose.
Issued for Owner Approval: Published specifically for this purpose.
Issued for Quotation: Published specifically for this purpose.
Approved for Design: The information provided may be used for further design.
Approved for Fabrication: The information provided may be used to manufacture the items shown or described.
Approved for Construction: The information provided may be used to construct the items shown or described.
Approved Instruction. The information provided may be used by the Owner for the operation or maintenance of the items shown or described.
As Built. The information provided is a record of the condition of the goods as delivered.
Limitations on the use of the document may be made by adding a qualifier to the status. For example: “Approved for Design (Layout only)”

## Published Documents

### Logging
On publishing, documents will be logged into the Document Control Database recording the following information:
Document Title
Document Number
Document Revision Number
Date Published
Document Status

### Notification
A notification containing the identical information as listed in Section 4.1 will be issued to the Project Engineer and all Discipline Leads.

## Issue of Documents

### Initiation
Only published documents will be issued to parties outside of Aker Kvaerner Chemetics. The responsible Discipline Lead(s) will place copies of the published documents to be issued in the project electronic file P:\00\0-Administration\0-Documentation\TRN to be accessed by Document Control.

### Logging
Issued documents will be logged into the Document Control Database recording the following information:
Date Issued
Reference (Purchase Order, Subcontract or Owner’s Contract) Number
Receiving Parties Name
Transmittal Number
Document Title
Document Number
Document Revision Number
Date Published
Document Status
Document Return Date where applicable

### Outgoing Transmittal
An Outgoing Transmittal containing the identical information as listed in Section 5.2 will be issued with the documents, copied to the Project Engineer and all Discipline Leads.
Outgoing Transmittals will be titled and numbered as follows:
Document Transmittal from Aker Kvaerner Chemetics to [Parties Name] -XXXX
XXXX will be a sequential series beginning with 0001. There will be a unique series for each party receiving documents from Aker Kvaerner Chemetics. Outgoing Transmittals will be published (0-PRC-0005: Publishing of Project Documents) and filed (0-PRC-0003: File Structure).

### Document Transmission
The documents will be transmitted to the receiving party(s) by one of the following means as available:
As electronic files placed in an Internet FTP Site
As electronic files attached to an e-mail,
As paper copies by courier
No file copy of the transmitted documents will be kept.

## Vendor Document Requirements
On issue of a Purchase Order, the requirements for Vendor documentation as set out in the Vendor Document Requirements will be entered into the Document Control Database, recording the following information:
Aker Kvaerner Chemetics Document (Package) Number
Document (Package) Description
Date Required
Review Requirements (“Hold” Documents)

## Received Documents

### Logging
On receipt of documents from Owner, Vendors or Subcontractors, they will be logged into the Document Control Database recording the following information:
Date Received
Reference (Purchase Order, Subcontract or Owner’s Contract) Number
Issuer’s Name
Issuer’s Document Title
Issuer’s Document Number
Issuer’s Document Revision Number
Issuer’s Document Status
Aker Kvaerner Chemetics Document Number
Document Return Date where applicable

### Incoming Transmittal
An Incoming Transmittal containing the identical information as listed in Section 7.1 will be sent to the Issuer, copied to the Project Engineer and all Discipline Leads.
Incoming Transmittals will be titled and numbered as follows:
Document Transmittal from [Parties Name] to Aker Kvaerner Chemetics -XXXX
XXXX will be a sequential series beginning with 0001. There will be a unique series for each party issuing documents to Aker Kvaerner Chemetics. Incoming Transmittals will be published (0-PRC-0005: Publishing of Project Documents) and filed (0-PRC-0003: File Structure).

### Publishing and Filing
If the received documents are not already in Adobe Portable Document Format, Document Control will convert them in the case of native digital format documents, or scan them in the case of printed paper documents.
Document Control will place the documents in the correct folder in the project electronic file (0-PRC-0003: File Structure).
Documents received in printed paper format will be filed by Document Control. No other file copy of documents received electronically will be kept.

## Document Status Reports
Periodic reports will be produced from the Document Control Database and forwarded to the Project Engineer showing the status of project documentation as follows:
Vendor Document Expediting: Listing the Vendor documents overdue or scheduled to be received in the upcoming period.
Vendor Document Return: Listing the Vendor hold documents overdue or scheduled to be returned in the upcoming period.
Published Document Status: Listing all published documents with full revision history.
Document Issue Summary: Listing all documents issued to any single party (Vendor, Subcontractor, Owner, field supervisors, etc.)
Exception Reports: Listing all parties who have received early revisions of documents, but have not been issued the latest versions.
