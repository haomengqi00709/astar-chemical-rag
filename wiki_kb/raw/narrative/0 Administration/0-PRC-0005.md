# 0-PRC-0005 — Procedure


[TABLE: 0-PRC-0005_table_1]


## Purpose
This procedure describes the means by which project documents are published prior to checking and approval (0-PRC-7004: Checking and Approval of Design) or prior to issue external to Aker Kvaerner Chemetics (0-PRC-0006: Control of Project Documentation).

## Definition
Publishing refers to the process of creating an unalterable record of a document that can have signatures attached by authorised personnel to certify status.

## Methods
Two methods of publishing documents are permitted:

### Digital Publishing
The document is published into Adobe Portable Document Format and signatures affixed digitally. Detailed procedures are appended to this procedure.
The published and digitally signed document will be stored in the project electronic file (0-PRC-0003: File Structure) in the same folder as the native format version.

### Paper Publishing
The document is printed on paper and signatures affixed using blue ink. The signed document will be scanned into Adobe Portable Document Format, and stored in the project electronic file in the same folder as the native format version.
The original signed document will be stored in the project paper file (0-PRC-0003: File Structure).

## Verification of Signatures
Personnel in receipt of digitally signed documents in Adobe Portable Document Format can view the digital signatures using Adobe Approver or Adobe Acrobat. In order to verify the authenticity of the signatures they must have received the digital signature key belonging to the signer.
All Aker Kvaerner Chemetics personnel responsible for checking or approving project documents will store their Q:\Signatures\Aker Kvaerner ChemeticsAker Kvaerner Chemetics

## Logging
On completion of publication and any required checking and approval, the responsible Discipline Lead (0-PRC-2001: Assignment of Project Responsibilities) will advise Document Control to update the project Document Control Database (0-PRC-0006: Control of Project Documentation).

Creating and Storing a Digital Signature
Before you can sign documents with Acrobat Self-Sign Security, you must set up a profile, a password-protected file containing your name, your password, and other basic attributes. This profile file stores your private key (encrypted), your public key (wrapped in a certificate), your list of trusted certificates (certificates of other users), and a time-out value representing when a password is required for signing.
Creating a Profile:
In Adobe Acrobat or Adobe Approver, select Tools > Self-Sign Security > Log In.
Click New User Profile
In the Create New User dialog box, enter your name for your user profile. This must be your first name followed by a space and your last name with the first letter of each name part capitalized. When you add a signature to a document, this user profile name is the name seen in the Signatures palette. For Example: John Smith
Note: Names must be unique within an organization. If two or more people have the same first and last name, they shall use their middle name in their profile.
Enter a password containing at least six characters. You need to enter the same password in both the User Password and Confirm Password text boxes.
Important: Your signature is only as secure as your password. Choose a password that consists of two short unrelated words, and use the two words together with a special character in between. If you speak a foreign language, pick one word in English and the second word in the other language. And lastly, make it memorable.  Examples of passwords that follow the above guidelines: Sky$is-red, rain+fell, $cut%hurt$
Click OK.
Select the location where your profile is to be stored: Q:\Signatures\Aker Kvaerner Chemetics. Change to this directory in the dialog shown below. The filename containing your profile will default to the name you used for your profile, but without any spaces. Leave as.
Press the “Save” button to save your profile.
Do one of the followinI:
• 	Click OK to end the profile creation process.
•	Click User Settings to change the profile’s password, and password options, or to set the appearance of your signature.

Applying a Digital Signature to a Document
You will have your document open in Adobe Acrobat or Adobe Approver.
If you are not already logged in to a profile, choose Tools > Self-Sign Security > Log In and select your profile from the pop-up menu, or use the browser to find your profile in Q:\Signatures\Aker Kvaerner Chemetics.
Select the signature tool from the toolbar and use the mouse to drag a box within which your signature will be placed.
A window with some information may display at this point. Acknowledge the window by pressing the “Sign” button, or the “OK” button.
In the Sign Document dialog box, enter your password in the Confirm Password text box.
Click Show Options and choose the signature appearance to be the “Kvaerner Standard Signature”. Do not select or place a Reason or a Location. Do insert your e-mail address. These settings will be saved and do not have to be repeated each time that you sign a document.
Click the “Save” button and the now signed document will be saved in the same file location with the same name.
A document may be signed any number of times. The signatures will appear in the Signatures palette in document in the order that the document was signed.
