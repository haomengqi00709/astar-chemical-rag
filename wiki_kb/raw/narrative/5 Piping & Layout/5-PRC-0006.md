# 5-PRC-0006 — Procedure


[TABLE: 5-PRC-0006_table_1]


## Purpose
This procedure describes the requirements for standard identification numbers for piping specialty item.
The standard identification numbers will be used for the development of all related numbering systems such as drawing numbers, etc.
The standard identification numbers will be used on all projects unless specific client requirements dictate otherwise.

## Number Format for Type A Piping Specialty Item
R-780302
R:	Device Type
7803:	Associated Equipment Number
02:	Serial Number

## Device Type A
Code designating the type A piping specialty item as listed below:
RO		: Restriction orifice
PSI		: Piping specialty item
SP		: Spectacle

## Associated Equipment Number for Type A Piping Specialty Item

## Serial Number
A unique two-digit number is assigned to each piping specialty item belongs to same equipment.

## Number Format for Type B Piping Specialty Item
X-EJ-9xxx
X:	Nominal Diameter in inches or millimeters
EJ:	Device Type
9:	Code designating type B piping specialty item
xxx:	Three digit serial number

## Device Type B
Code designating the type B piping specialty item as listed below:
EJ			: Expansion joint
FH		: Flexible hose
HC		: Hose connection
HS		: Hose station
SG		: Sight glass
SN		: Spray nozzle
SP		: Spacer
ST			: Strainer or filter
TS			: Temporary strainer
SP		: Spectacle flange
AV		: Air vent
GD		: Grounding device
BF			: Back flow preventer
T		: Steam Trap

## Serial Number
A unique three-digit number is assigned to each piping specialty item.
