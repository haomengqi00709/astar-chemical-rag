# 4-PRC-0008 — Procedure


[TABLE: 4-PRC-0008_table_1]


## Purpose
This procedure gives general guidelines for thermal design of acid plant radial flow gas/gas heat exchangers utilizing Aker Kvaerner Chemetics’ in-house TGAS/2 program.  Basic mechanical data for gas/gas exchangers is also presented.

## Background
TGAS/2 is a proprietary piece of software developed by Aker Kvaerner Chemetics.  It is coded in Visual Basic, utilizing Excel for input and output.  TGAS/2 is based on the original TGAS, but with new heat transfer and pressure drop calculations derived from HTRI methods.   Acoustic resonance calculations based on the work of Dr. H. Goyder are also included.  Additionally, the program has enhanced functionality for data input/output as well as automatic drawing generation.

## Confidentiality
The contents of this procedure and the TGAS/2 program itself, are strictly confidential and as such are not to be duplicated or divulged to persons outside the employ of Aker Kvaerner Chemetics.

## Data Input
Data can be input either directly (in either Imperial or SI units) or imported from the Aspen process simulator.

### Direct Input
For input in Imperial units, simply fill in the blue cells in the “Input Sheet IMP” worksheet.  For input in SI units, fill in the blue cells in the “Input Sheet SI” worksheet and press the “Convert to Imperial units” button.  This converts the input to Imperial units and populates the appropriate cells in the “Input Sheet IMP” worksheet.

### Import from Aspen
The following sequence is necessary to import data from the Aspen process simulator.
Select the streams to export utilizing Aspen’s export to Excel feature.
Paste the Aspen output to the “Aspen Input” worksheet.
Fill in the atmospheric pressure
Specify the shell side and tube side streams
Press the “Sort Aspen Data” button.
The program sorts the Aspen data into a form readable by TGAS/2, converts to Imperial units and populates the appropriate cells in the “Input Sheet IMP” worksheet.

## Program Execution
The program operates in either design or rating mode.  Design mode allows the user to make interactive changes to exchanger geometry in order to optimize the exchanger design.  In rating mode, different process conditions can be evaluated for a given geometry.  Regardless of program mode, program execution commences by pressing the “Run TGAS/2” button on the  “Input Sheet IMP” worksheet.

### Design Mode
In design mode, the user must enter the process data as well as general configuration data (shell and vestibule types, materials of construction, tube diameter and thickness, etc.).  The program will then calculate a preliminary exchanger size and display a list of all possible tube layouts which satisfy this sizing requirement.  Once a layout is selected, the program calculates duct diameters, heat transfer coefficients and pressure drops and displays the results.  The user can now change various geometric parameters in order to optimize the exchanger design.  This is done by selecting the item and pressing the “Recalculate” button in the dialog box shown below:
Changing certain items will require a new tube layout.  If this is the case, the user is prompted  and has the option of not making the change.  When a new tube layout is generated, the program will reset the shell and baffle diameters to suit the new layout.
Once a satisfactory design is achieved, the user will press the “Continue (check acoustics)” button.  The program then continues on to check for acoustic resonance.  The dialog box on the right is displayed indicating whether or not acoustic resonance is possible.  The user has the option of adding acoustic baffles.
If the user elects to add acoustic baffles, the program will prompt for the number of baffles to add and the acoustic baffle thickness (see below).
The calculated number of baffles will be displayed as the default selection, but the user may override.  A default baffle thickness is also displayed, but this too may be changed.  Once both data are entered, the program will convert the tube layout to a segmental layout to accommodate the acoustic baffles.  Heat transfer and pressure drop will be rechecked with this new layout and the program terminated.

### Rating Mode
For rating mode, the user must enter the same data as for design mode with some additional geometric data to fully describe the heat exchanger.  The program will then calculate heat transfer, pressure drop and acoustic resonance and display the results.
In rating mode duct sizes are specified, not calculated.  The program will check the duct velocities vs. the maximum recommended value (80 ft/s) and issue a warning for the offending duct(s).
Regardless if acoustic baffles are present or not, the program will check for acoustic resonance and display the dialog box on the right to indicate whether or not acoustic resonance is possible.
Should the required (calculated) number of acoustic baffles exceed the input amount, a dialog will be issued to advise the user, but the number of baffles present cannot be changed during execution.

## Program Notes

### Heat and Mass Balance
The program performs a heat balance check based on input mass flows, temperatures and molar compositions.  If heat loads differ by more than 2%, a warning dialog is issued and execution continues.  The program will use the higher heat load as the design value.
If heat loads differ by more than 5%, an error dialog is issued and execution terminates.
If the mass flow or either temperature for one side are input as zero, the program will calculate the missing value based on the other side heat load.
The program will not overwrite mass flows based on the molar flows.  Molar flows are used only for calculation of fluid physical properties.

### Physical Properties
Properties for individual components are calculated based on correlations from the Acid Technology Division “Physical Property Data Manual”.  Gas mixtures are assumed to behave ideally.

### Program Limits
The following limits are hard coded into the program and cannot be exceeded.
Shell side cross passes - 12
Number of acoustic baffles - 9
Number of tube groups - 3
Total number of rows in layout - 50

### Nomenclature
The following terms and abbreviations are found in the program output.
Aeff – effective heat transfer area (tube outside surface area between tubesheets)
Agross – gross heat transfer area (total tube outside surface area)
ASFLOW – shell cross flow area for a single pass
DelPS – total shell side pressure drop (includes inlet/outlet vestibule losses)
DelPT – total tube side pressure drop (includes inlet/outlet vestibule losses)
GRP – number of tube groups
HI – heat transfer coefficient on inner tube surface
HO – heat transfer coefficient on outer tube surface
NP – number of shell side cross passes
NR – number of tube rows (rings) in a group
NRTOT – total number of tube rows in the layout
NTR – number of tubes per row in a group
Qave – heat duty (greater of shell side or tube side heat loads)
RMAX – radius of outermost tube row in a group
Safety Factor – heat transfer safety factor (defined as actual area / required area)
Theta – layout angle of outermost tube row in outermost group (see Figure 1)
U – overall heat transfer coefficient (includes tube wall resistance)

Appendix A – Gas/Gas Exchanger Process Descriptions
The most common services for gas/gas exchangers are described below.
Cold Exchanger
The cold exchanger is used to preheat the main gas stream before it enters the converter.  Excess heat from the gas stream leaving bed 4 of the converter provides the required heat.  The cold process gas from the discharge of the main blower enters the shell at the bottom of the exchanger.  The shell side discharge goes on to the tube side of the hot exchanger.  Hot gases from bed 4 of the converter enter the tube side of the exchanger at the top.  The tube side gas discharges at the bottom (along with any condensate) and then goes on to the final absorption tower.
Hot Exchanger
Aker Kvaerner Chemetics normal arrangement is to use an internal hot exchanger located inside the converter.  An internal exchanger eliminates the hot duct between the outlet of  bed 1 and the shell side of an external exchanger.  This duct is prone to frequent failures.  The hot exchanger performs the final stage of preheating of the process gas before it enters bed 1 of the converter.  Process gas from the shell side of the cold exchanger enters the tube side of the hot exchanger.  The gas flows downwards where it is heated to the strike temperature for the catalyst.  The gas then exits the tubes and passes through bed 1 of the converter.  Gas exiting bed 1 enters the shell side of the hot exchanger.  The shell side gas flows upwards and is discharged into bed 2.  The hot exchanger also has a central bypass duct.  This permits some of the gas exiting the cold exchanger to bypass the tube side of the hot exchanger, allowing for temperature control.
Cold Reheat Exchanger
The most common arrangement for double absorption acid plants is 3:1 (i.e. gas goes to the intermediate absorption tower after bed 3).  In this arrangement, the cold reheat exchanger is used to cool the gas leaving bed 3 and to reheat the gas leaving the intermediate absorption tower.  Gas exiting bed 3 enters the tube side of the cold reheat exchanger and flows downwards, discharging to the intermediate absorption tower.  Gas leaving the intermediate absorption tower then enters the shell side of the cold reheat exchanger and flows upwards where it is discharged into the shell side of the inter reheat exchanger.
Inter Reheat Exchanger
The inter reheat exchanger is used to cool the gas exiting bed 2 of the converter and to add additional heat to the gas leaving the cold reheat exchanger before entering bed 4 of the converter.  Gas leaving the shell side of the cold reheat exchanger enters the shell side of the inter reheat exchanger and flows downwards where it is discharged into bed. 4.  Gas from bed 2 enters the tube side of the inter reheat exchanger and flows upwards where it is discharged into bed 3.
Preheat Exchanger
The preheat exchanger is used to provide initial heat to the plant during start-up.  In metallurgical plants, this exchanger also supplies additional heat when the gas strength is below the autothermal limit.  The preheat exchanger uses hot combustion gas from a preheat furnace to heat air which is then added to the process gas.  The combustion gas enters the shell side of the exchanger and flows upwards where it is discharged to the atmosphere.  The process gas passes through the tube side of the exchanger flowing downwards.  Since the preheat exchanger is not used continuously, it is subject to repeated cycling.  Depending on the plant operation, the cycling can be severe.  This unit should be kept as short as practical to minimize differential thermal expansion.  Note: when Bunker C (#6 fuel oil) is used, the process flows should be switched (combustion gas on tube side) and the exchanger arranged horizontally to facilitate cleaning.
SO3 Cooler
The SO3 cooler uses air to cool an SO3 rich gas stream.  The SO3 stream is always placed on the tube side and enters the top of the exchanger flowing downwards.  This is done to ensure any condensed acid drains from the exchanger.  Like the preheat exchanger, this unit can be subject to extreme cycling and should be kept as short as practical to minimize differential thermal expansion.
