# 1-PRC-0001 — Procedure


[TABLE: 1-PRC-0001_table_1]


## Purpose
The purpose of the Process Design Criteria document is to record the owner’s process requirements for the project and present a summary of the process design criteria and contractual requirements for the project team.

## Document Requirements
This document will contain the follow elements as applicable:
Contract Requirements
Process description
Plant capacity
Design basis
Control philosophy
Reference to the appropriate Chemetics specification(s)
Any additional Chemetics general requirements for Plant design
Reference materials and Design Tools

## Approval
Process Design Criteria will be prepared by Process
Process Design Criteria will be checked by Project Engineer
Process Design Criteria will be approved by Process

## Commentary:

### Process Description
Overview of process (1/2 to1 page in length).

### Plant Capacity
Special requirements should be noted e.g., Plant design to handle hydraulically 110% of nameplate capacity.
Specify all design capacities, strengths, concentrations, etc.
Specify all guarantee values.

### Design Basis
List all atmospheric emission values (normal and guarantee).
List all liquid and solid effluents.
Specify plant availability e.g., 99%, 350 days operation per year, etc.
Reference documents include:
1-DST-0001 Site Design Conditions
1-LST-0001 Battery Limit Conditions

### Control Philosophy
Specify DCS control functions.
1) Process parameter measurement and signal transmission
2) Data acquisition and control
3) Alarms, interlocking, and shutdown
4) Operator interface and systems management
Specify details of how operators interface with DCS.
Specify start/stop philosophy for electric motors.
Specify details of all field control panels.

## Chemetics Requirements
The Plant will be designed following Chemetics standards and procedures as described in Q drive.

## Reference Material / Design Tools
List Process design programs.
List design manuals, design files, and previous project designs as references.
