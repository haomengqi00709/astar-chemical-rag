## Design Procedure
Project personnel will produce the P&ID in accordance with following procedures:

### Stage 1 P&ID - Approved for Design (Layout)
Stage 1 P&ID will contain following elements:
Equipment 	By Process
Process line connectivity	By Process
Process line fluid code	By Process
Process line preliminary material code	By Process
Estimated line size – major lines	By Process
Utility line to/from equipment	By Process
Utility line fluid code	By Process
Utility line preliminary material code	By Process
Hand valve	By Process
Field instruments and control loops	By Process
Stage 1 P&ID will be prepared by Design
Stage 1 P&ID will be checked by
Stage 1 P&ID will be approved by

### Stage 2 P&ID - Approved for Design (Pipe Study, Process Study, Stage 1 Line List & OTL)
Stage 2 P&ID will contain the following elements as applicable:
Utility line connectivity - header	By Design
Line identifier - all	By Design
Hand valve 	By Process
Control loop details	By Process
Insulation and heat tracing 	By Process
Field instrument and control loop numbers	By
Stage 2 P&ID will be prepared by Design
Stage 2 P&ID will be checked by Process
Stage 2 P&ID will be approved by Project Engineer

Stage 3 P&ID will contain the following elements as applicable:
Step 1
Pipe and gasket material – Final	By Design from Stage 3 Line list
size	By Design from Stage 3 Line list
Insulation material and thickness code	By Design from Stage 3 Line list
Results from process study	By Process
Piping process requirements	By Process
Hand valve process requirements	By Process
Alarm & interlocks	By Process
Motor controls	By Process
Emergency power	By Process
Step 2
Hand valve identifier	By Mechanical
Restriction orifices with identifier	By Mechanical
Expansion joints with identifier	By Mechanical
Pressure relief with identifier	By Mechanical
Piping specialities with identifier	By Mechanical
Stage 3 P&ID will be prepared by Design
Stage 3 P&ID will be checked by
Stage 3 P&ID will be approved by

### Stage 4 P&ID - Approved for Design (pre HAZOP)
Stage 4 P&ID will contain the following elements as applicable:
All changes identified in Team P&ID Review
Stage 4 P&ID will be prepared by Design
Stage 4 P&ID will be checked by Project Engineer
Stage 4 P&ID will be approved by Process

Stage 5 P&ID will contain the following elements as applicable:
All changes identified in HAZOP study
Stage 5 P&ID will be prepared by Design
Stage 5 P&ID will be checked by Process & Mechanical
Stage 5 P&ID will be approved by Project Engineer
