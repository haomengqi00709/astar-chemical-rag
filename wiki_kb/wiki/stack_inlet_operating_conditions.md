# Stack Inlet Operating Conditions

This page details the standard operating conditions specified for the inlet of a stack, as documented in the [[4-dst-xxxx-r0_template_stack_datasheet_administration|Template Stack Datasheet]]. These parameters are crucial for the design and performance evaluation of stack systems.

**Key Operating Condition Parameters at Stack Inlet:**
The following properties are typically recorded for the fluid entering the stack:
*   **General Property:** A descriptive field for general characteristics.
*   **T. L. V. for Single Component:** Measured in ppm v/v (parts per million by volume), indicating the Threshold Limit Value for a single component, relevant for safety and environmental considerations.
*   **Design Mass Flow Rate:** Specified in kg/h (kilograms per hour), representing the maximum expected mass flow.
*   **Design Minimum Mass Flow Rate:** Specified in kg/h, representing the minimum expected mass flow.
*   **Temperature:** Measured in °C (degrees Celsius), indicating the operating temperature of the inlet fluid.
*   **Pressure:** Measured in kPag (kilopascals gauge), indicating the operating pressure at the stack inlet.
*   **Volumetric Flow Rate:** Measured in Am3/h (actual cubic meters per hour), representing the actual volume of fluid flowing.
*   **Density:** Measured in kg/m3 (kilograms per cubic meter), indicating the fluid's density at operating conditions.
*   **Viscosity:** Measured in cP (centipoise), indicating the fluid's resistance to flow.
*   **Dew Points of Mixtures:** Measured in °C, critical for preventing condensation and potential corrosion within the stack.

**Data Structure for Operating Conditions:**
The datasheet organizes these parameters using specific column headers to allow for detailed breakdown:
*   **Total:** Represents the aggregate value for the operating condition.
*   **Comp 1:** Details for the first component in a mixture.
*   **Comp 2:** Details for the second component in a mixture.
*   **Comp 3:** Details for the third component in a mixture.
*   **Description:** Provides additional descriptive information for each parameter.

These detailed specifications ensure that the stack design accounts for the full range of process conditions. For related process information, refer to [[process_design_criteria_1_prc_0001]].

**Specific Operating Conditions and Units:**
*   **Description:** General Property
*   **T. L. V. for Single Component:** ppm v/v
*   **Design Mass Flow Rate:** kg/h
*   **Design Minimum Mass Flow Rate:** kg/h
*   **Temperature:** °C
*   **Pressure:** kPag
*   **Volumetric Flow Rate:** Am3/h
*   **Density:** kg/m3
*   **Viscosity:** cP
*   **Dew Points of Mixtures:** °C

**Column Headers:**
