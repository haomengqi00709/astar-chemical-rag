# Instrument Index and Tagging

The Instrument Index is a critical component of the project documentation, serving as a central listing for all plant instrumentation. It is maintained, in part, as a Microsoft Access database, which also supports the DCS I/O List and individual [[instrument_calibration_and_testing|Instrument Specification Sheets]].

**Development and Content:**
The development of the Instrument Index is initially derived from Aker Kvaerner Chemetics' issue of Stage III P&IDs (Piping and Instrumentation Diagrams). If the project contract requires an Instrument Index at an earlier stage, it may be created from Stage II P&IDs, though this version will be subject to revision as P&IDs are updated to Stage III.

The Instrument Index **will** provide a comprehensive listing of all instruments, including their tag numbers, as depicted on the P&IDs. All instruments shown on the P&IDs **will** be allocated a tag number. The index **will** be developed to its final stage, incorporating a complete cross-reference of primary documents associated with each instrument.

**Instrument Specification Sheets:**
An approved Instrument Specification Sheet **will** be provided for each instrument and actuated valve prior to its purchase. The creation of these sheets is dependent on:
*   Stage III issue of P&IDs (Approved for Design)
*   Issue of Process Data Lists as per Stage III P&IDs (Approved for Design)
*   Issue of Instrument Index as per Stage III P&IDs (Approved for Design)

**Tag Numbering and Identification:**
*   The Instrument Index **will** normally include standard Aker Kvaerner Chemetics Instrument Numbers.
*   Where required by project contract, a second identification tag number **will** be added according to the owner's requirements. This owner's tag number **will** be considered the main identification and **will** be used for referencing throughout all other project documents.
*   Instruments **will** be provided tagged with the owner's identification number.
*   The tag number **shall** be included in the configured parameters of instruments.
*   The service description **shall** also be included in the configured parameters of instruments.

For specific requirements regarding the allocation of instrument loop, tag numbering, and setup, refer to **8-PRC-0001: Plant Instrument Numbering**. For specific requirements for allocation of drawing numbers, refer to **0-PRC-0002: Document Numbering**.

The preparation of the Instrument Index, DCS I/O List, and Instrument Specification Sheets is a responsibility of the [[roles_and_documentation_management|Aker Kvaerner Chemetics Retained Subcontractor]].
