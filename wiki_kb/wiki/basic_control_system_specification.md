# Basic Control System Specification (8-SPC-0004)

The **Basic Control System Specification** document (8-SPC-0004) details the technical requirements for the control system, primarily for procurement purposes.

**Document ID:** 8-SPC-0004
**Usage:** Procurement
**Data available in SQL:** 8-SPC-0004

**Content Requirements:**
The Basic Control System Specification **MUST** contain the following:
*   Process controller requirements, including redundancy specifications.
*   Power supply requirements, including redundancy specifications.
*   I/O card requirements and specifications.
*   Communication interface requirements.
*   System performance specifications.
*   Cabinet specifications.
*   Operator console and engineering workstation specifications.
*   Alarm handling specifications.
*   Trends and logging specifications.
*   Security and fault tolerance specifications.
*   Expansion capacity specifications.
*   Factory testing and acceptance requirements.
*   Initial start-up and system checkout requirements.
*   Electrical requirements.
