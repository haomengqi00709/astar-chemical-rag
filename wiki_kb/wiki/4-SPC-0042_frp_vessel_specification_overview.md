# FRP Vessel Specification Overview (4-SPC-0042)

This Specification (Document ID: 4-SPC-0042, titled "Specification") outlines the requirements for shop-fabricated fibreglass reinforced plastic (FRP) process tanks or vessels that are not classified as pressure vessels. It serves as a foundational document for design, incorporating information from related specifications, drawings, and data sheets.

The specification details [[aker_kvaerner_chemetics_company_details]] requirements, presenting them as exceptions and additions to the 1999 Edition of [[ASME_RTP-1_standard_for_reinforced_thermoset_plastic_corrosion_resistant_equipment]]: Standard for Reinforced Thermoset Plastic Corrosion Resistant Equipment. Specific exceptions and additions are also made to RTP-1 Mandatory Appendix M-14, which covers Dual Laminate Vessels.

**Mandatory Requirements**:
*   RTP-1 accreditation is **not required** to fabricate equipment to this Specification.
*   Vessels **will** be designed to RTP-1, except where explicitly indicated on drawings and with exceptions detailed within this specification.
*   The User's Basic Requirements Specification (UBRS) **will not** be completed for vessels under this specification.
*   This Specification **will not** be used for vessels in a critical service.
*   Formal accreditation by ASME is **not required** to supply vessels to this Specification.
*   The fabricator **shall** engrave and affix an [[nameplate_order_equipment]] supplied by Aker Kvaerner Chemetics to each vessel.

**Scope and Application**
This Specification provides Aker Kvaerner Chemetics' specific requirements, acting as exceptions and additions to the 1999 Edition of ASME RTP-1: Standard for Reinforced Thermoset Plastic Corrosion Resistant Equipment. This includes specific exceptions and additions to RTP-1 Mandatory Appendix M-14, Dual Laminate Vessels.
*   RTP-1 accreditation is not required for fabricating equipment to this Specification, nor is formal accreditation by ASME required to supply vessels.
*   The User's Basic Requirements Specification (UBRS) will not be completed for vessels under this specification.
*   This Specification is not intended for use with vessels in critical service.

**Historical Context**
This specification completely replaces Standard-4-SPC-0042-R0. A name change for the document was implemented in 2005, for which no new revision number was used, and changes were not marked during this conversion.
