# Request for Quotation Process - Instrumentation (0-PRC-5005)

The [[issue_of_request_for_quotation_or_purchase_order_0_prc_5005]] procedure (0-PRC-5005) governs the Request for Quotation (RFQ) process, which is applied to both field instruments and instrument bulk materials.

**RFQ Preparation and Issuance:**
*   **Prepared by:** Procurement

The Project Buyer will produce the formal RFQ package after advisement by the Field Instrument Engineer (FIE) that all documents are complete and ready for issue. "Ready for issue" includes all required digital signatures.

**Communication and Documentation:**
The Project Buyer is responsible for all Request for Quotation communications to potential suppliers. The FIE **will ensure** that all critical communications between the FIE and potential suppliers are copied to the Project Buyer. The Project Buyer will place copies of these communications in the Purchase File.
