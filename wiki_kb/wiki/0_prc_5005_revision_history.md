# 0-PRC-5005 Revision History

This page documents the revision history for the procedure 0-PRC-5005, "Issue of Request for Quotation or Purchase Order."

**Revision 2:**
*   Sections 5 and 6 were transposed.
*   The requirement for the delivery date in an RFQ was clarified.
*   The checking and approval process for an RFQ was deleted.

**Name Change Conversion (Undated):**
*   A name change was implemented, referring to "Name Change Conversion."
*   No new revision number was used for this conversion.
*   Changes were not marked during this conversion.

**Revision 3:**
*   The procedure was modified to comply with [[vendor_bid_evaluation_procedure_0_prc_5003|0-PRC-5003-R4: Bid Evaluation and Approval]].
*   Requirements for the particulars of the Inspector were added.
*   Requirements for the particulars of the Vendor’s responsible personnel were added.

**2005 Name Change Conversion (Undated):**
*   A name change was implemented, referring to "2005 Name Change Conversion."
*   No new revision number was used for this conversion.
*   Changes were not marked during this conversion.

**Revision 4:**
*   Approval levels for revisions to orders were modified.

This history provides an overview of changes to the document, including [[0_prc_0005_document_name_change_history|name change impacts]] and procedural updates.
