# Document Administration (4-SPC-0081)

This page details the administrative history and conventions applied to document 4-SPC-0081, "Rubber Lining Specification."

**Name Change Conversion:**
A name change conversion, reflecting the transition to Aker Kvaerner Chemetics, has been implemented within this document. This conversion was applied without altering the existing revision number of the document. Consequently, changes related to this name change conversion have not been explicitly marked within the document text.

**2005 Name Change Conversion:**
Similarly, a separate 2005 name change conversion was also implemented in this document. As with the previous conversion, no new revision number was used, and the changes associated with this conversion have not been marked.

For general procedures on document numbering and administration, refer to [[0-PRC-0002_document_numbering]] and [[0-PRC-0005_publishing_of_project_documents]].
