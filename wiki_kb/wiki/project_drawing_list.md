# Project Electrical Drawing List

The Project Drawing List is a critical document for managing all electrical drawings throughout a project. It provides a centralized record of all drawing information and is maintained by the electrical lead.

**Content of the Project Drawing List**
The project drawing list, documented as 9-LST-0100, **shall** contain:
*   Document/drawing number.
*   Document/drawing revision number.
*   Name or title of the document/drawing.
*   Reason for issuing the document/drawing.
*   Client/Owner document/drawing number.

**Purpose and Maintenance**
The drawing list is used to keep a comprehensive record of all electrical drawings. It is prepared by the electrical lead and subsequently forwarded to the Project Engineer to update the overall project drawing list, ensuring consistency across all disciplines.
