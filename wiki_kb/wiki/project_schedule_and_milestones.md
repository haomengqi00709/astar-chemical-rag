# Project Schedule and Milestones

The project's detailed schedule is documented in 0-DAT-3001: Project Schedule.

**Contractual Milestones:**
*   **Delivery of Quality Plan:** This milestone is set at 4 weeks from the project start.
*   **Substantial Completion:** This milestone is set at 19 months from the project start.

**Substantial Completion Definition:**
Substantial Completion is defined as the point when the plant is "fully commissioned ready for performance testing." This milestone is subject to Liquidated Damages (LD) if not met within the contractual timeframe.
