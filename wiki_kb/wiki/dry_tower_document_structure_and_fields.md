# Dry Tower Document Structure and Fields

This page describes the structure and specific fields found within the Dry Tower engineering documents, including the signature sheet and data input sheets.

**Signature Sheet Details**
*   The signature sheet includes column headers numbered 1.0 through 24.0.
*   The "Calculation" field on the signature sheet is associated with "CHEMETICS".
*   The "Location" field on the signature sheet is present but has no specified value.

**Data Input Sheet Details**
*   The "Case Description" field on the Data Input sheet is present but has no specified value.
*   The "Design Basis" field on the Data Input sheet is present but has no specified value.

**Process Data Sheet Details**
*   The process data sheet includes column headers numbered 1.0 through 24.0.
*   The "Process Data Sheet" field on the data sheet is associated with "CHEMETICS".
*   The "Project Title" field on the data sheet is present but has no specified value.
*   The "Location" field on the data sheet is present but has no specified value.
