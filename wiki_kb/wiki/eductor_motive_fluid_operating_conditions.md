# Ejector Motive Fluid Operating Conditions

This page specifies the standard units and parameters for the motive fluid operating conditions in ejector systems, as defined in the Template Ejector Datasheet (Document ID [[template_ejector_datasheet_administration]]). Accurate specification of these parameters is essential for efficient ejector performance.

**Motive Fluid Parameters and Units:**
*   **Flow Rate:** kg/h
*   **Operating Temperature:** °C
*   **Superheat:** °C
*   **Maximum Temperature:** °C
*   **Operating Pressure:** kPa(g)
*   **Maximum Pressure:** kPa(g)
*   **Density:** kg/m³

These specifications are integral to the [[process_design_criteria_1_prc_0001]] and are documented in the [[process_data_sheet_overview]] for the equipment.

**Motive Fluid Parameters and Units:**
*   **Flow Rate:** kg/h
*   **Operating Temperature:** oC
*   **Superheat:** oC
*   **Maximum Temperature:** oC
*   **Operating Pressure:** kPa(g)
*   **Maximum Pressure:** kPa(g)
*   **Density:** kg/m3
