# 7-SPC-0001 Table 3: UV Protection Systems

This page describes the content of Table 3 from `7-SPC-0001 Protective Coating Specification`. This table lists specialized coating systems that are to be used exclusively for UV protection.

These systems are specifically designed to withstand degradation from ultraviolet radiation and **must** only be applied where explicitly indicated for this purpose. The table provides details necessary for proper selection and application of these coatings.
