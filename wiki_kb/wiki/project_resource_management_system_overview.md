# Project Resource Management System (PRMS) Overview (0-PRC-3003)

This procedure, identified as 0-PRC-3003, outlines the methods for monitoring project home-office resources, providing essential measures of progress and productivity, and forecasting ongoing requirements. The core tool for this process is the Project Resource Management System (PRMS), a Microsoft Excel spreadsheet designed to offer the necessary functionality and reporting capabilities.

The body of this procedure provides a generalized description of the functioning of the PRMS. For more specific guidance, [[detailed_prms_operating_procedures_appendix_a|Appendix A]] contains detailed operating instructions for the PRMS.

**Key Responsibilities:**
*   **Project Controls** is responsible for inputting all data into the PRMS and producing all reports generated from the system.
*   All projects **must** utilize the PRMS and ensure it is updated regularly to maintain accurate resource tracking and forecasting.

The PRMS is a critical tool for project management, enabling effective oversight of resource allocation, performance, and future needs. It integrates various project data points to provide a comprehensive view of home-office resource utilization.
