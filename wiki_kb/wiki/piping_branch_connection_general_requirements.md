# Piping Branch Connection General Requirements

This page outlines the overarching requirements and standards applicable to all branch connections within piping systems. Specific details for individual branch connection types are provided in their respective specifications.

**Mandatory Compliance and Standards**
All branch connections **shall** be in accordance with [[ASME_b31_3_chemical_plant_and_petroleum_refinery_piping]]. In the event of any conflict between the requirements of ASME B31.3 and any specific branch connection specification, ASME B31.3 **shall** govern.

**Design and Fabrication**
*   Branch connections **shall** be made at 90° only.
*   A branch connection **shall not** intersect with the longitudinal weld of the run pipe.
*   Required stiffening rings, where applicable, are specified with the respective branch connection tables in Section 5 of the main piping specification.

**Substitutions and Approvals**
Any substitutions for specified branch connection components are subject to prior approval by Aker Kvaerner Chemetics.
