# Expenditure Request Form (Appendix A)

The "Expenditure Request Form," designated as Appendix "A" to the [[0-prc-5006_procurement_purchase_card_procedure|Procurement Purchase Card Procedure (0-PRC-5006)]], is an integral part of the procedure.

### Purpose
This form **MUST** be used to detail all proposed non-project expenditures made using the Purchase Card. Its primary purpose is to clearly identify the rationale and specifics for each expenditure, ensuring transparency and compliance with company policies.

### Required Information
The form **WILL** require the following details for each proposed non-project expenditure:
*   Clear identification of the purpose for the expenditure(s).
*   Name and address of the Vendor.
*   Description of the purchase to be made.
*   Quantity to be purchased.
*   Unit price of each item.
*   Amount of Sales Tax to be paid.
*   Shipping Charges, etc., if applicable.

### Relation to Procedure
The completion and approval of this form are mandatory for all non-project related purchases made with the Purchase Card, as outlined in the [[0-prc-5006_procurement_purchase_card_procedure|Procurement Purchase Card Procedure]].

### Content Requirements
All proposed non-project expenditures must be detailed in writing using this form. The "expense request form" must clearly identify the purpose for the expenditure(s) and provide the following details:
*   Name and address of Vendor.
*   Description of the purchase to be made.
*   Quantity to be purchased.
*   Unit price of each item.
*   Amount of Sales Tax to be paid.
*   Shipping Charges, etc., if applicable.
