# Document Preparation and Revision Process

The initiation and modification of project documents follow a structured process to ensure proper tracking and version control.

**New Document Preparation:**
Upon commencing the preparation of a new document, the individual responsible for the work must adhere to the following steps:
*   The preparer's name shall be inserted into the document revision log.
*   The initial revision number shall be denoted as either “A” or “1”, as appropriate for the document type.
*   The document's status shall be marked as "Draft in Progress".
*   A unique document file name must be assigned, adhering to the guidelines specified in [[document_file_naming_conventions]] (reference: 0-PRC-0003: File Structure).

**Existing Document Revision:**
When undertaking a revision of an existing document, the following procedures must be followed:
*   The preparer's name shall be inserted into the document revision log.
*   The existing revision number shall be incremented to reflect the new version.
*   The document's status shall be denoted as "Revision in Progress".
*   The file name must be updated to include the new revision number, in accordance with [[document_file_naming_conventions]] (reference: 0-PRC-0003: File Structure). Incrementing the revision number in the file name serves as an immediate alert to users that a revision is underway and prompts them to seek the latest version of the document.

**New Document Preparation:**
Upon commencing the preparation of a new document, the individual responsible for the work must adhere to the following steps:
*   The preparer's name must be inserted into the document revision log.
*   The initial revision number must be denoted as either “A” or “1” as appropriate.
*   The status of the document must be set to "Draft in Progress".
*   The document file name must be assigned, adhering to the guidelines specified in [[0-prc-0003_file_structure]].

**Existing Document Revision:**
When commencing a revision of an existing document, the person doing the work must:
*   Insert their name in the document revision log as the preparer.
*   Increment the revision number.
*   Denote the status as "Revision in Progress".
*   Change the file name to include the new revision number, following the guidelines in [[0-prc-0003_file_structure]]. Incrementing the revision number in the file name serves to alert users looking for the latest version that a revision is currently in progress.
