# Administrative Document Changes

This page documents administrative changes applied to various project documents, specifically focusing on name change conversions.

**Name Change Conversions:**
*   The "2005 Name change conversion" has been implemented across relevant documents.
*   A subsequent name change conversion has also been implemented.

**Revision and Marking:**
*   For both the 2005 and later name change conversions, no new revision number was used.
*   Changes related to these conversions were not marked within the documents. This means that the content reflects the updated names without explicit revision indicators for these specific administrative modifications.
