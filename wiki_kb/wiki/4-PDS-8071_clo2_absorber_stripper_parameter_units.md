# ClO2 Absorber-Stripper Parameter Units

This page lists the standard units used for various parameters in the ClO2 Absorber-Stripper Process Data Sheet (Document ID 4-PDS-8071).

**Parameter Units**
*   **Vapour Flow:** kg/h
*   **Liquid Flow:** kg/h
*   **Minimum Flow Rate:** kg/h
*   **Temperature:** oC
*   **Pressure:** kPaa
*   **Density:** kg/m3
*   **Viscosity:** cP
*   **Surface tension:** mN/m
