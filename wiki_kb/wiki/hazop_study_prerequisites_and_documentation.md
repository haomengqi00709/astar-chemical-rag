# HazOp Study Prerequisites and Documentation

A Hazard and Operability (HazOp) Study can only commence once specific project documentation has reached the required approval status.

**Mandatory Documentation Status:**
*   All supporting project documentation **must** have the status "Approved for Design".
*   [[Piping and Instrument Diagrams]] (P&IDs) **must** be at the status "Approved for Design (HazOp)".

The development and approval process for P&IDs is governed by [[0-PRC-0003_file_structure]].

**Required Supporting Documentation:**
The HazOp team requires access to the following documents:
*   1-DST-0001: [[site_design_conditions_1_dst_0001]]
*   1-LST-0001: [[battery_limits_conditions_1_lst_0001]]
*   1-PFD-XXXX: [[process_flow_diagram]]
*   1-PID-XXXX: [[piping_and_instrumentation_drawings]]
*   1-PRC-0001: [[process_design_criteria_1_prc_0001]]
*   4-LST-0001: [[equipment_list]]
*   5-LST-0001: [[line_list_5_lst_0001]]
*   5-LST-0002: [[tie_point_list_5_lst_0002]]
*   8-SPC-0020: [[logic_narrative]]
*   8-SPC-XXXX: [[instrumentation_specification]]

A copy of the published versions of all supporting documentation will be stored in the project directory: `P:\1-Process-Technology\HAZ`.

**Related Procedures and Document Storage:**
*   P&ID development and approval is governed by [[0-prc-0003_pid_development_and_approval|0-PRC-0003]].
*   A copy of the published versions of all supporting documentation will be stored in `P:\1-Process-Technology\HAZ`.
