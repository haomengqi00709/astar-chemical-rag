# 4-SPC-0016 Table 2: Manual Metallic Arc Welding Combinations

This page describes the content of Table 2, which is part of the 4-SPC-0016 standard.

Table 2 outlines specific combinations for manual metallic arc welding of clad material or overlay welding on carbon steel. It provides guidance on acceptable electrode types and welding parameters for these applications.

Key requirements related to this table include:
*   A 25CR-20Ni (E-310) electrode **must not** be used under any circumstances.
*   Electrode selection other than those shown in this table **must** be approved in writing by Aker Kvaerner Chemetics.
*   Weld deposits **must** be performed in not less than three (3) layers, as shown in this table.

Refer to [[4-SPC-0016_welding_consumables_and_chemical_analysis]] for further details on welding consumables and their application.
