# DCS Operator Console and Highway Device Checkout (8-PRC-0014)

This page details the specific steps for performing the checkout of Operator Consoles, Engineering Stations, and Highway Devices as part of the overall [[dcs_field_hardware_checkout_8_prc_0014|DCS Hardware Checkout Procedure (8-PRC-0014)]].

**Operator Console/Engineering Stations Checkout:**
The following steps **must** be performed for each Operator Console and Engineering Station:
1.  Power up the first Station.
2.  Observe the boot-up process of the station.
3.  Check all peripherals, including the CRT, keyboard, mouse, printer, horn, alarm lights, CD-ROM, and any other installed devices.
4.  Load the station with DCS System software, if required.
5.  Verify that the station is online and successfully communicating with other DCS devices.
6.  Check the [[dcs_system_functionality]] (new slug) of the station.
7.  Disconnect the communication cable and observe the station status.
8.  Ensure a system alarm appears on the screen.
9.  Repeat this entire procedure for all other Operator Stations and Engineering Stations.

**Highway Devices Checkout:**
The following steps **must** be performed for each Highway Device:
1.  Power up the first Highway device.
2.  Wait for the self-diagnostic test to complete.
3.  Observe the local status LED display, if applicable.
4.  Disconnect the highway communication cable.
5.  Observe the local status LED display after disconnection.
6.  Load the required software for this device.
7.  Repeat this entire procedure for all other highway devices.

**Operator Console/Engineering Stations Checkout:**
The following steps are performed for Operator Console/Engineering Stations Checkout:
1.  Power up the first Station.
2.  Observe the boot up of the station.
3.  Check all peripherals including CRT, keyboard, mouse, printer, horn, alarm lights, CD-ROM and other devices.
4.  Load the station with DCS System software (if required).
5.  Verify that the station is on-line and communicating with other DCS devices.
6.  Check the DCS system functionality of the station.
7.  Disconnect the communication cable and observe the station status.
8.  Ensure a system alarm appears on the screen.
9.  Repeat the same procedure on all other Operator Stations/Engineering Stations.

**Highway Devices Checkout:**
The following steps are performed for Highway Devices Checkout:
1.  Power up the first Highway device.
2.  Wait for the self-diagnostic test to complete.
3.  Observe the local status LED display (if applicable).
4.  Disconnect the highway communication cable.
5.  Observe the local status LED display.
6.  Load the required software for this device.
7.  Repeat the same procedure for other highway devices.
