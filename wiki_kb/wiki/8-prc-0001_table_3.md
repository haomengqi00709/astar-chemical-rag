# Standard Instrument Device Type Character Assignments (Device Type & Action Modifier)

This page details the standard character assignments for the second and third characters of the Device Type tag. The second character represents the Device Type (e.g., 'S' for switch, 'T' for transmitter, 'V' for valve), and the third character represents the Action Modifier (e.g., 'H' for high, 'L' for low).
