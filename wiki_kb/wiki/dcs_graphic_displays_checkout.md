# DCS Graphic Displays Checkout

The checkout of Distributed Control System (DCS) graphic displays is an integral part of the [[8-PRC-0006_dcs_control_function_checkout|DCS Control Function Field Checkout]]. This process ensures that the operator interface accurately represents the process, provides correct information, and allows for proper interaction with control elements.

**Key Checks for Graphic Displays:**
*   **Graphic Links:** All links between different graphic pages **must** be tested to ensure seamless navigation and access to related process views.
*   **Object Presentation:** Verify the correct graphic presentation of all objects shown on the graphics. This includes ensuring that equipment, piping, and instrumentation are displayed accurately and clearly.
*   **Standard Faceplate Appearance:** Check for the correct appearance of standard faceplates (e.g., for Controllers, Motors, etc.). These faceplates provide a consistent interface for interacting with control elements.
*   **Standard Faceplate Behavior:** Verify the correct behavior of standard faceplates, ensuring that they respond as expected to operator inputs and display real-time data accurately.

**Documentation on Checkout Sheets (Sheet 2):**
For graphics on [[8-LST-0102_dcs_configuration_checkout_sheet|DCS Configuration Checkout Sheet 2]], the following aspects **must** be marked off in the appropriate columns:
*   **Correct Relative Location:** Confirm that objects are displayed in their correct relative positions on the graphic page.
*   **Correct Display and Display Value:** Verify that the displayed information and values for each point are accurate and up-to-date.
*   **Event List Presence:** Mark whether the point shows up on the event list, indicating its logging capability.
*   **Alarm List Presence and Priority:** Mark whether the point shows up on the alarm list, and specify its alarm priority level.
*   **Trending Status and Number:** Mark whether the point is trended, and if so, list the corresponding trend number.

These comprehensive checks ensure that the DCS operator interface is intuitive, accurate, and fully functional, supporting effective process monitoring and control.
