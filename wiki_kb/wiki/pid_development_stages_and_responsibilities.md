# P&ID Development Stages and Responsibilities

This procedure, documented as [[document_control_1_prc_0003|1-PRC-0003]], outlines the phased development of Process & Instrumentation Diagrams (P&IDs) throughout a project lifecycle. Project personnel **shall** produce P&IDs in strict accordance with the requirements specified for each stage.

### Stage 1 P&ID (Approved for Design - Layout)
This initial stage focuses on the fundamental layout and process connectivity.

*   **Preparation:** Prepared by Design.
*   **Content Requirements (By Process):**
    *   Equipment
    *   Process line connectivity
    *   Process line fluid code
    *   Process line preliminary material code
    *   Estimated line size – major lines
    *   Utility line to/from equipment
    *   Utility line fluid code
    *   Utility line preliminary material code
    *   Hand valve
    *   Field instruments and control loops
*   **Checker:** Not specified.
*   **Approver:** Not specified.

### Stage 2 P&ID (Approved for Design - Pipe Study, Process Study, Stage 1 Line List & OTL)
This stage refines the P&ID with more detailed line information and initial control loop specifics.

*   **Preparation:** Prepared by Design.
*   **Content Requirements:**
    *   Utility line connectivity - header (By Design)
    *   Line identifier - all (By Design)
    *   Hand valve (By Process)
    *   Control loop details (By Process)
    *   Insulation and heat tracing (By Process)
    *   *Note:* No specified party responsible for Field instrument and control loop numbers at this stage.
*   **Checker:** Checked by Process.
*   **Approver:** Approved by Project Engineer.

### Stage 3 P&ID (Approved for Design - Team P&ID Review, Instrumentation & Control Design)
This stage incorporates final material specifications, detailed process requirements, and mechanical components.

*   **Preparation:** Prepared by Design.
*   **Content Requirements:**
    *   Pipe and gasket material – Final (By Design from Stage 3 Line list)
    *   Size (By Design from Stage 3 Line list)
    *   Insulation material and thickness code (By Design from Stage 3 Line list)
    *   Results from process study (By Process)
    *   Piping process requirements (By Process)
    *   Hand valve process requirements (By Process)
    *   Alarm & interlocks (By Process)
    *   Motor controls (By Process)
    *   Emergency power (By Process)
    *   Hand valve identifier (By Mechanical)
    *   Restriction orifices with identifier (By Mechanical)
    *   Expansion joints with identifier (By Mechanical)
    *   Pressure relief with identifier (By Mechanical) - See also [[pressure_relief_equipment_tagging|Pressure Relief Equipment Tagging]].
    *   Piping specialities with identifier (By Mechanical)
*   **Checker:** Not specified.
*   **Approver:** Not specified.

### Stage 4 P&ID (Approved for Design - pre HAZOP)
This stage integrates all changes identified during the Team P&ID Review, preparing the document for the HAZOP study.

*   **Preparation:** Prepared by Design.
*   **Content Requirements:**
    *   All changes identified in Team P&ID Review.
*   **Checker:** Checked by Project Engineer.
*   **Approver:** Approved by Process.

### Stage 5 P&ID (Approved for Design - post HazOp)
This stage incorporates all modifications and updates resulting from the formal HAZOP study.

*   **Preparation:** Prepared by Design.
*   **Content Requirements:**
    *   All changes identified in HAZOP study.
*   **Checker:** Checked by Process & Mechanical.
*   **Approver:** Approved by Project Engineer.

### P&ID Approved for Design
This final design-approved P&ID reflects all changes from the detailed design phase.

*   **Preparation:** Prepared by Design.
*   **Content Requirements:**
    *   All changes resulting from final stages of detail design.
*   **Checker:** Checked by Process.
*   **Approver:** Approved by Project Engineer.

### P&ID As Built
The "As Built" P&ID captures all changes and modifications made during construction and commissioning, serving as the definitive record.

*   **Preparation:** Prepared by Design.
*   **Content Requirements:**
    *   All changes and modifications during construction and commissioning.
*   **Checker:** Checked by Process.
*   **Approver:** Approved by Commissioning Manager.
