# Instrumentation and Control Erection (0-SPC-6X98)

This page describes the requirements for Instrumentation and Control Erection as outlined in document 0-SPC-6X98. The Subcontractor **must** adhere to these specifications for all instrumentation and control system installation activities related to the construction subcontract. This includes, but is not limited to, the mounting, wiring, and connection of instruments and control panels.

Refer to [[0-SUB-6_construction_subcontract_scope_of_works]] for the specific application of this specification within the overall project scope.
