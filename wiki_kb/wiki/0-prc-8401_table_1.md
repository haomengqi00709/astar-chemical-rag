# 0-PRC-8401 Table 1: Site Construction Manager Responsibilities

This page refers to Table 1 within document 0-PRC-8401, which details specific responsibilities of the Aker Kvaerner Chemetics Site Construction Manager.

The Aker Kvaerner Chemetics Site Construction Manager has overall responsibility for all activities on the construction site, including ensuring the implementation and adherence to the Project Health, Safety and Environment plan by all Aker Kvaerner Chemetics subcontractors.

The Aker Kvaerner Chemetics Site Construction Manager has overall responsibility for all activities on the construction site, including ensuring:
*   The Project Health, Safety and Environment plan is implemented in a timely manner.
*   The Project Health, Safety and Environment plan is followed by all Aker Kvaerner Chemetics subcontractors.
