# Project Document Control and Numbering

Effective document control and numbering are essential for managing project documentation.

**Handling Owner Design Documents:**
The Project Engineer **must** forward all Owner design documents referenced by the Contract to Document Control. Document Control will then publish, log, and file these Owner design documents in accordance with [[control_of_project_documents_0_prc_0006|0-PRC-0006: Control of Project Documents]].

**Dual Document Numbering:**
If the project requires dual Owner and Aker Kvaerner Chemetics document numbers, the Project Engineer **must** modify and issue [[document_numbering_and_name_change_conventions|0-PRC-0002: Document Numbering]] specifically for the project.

**Initial Project Document List (0-LST-0001):**
Discipline Leads and the Project Engineer **must** collaborate to develop an initial listing of all project documents, known as 0-LST-0001: Document List. This list is based on the [[scope_definition_documents|0-LST-2001: Engineering Scope Checklist]].

Data available in SQL: 0-LST-0001
