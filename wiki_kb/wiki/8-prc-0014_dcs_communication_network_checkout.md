# 8-PRC-0014 DCS Communication Network Checkout

This page outlines the procedure for checking the Distributed Control System (DCS) communication network as part of the overall [[dcs_field_hardware_checkout_8_prc_0014|DCS Hardware Checkout Procedure (8-PRC-0014)]].

The DCS communication network will be tested to ensure it meets the DCS Manufacturer’s Performance Requirement(s).
