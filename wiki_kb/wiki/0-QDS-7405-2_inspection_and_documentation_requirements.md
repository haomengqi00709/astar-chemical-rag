# 0-QDS-7405-2 Inspection and Documentation Requirements

The following outlines the mandatory inspection and documentation requirements for the Blower Lube Oil System, in accordance with [[0-QDS-7405-2_document_details]] and [[0-QDS-7405-2_vendor_quality_assurance_requirements]]. Quality Record requirements are defined using the terms [[0-QDS-7405-2_quality_record_definitions|AP]] (As Prepared) and [[0-QDS-7405-2_quality_record_definitions|FP]] (Included in Quality Assurance Documentation Package).

*   **Material Verification**
    *   Required in the Vendor I & T Plan.

*   **Material Test Certificates**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|FP]] for the Reservoir liner.
    *   Chemetics requires to Witness these certificates.
    *   Certificates **shall** be complete.

*   **Certificate of Compliance**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|FP]] for the balance of materials.
    *   Chemetics requires to Witness this certificate.
    *   Certificate **shall** be complete.

*   **Hydrostatic Test**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|FP]].
    *   Chemetics requires to Witness this test.
    *   Chemetics requires a Hold point for this test.
    *   The test **shall** be performed Per API-614.
    *   The test **shall** be complete.

*   **Operational Test**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|FP]].
    *   Chemetics requires to Witness this test.
    *   Chemetics requires a Hold point for this test.
    *   The test **shall** be performed Per API-614.
    *   The test **shall** be complete.

*   **External Coating of CS**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|FP]].
    *   Chemetics requires to Witness this activity.
    *   Chemetics requires a Hold point for this activity.
    *   The coating application **shall** be complete.

*   **Dimensional Inspection**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|FP]].
    *   Chemetics requires to Witness this inspection.
    *   Chemetics requires a Hold point for this inspection.
    *   The inspection **shall** be complete.

*   **Surfaces Free From Defects Inspection**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|FP]].
    *   Chemetics requires to Witness this inspection.
    *   Chemetics requires a Hold point for this inspection.
    *   The inspection **shall** be complete.

*   **Cleanliness Inspection**
    *   Chemetics requires to Witness this inspection.
    *   Chemetics requires a Hold point for this inspection.
    *   The inspection **shall** be complete.
    *   No Quality Record is required for this inspection.

*   **Review QA Documentation**
    *   Chemetics requires to Witness this review.
    *   Chemetics requires a Hold point for this review.
    *   The review **shall** be complete.
    *   No Quality Record is required for this review.

*   **Packaging**
    *   Chemetics requires to Witness this activity.
    *   Packaging **shall** be complete.
    *   No Quality Record is required for this activity.
    *   No Chemetics Hold point is required for this activity.

*   **Packing List**
    *   Required as [[0-QDS-7405-2_quality_record_definitions|AP]].
    *   Chemetics requires to Witness this list.
    *   The list **shall** be complete.
    *   No Chemetics Hold point is required for this list.
