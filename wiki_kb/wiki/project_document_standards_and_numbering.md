# Project Document Standards and Numbering

All project documents **must** adhere to specific standards for language, units, and paper size:
*   **Language:** English language **must** be used for all project documents.
*   **Units:** SI Units **must** be used for all project documents.
*   **Paper Size:** Only Metric Paper sizes A1, A3, and A4 **must** be used for all project documents.

**Dual Document Numbering:**
All project documents **shall** contain both Aker Kvaerner Chemetics and Owner's document numbers.
*   The Owner’s document numbering system is described in [[document_number_format_and_components]] (0-PRC-0002: Document Numbering).
*   Owner document numbers will be assigned by the Project Engineer and stored in the Document Control Database.

**Owner's Numbering Systems for Equipment:**
The Owner has established numbering systems for various plant components, including:
*   Equipment
*   Piping
*   Valves
*   Instruments
*   Electrical equipment
*   Cabling

Owner’s numbers **shall** be used for all items from the outset of the project.

**Aker Kvaerner Chemetics Standard Numbers:**
Reference Aker Kvaerner Chemetics standard numbers will be shown on the following lists:
*   Equipment List: Data available in SQL: 4-LST-0001
*   Piping Line List: Data available in SQL: 5-LST-0001
*   Field Instrument List: Data available in SQL: 8-LST-0001
*   Electrical Equipment List: Data available in SQL: 9-LST-0001

Aker Kvaerner Chemetics document numbers will be derived from the Aker Kvaerner Chemetics standard tag numbers, in accordance with [[document_number_format_and_components]] (0-PRC-0002: Document Numbering).

**Document Review and Approval:**
*   The requirement for document review and approval by the Owner is set out in 0-LST-2001: Engineering Scope Checklist. Any contractually required submittal dates are also noted in this checklist.
*   The requirement for document review and approval by an Australian registered engineer is set out in 0-LST-2001: Engineering Scope Checklist. Such approvals will be obtained from engineering contractor(s) engaged for detail engineering or for the specific purpose.

**Document Numbering Systems:**
All documents will contain both Aker Kvaerner Chemetics and Owner's document numbers.
*   The Owner’s document numbering system is described in 0-PRC-0002: Document Numbering.
*   Owner document numbers will be assigned by the Project Engineer and stored in the Document Control Database.
*   The Owner has established numbering systems for Equipment, Piping, Valves, Instruments, Electrical equipment, and Cabling. Owner’s numbers will be used for all items at the outset of the project.
*   Reference Aker Kvaerner Chemetics standard numbers will be shown on the following lists:
    *   4-LST-0001: Equipment List
    *   5-LST-0001: Piping Line List
    *   8-LST-0001: Field Instrument List
    *   9-LST-0001: Electrical Equipment List
*   Aker Kvaerner Chemetics document numbers will be derived from the Aker Kvaerner Chemetics standard tag numbers, in accordance with 0-PRC-0002: Document Numbering.
