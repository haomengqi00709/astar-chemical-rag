# Packed Tower Internals and Performance Data (4-PDS-XXXX-R2)

The Packed Tower Process Data Sheet (4-PDS-XXXX-R2) provides detailed specifications for the tower's internal components and expected performance characteristics across different zones. This information is vital for the mechanical design, fabrication, and operational validation of the packed tower.

**Equipment Data - Zones:**
The packed tower is divided into **6 Zones (1.0 to 6.0)**, allowing for detailed specification and performance evaluation for each section.

**Key Dimensional and Performance Parameters (with units):**
*   **Column Inside Diameter:** m
*   **Packing Size:** mm
*   **Packing Height:** m
*   **Pressure Drop Wet:** kPa
*   **Wetting Rate:** m3/h·m
*   **Flooding:** %
*   **Loading:** %
*   **Hold-Up:** %
*   **H.E.T.P. (Height Equivalent to a Theoretical Plate):** m
*   **Packing Support Size:** Specified as % min open area.

**Mandatory Vendor Requirements:**
The **Vendor MUST** provide the following performance data for each zone:
*   Pressure drop per meter packing
*   % flooding
*   % hold-up
*   Wetting rate at entry and exit of each zone

**Internal Components:**
The datasheet also specifies the types and materials for various internal components, which are crucial for the tower's functionality and corrosion resistance. These include:
*   **Packing Type**
*   **Packing Material**
*   **Packing Support Type**
*   **Packing Support Material**
*   **Bed Limiter Type**
*   **Bed Limiter Material**
*   **Redistributor/Distributor Type**
*   **Redistributor/Distributor Material**
*   **Collector Plates Type**
*   **Collector Plates Material**

For more information on packing specifications, refer to [[tower_internals_packing_specifications]]. Details on process design conditions for tower internals can be found in [[tower_internals_process_design_conditions]], and information on support and ancillary components is available in [[tower_internals_support_and_ancillary_components]].
