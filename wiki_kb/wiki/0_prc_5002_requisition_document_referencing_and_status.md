# Requisition Document Referencing and Status (0-PRC-5002)

The status of documents referenced within a Requisition is crucial for ensuring that the correct and approved versions are used throughout the Request for Quotation (RFQ) and Purchase Order (PO) processes.

**For Requisitions for Request for Quotation (RFQ):**
*   All documents referenced by a Requisition for an RFQ **must** be published in accordance with the [[publishing_project_documents]] procedure (0-PRC-0005).
*   If a document is available with the status “Approved for Fabrication,” that specific version **shall** be referenced in the Requisition for RFQ.
*   If a document is not yet available with the status “Approved for Fabrication,” the requisitioner **must** ensure that these documents are published with the status “Issued for Quotation.” These “Issued for Quotation” versions will then be referenced in the Requisition for RFQ.

**For Requisitions for Purchase Order (PO):**
*   Prior to the preparation of a Requisition for a PO, all referenced documents **must** be modified as necessary to incorporate any changes or agreements reached during the [[0_prc_5003_bid_evaluation_and_approval|bid evaluation process]] (0-PRC-5003).
*   Documents referenced by a Requisition for a PO **must** have the status “Approved for Fabrication” before the Requisition itself is issued. This ensures that the final, approved technical specifications are part of the Purchase Order.
*   Any revisions to documents referenced by an issued Requisition for a PO will necessitate the issuance of a revised Requisition. This revised Requisition **must** include the updated references to the modified documents.
