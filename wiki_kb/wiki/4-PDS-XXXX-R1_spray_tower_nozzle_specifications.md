# Spray Tower Nozzle Specifications (4-PDS-XXXX-R1)

The Template Spray Tower Process Data Sheet (document ID 4-PDS-XXXX-R1) provides detailed specifications for the nozzles used within the spray tower. This information is crucial for ensuring proper fluid distribution and performance.

The **Nozzle Information** section includes:

*   **Type**: Specifies the design or configuration of the nozzle (e.g., full cone, spiral, etc.).
*   **Size**: The nominal size of the nozzle, measured in millimeters (mm).
*   **Material**: The material of construction for the nozzle, selected for compatibility with process fluids.
*   **Pressure Drop**: The expected pressure drop across the nozzle, measured in kPa.

**Nozzle Table**
A dedicated **Nozzle Table** is included in the document, providing a structured overview of all nozzles. The columns in this table are:

*   **Nozzle Description**: A brief description of the nozzle's function or location.
*   **Mark**: A unique identifier or tag for the nozzle.
*   **Size (mm)**: The size of the nozzle, explicitly stated in millimeters.
*   **Quantity**: The number of identical nozzles required.

An **EQUIPMENT SKETCH** is also provided within the document, which visually represents the spray tower and indicates the locations and types of nozzles, aiding in understanding the "Stream" references in the [[4-PDS-XXXX-R1_spray_tower_process_design_conditions]] section.
