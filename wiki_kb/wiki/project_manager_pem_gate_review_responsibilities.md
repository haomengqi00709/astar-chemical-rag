# Project Manager Responsibilities for PEM Gate Reviews

The Project Manager plays a central role in the successful execution and management of [[0-prc-2101_project_execution_model_gate_reviews_overview|Project Execution Model (PEM) Milestone Gate Reviews]]. Their responsibilities encompass planning, organization, and follow-up actions.

**Planning and Organization**
The Project Manager is responsible for:
*   Planning and organizing the Milestone Gate Reviews.
*   Inviting participants, including personnel from both within and outside the immediate project team, as appropriate.
*   Expediting the preparation for the review with [[discipline_lead_and_approver_roles|Discipline Leads]] and Department Managers.
*   Ensuring that all documentation required for the review is readily available to participants.

**Post-Review Deliverables**
The Project Manager is responsible for:
*   Producing the Action Plan following the Review. This plan is prepared by the [[project_engineer_pem_gate_review_responsibilities|Project Engineer]].
*   Producing the Risk Mitigation Plan following the Review. This plan is prepared by the Project Manager.
*   Producing the Report to the [[pem_steering_committee_roles|PEM Steering Committee]].

**Action Tracking**
The Project Manager is responsible for:
*   Tracking actions resulting from the approved Report to ensure their timely completion. The expediting of these actions is performed by the [[project_engineer_pem_gate_review_responsibilities|Project Engineer]].

**Planning and Organization**
*   Inviting participants, from both within and outside the project team.
*   Expediting review preparation with Discipline Leads and Department Managers.
*   Ensuring all documentation required for the review is available.

**Follow-up Actions**
The Project Manager is responsible for:
*   Producing the Action Plan following the Review.
*   Producing the Risk Mitigation Plan following the Review. The Risk Mitigation Plan is prepared by the Project Manager.
*   Producing the Report to the PEM Steering Committee.
*   Tracking actions resulting from the approved Report.
