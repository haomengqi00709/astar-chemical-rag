# Template Horizontal Centrifugal Pump Datasheet Structure

The Template Horizontal Centrifugal Pump Datasheet (Document ID: [[template_horizontal_centrifugal_pump_datasheet_administration]]) is structured to capture comprehensive information for horizontal centrifugal pumps. The document utilizes a columnar format, with column numbers ranging from 1.0 to 24.0 to organize data efficiently.

Key fields and their usage within the datasheet include:

*   **Tag No.:** A unique identifier for the specific pump unit.
*   **Location:** Specifies the physical installation location of the pump within the plant.
*   **Quantity:** This field allows for specifying the number of units required, differentiating between:
    *   **Operating:** The number of pumps actively in service.
    *   **Installed Spare:** The number of spare pumps installed and ready for immediate use.
*   **Process Conditions:** This section details the operational parameters and can be specified as:
    *   **DESIGN PER UNIT:** Parameters for the intended design operation of a single unit.
    *   **ALTERNATE PER UNIT:** Parameters for alternative or transient operating conditions for a single unit.
*   **Fluid Description:** A textual description of the fluid being handled by the pump.
*   **Solids Type:** If the fluid contains solids, this field describes their nature.

This structured approach ensures that all necessary data points are consistently captured for procurement, engineering, and operational purposes. For specific process parameters, refer to [[horizontal_centrifugal_pump_process_design_conditions]].

The datasheet is presented on a single sheet, identified as "Sheet1". Key identification fields include a "Tag No." for unique equipment identification and a "Location" field to specify the installation site.
