# Project Instrument Manuals (8-MAN-XXXX)

Project Instrument Manuals (8-MAN-XXXX) compile essential documentation for the operation and maintenance of instrumentation.

**For Field Instruments:**
Project Instrument Manuals – Field Instruments **will contain** as a minimum:
*   Table of Contents.
*   [[8-dst-xxxx_instrument_specification_sheets]].
*   [[8-cal-xxxx_instrument_sizing_calculations]].
*   [[8-lst-0002_instrument_index]].
*   Instrument Vendor Manuals (Operation and Maintenance).

**Preparation:**
*   **Prepared by:** Field Instrument Engineer (FIE)

Field Instrument Manuals will be as per project requirements. The Instrumentation Department will co-ordinate with the FIE to ensure consistency is maintained with respect to all project manuals. Project binders **will be provided**. The FIE **shall** prepare one hard copy of the manual and an equivalent electronic version on CD. Xerox department **shall** compile additional manuals as required.

**For Instrument Bulk Material:**
Project Instrument Manuals – Instrument Bulk Material **will contain** as a minimum:
*   Table of Contents.
*   [[8-dst-xxxx_instrument_specification_sheets]].
*   Instrument Bulk Material Purchase Orders.
*   Instrument Bulk Material Vendor Manuals (Operation and Maintenance).

**Preparation:**
*   **Prepared by:** Detail Design Engineer (DDE)

Instrument Bulk Material Manuals **shall** be as per project requirements. The Instrumentation Department **shall** co-ordinate with the DDE to ensure consistency is maintained with respect to all project manuals. Project binders **shall** be provided to the Detail Instrument Engineer.
