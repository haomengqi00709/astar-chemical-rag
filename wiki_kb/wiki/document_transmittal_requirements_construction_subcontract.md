# Document Transmittal Requirements for Construction Subcontractors

All documents delivered to Aker Kvaerner Chemetics by the Construction Subcontractor **must** be accompanied by a Transmittal.

**Transmittal Content**
The Transmittal **must** contain the following information in tabular form:
*   Subcontract Number
*   Document File Name
*   Document Number
*   Document Title
*   Document Revision Number
*   Document Status

**Electronic Transmittals**
For documents delivered electronically, the Transmittal **must** be in the form of a Microsoft Excel file. This Transmittal file **must** be named “Transmittal”.

For general document transmittal requirements, refer to [[document_transmittal_requirements]].
