# Instrument Types and Application Scope for 0-QDS-7802

This page specifies the types of instruments to which the Quality Data Sheet 0-QDS-7802 template applies. This template is designed to standardize quality assurance requirements for a range of "Type 2 Instruments" used in Chemetics applications.

**Applicable Instrument Types:**
The 0-QDS-7802 template is applicable to the following instrument categories:
*   Pressure / Flow Switches
*   Pressure Safety Relief Valves
*   Magnetic Flow Meters
*   Regulators
*   Control Dampers
*   Chlorine Duct Monitors
*   Temperature RTDs (Cells)
*   On / Off Valves
*   ClO2 / H2 / SO2 Analyzers
*   Transmitters
