# Belt Filter Package Mechanical and Installation Requirements

This page outlines the mechanical and installation requirements for the Template Belt Filter Package, as specified in Document ID **4-PDS-XXXX-R1**. These requirements aim to facilitate efficient installation and define the scope of vendor-supplied components.

**Installation Requirements:**
*   The unit **shall** be skidded as much as possible to facilitate installation. This requirement aims to minimize on-site assembly and streamline the installation process.

**Vendor Scope Definition:**
*   The Vendor **shall** clearly indicate which piping, controls, and instrumentation are included in the supplied package.
*   The Vendor **shall** clearly indicate which piping, controls, and instrumentation are excluded from the supplied package.

This clear delineation of scope is essential for project planning, procurement, and ensuring all necessary components are accounted for. For related information on equipment installation and mechanical design, refer to [[equipment_erection_0_spc_6x94|Equipment Erection]], [[electrical_installation_specification|Electrical Installation Specification]], [[instrument_installation_specification|Instrument Installation Specification]], and [[aodd_pump_mechanical_design_requirements|AODD Pump Mechanical Design Requirements]].

**Vendor Scope Clarification:**
*   The vendor is required to indicate which piping, controls, and instrumentation are included in the supplied packages.
*   Conversely, the vendor must also indicate which piping, controls, and instrumentation are excluded from the supplied packages.
