# Bolting Specification (5-SPC-0002)

This document, identified as 5-SPC-0002, provides the comprehensive specification for bolting requirements within piping and layout designs.

The General section of this specification is **only required** when metric bolting is specified.

For all ASME flanges, metric bolt sizes **shall** be used. Detailed metric bolt sizes for ASME flanges are provided in:
