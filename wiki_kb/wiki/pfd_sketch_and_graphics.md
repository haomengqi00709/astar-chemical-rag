# PFD Sketch and Graphics

The creation of [[pfd_overview|Process Flow Diagrams (PFDs)]] involves distinct stages of sketching and graphic production, each contributing to the final visual representation of the process.

**PFD Sketch:**
The PFD sketch is an initial representation prepared by the Process department. It will contain the following elements, as applicable:
*   Equipment shape with the standard equipment number.
*   Process line connectivity.
*   Process stream numbers.
*   Utility stream numbers.

Sources for PFD sketches can include standard templates, proposal flow diagrams, previous project PFDs, or hand sketches.

**PFD Graphics:**
PFD graphics are the refined visual components that are eventually merged with stream data to form the complete PFD. These graphics are produced by the Design department, based on the PFD sketch.

PFD graphics will contain the following elements, as applicable:
*   Equipment shape with the standard equipment number.
*   Process and utility line connectivity.
*   Process stream numbers.
*   Utility stream numbers.

**Templates:**
*   Standard Form 1-PFD-0002: [Template: Equipment Shape] is used as a reference for PFD Graphics.

For details on the overall PFD development process, refer to [[pfd_development_process]]. For specific drawing standards and conventions, see [[pfd_drawing_standards]].
