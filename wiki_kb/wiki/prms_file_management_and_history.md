# PRMS File Management and Document History

Effective file management and historical record-keeping are essential for the Project Resource Management System (PRMS).

**Workbook Storage and Access:**
*   During project execution, all PRMS workbooks **should** be kept in a consistent location on the P:\ drive. This practice facilitates the easy collection of manpower requirement forecasts across all projects and allows these forecasts to be fed into a company-wide manpower level management system.
*   The last PRMS update **shall** be located in the directory `p:\00\0admin\3planning\progress\current`.
*   Previous updates of the PRMS **should** be stored in `p:\00\0admin\3planning\progress\archives` or deleted as appropriate, following company retention policies.

**Hard Copy Requirements:**
*   Hard copies of the "Totals," "Est-budget," "S-curve," "Tune up," and "EMF" worksheets **must** be kept as part of the project's permanent records.

**Document History:**
*   A name change conversion for this document was implemented in 2005.
*   No new revision number was used to mark the 2005 name change.
*   Consequently, changes related to the 2005 name change have not been specifically marked within the document.
