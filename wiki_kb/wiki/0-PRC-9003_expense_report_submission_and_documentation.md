# Expense Report Submission and Documentation (0-PRC-9003)

All travel or other business expenses to be reimbursed **must** be listed on an Expense Report. This report **shall** be similar to the template appended to this procedure.

**Completing the Expense Report**
*   Expenses **must** be entered against the date they were actually incurred.
*   Expenses **must** be entered in the currency of expenditure as shown on the receipts.
*   The exchange rate to Canadian Dollars **must** be clearly shown on the Expense Report.
*   The Expense Report **must** be totalled in Canadian Dollars.

**Required Documentation**
All expenses to be reimbursed **must** be supported by itemised receipts. Often, supporting receipts will require both a register receipt and a credit card slip.

Expenses for which no receipts are available **must** be described in detail on the Expense Report. Reimbursement for expenses without receipts will be granted as an exception, not as a rule.

**Submission Requirements**
The employee **must** sign the completed Expense Report and submit it to the Finance Department. The Expense Report **must** be submitted with the following attachments:
*   All itemised receipts.
*   The authorised [[travel_authorization_form_details_0_frm_9002|Travel Request Form]] (0-PRC-9002 Travel Authorisation).
*   All ticket stubs.
*   Any unused tickets that are to be refunded.
