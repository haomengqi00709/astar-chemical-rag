# Paper Document Publishing Process

Paper publishing is one of the two authorized methods for creating unalterable records of project documents at Aker Kvaerner Chemetics. This method involves physical printing, manual signing, and subsequent digitization.

### Process Steps
1.  **Document Printing**: Documents are printed on paper.
2.  **Manual Signing**: Authorized personnel **must** affix their signatures to the printed documents using blue ink. The use of blue ink is a mandatory requirement to distinguish original signatures from photocopies.
3.  **Scanning to PDF**: After signing, the paper documents **shall** be scanned into Adobe Portable Document Format (PDF). This step digitizes the physically signed record.
4.  **Electronic Storage**: The scanned PDF documents **shall** be stored in the project electronic file. It is a requirement that these scanned PDFs are placed in the same folder as their native format versions. The overall structure for the project electronic file is defined in [[document_control_1_prc_0003]].
5.  **Physical Storage**: The original signed paper document **shall** be stored in the project paper file. This ensures a physical archival record. The structure for the project paper file is also defined in [[document_control_1_prc_0003]].

### Integration with Document Control
Upon completion of the paper publishing process and any necessary checking and approval (as outlined in 0-PRC-7004, see [[document_approval_and_revision_process]]), the responsible Discipline Lead **must** advise Document Control. Document Control will then update the project Document Control Database, which is managed under [[control_of_project_documents_0_prc_0006]].

This method ensures that even documents requiring physical signatures are ultimately integrated into the digital document management system for ease of access and control, while maintaining a secure physical archive.

For an overview of both publishing methods, refer to [[document_publishing_methods]].

### Document Storage
Scanned PDF documents (from Paper Publishing) will be stored in the same folder as the native format version.
