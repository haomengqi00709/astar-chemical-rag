# Project Use of Standard Documents (Modified)

When a draft standard is to be used on a project, or where a standard document requires modification to meet specific contractual requirements, the project team **shall** implement the necessary changes following a defined procedure. This ensures that project-specific adaptations are controlled and documented.

### Procedure for Modified Use
1.  **Authoring Changes:** The project team **shall** author the necessary changes to the standard document.
2.  **Commentary Removal:** The project team **shall** remove any commentary from the standard document.
3.  **Document Numbering:** The project team **shall** replace the prefix "Standard" with the project number, adhering to [[0-PRC-0002_document_numbering]] conventions.
4.  **Handling Deleted Sections:** If any sections of the standard are deleted during modification, the section number and title **must** be retained. The text within these sections **must** be replaced with the words "Not Used". This preserves the original structure and makes modifications clear.
5.  **Project Revision Marking:** The document **must** be marked as **Rev A or Rev 1** for the project.
6.  **Status Indication:** The appropriate status **shall** be shown, followed by **"(MS-Rx)"**, where "x" represents the revision of the originating standard document. This indicates that the document is a modified standard (MS) derived from a specific standard revision (Rx).
7.  **Revision Log:** The revision entries of the originating standard **shall** be removed from the project document's revision log.
8.  **Flagging Changes:** Changes from the originating standard **must** be flagged within the project document. This allows for easy identification of project-specific modifications.
9.  **Publishing:** The document **must** be published in accordance with [[0-PRC-0005_publishing_of_project_documents]].
10. **Approval:**
    *   Procedures and templates **must** be checked and approved by the personnel assigned in Section 3 of the original 0-PRC-0001 procedure (referring to the [[standard_document_roles_and_responsibilities|roles and responsibilities]] for standard documents).
    *   Other documents in work areas 1 through 9 **must** be checked and approved by the applicable Chief Engineer.

### Draft Standards as Modified Standards
By definition, draft standards are considered modified standards (MS). Therefore, any revision marks present in a draft standard **shall** be carried into the project copy when it is used as a modified document.
