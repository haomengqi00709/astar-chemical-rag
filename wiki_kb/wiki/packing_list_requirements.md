# Packing List Documentation Requirements

Accurate and detailed packing lists are essential for all shipments.

**Packing List Content:**
*   The Vendor **must** provide a separate packing list for each package.
*   The Vendor **must** follow the line item numbering and equipment descriptions exactly as shown on the Aker Kvaerner Chemetics [[purchase_order_overview|purchase order]].
*   If the Aker Kvaerner Chemetics purchase order is less detailed, the Vendor’s more detailed list **must** be used.
*   General line item descriptions such as “one lot assembly nuts and bolts” are not acceptable on packing lists.
*   The packing list **must** detail the number and unit type of each individual item.

**Packing Slip Placement:**
*   The Vendor **must** attach the packing slip to the outside of each crate under a protective metal plate.
*   A duplicate packing slip, enclosed in a waterproof package clearly marked “Packing Slip”, **must** be placed inside the crate.
*   On large items, the packing slip **must** be located in a position that will permit easy access by a person standing at ground level.

These requirements ensure proper documentation for [[packaging_marine_transportation_0_spc_5005]], customs clearance, and inventory management upon receipt.
