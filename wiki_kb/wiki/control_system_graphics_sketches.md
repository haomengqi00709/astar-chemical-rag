# Control System Graphics Sketches

**Control System Graphics Sketches** serve as preliminary visual guidelines for the development of DCS display screens, aiding DCS programmers in creating the final graphical interfaces.

**Typical Document Number:** No typical document number
**Usage:** Design

**Purpose:**
Control system graphics sketches **SHOW** general DCS display screen layouts. They are examples used as a guideline for DCS programmers. These sketches help to establish the initial look and feel for the [[control_system_graphics]].
