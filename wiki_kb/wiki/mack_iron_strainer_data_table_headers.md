# Mack Iron Strainer Data Table Headers

This page defines the headers used in the Mack Iron Strainer Data table, which provides detailed specifications for various Saramet strainer sizes. This table is referenced in the [[1-CAL-7842-R1_final_strainer_calculation_document_details]] and is a key source for strainer design parameters.

The Mack Iron Strainer Data table is structured with the following primary headers:

*   **Casing:** This section contains data related to the strainer casing.
*   **Filter:** This section contains data related to the strainer filter (basket).
*   **Filter Area:** This section details various filter area calculations.
*   **In / Out:** This section likely pertains to inlet and outlet dimensions or flow characteristics.
*   **Annular:** This section provides data related to annular areas.
*   **Ratio:** This section includes various ratio calculations.

**Detailed Column Headers:**
The table further breaks down these primary headers into specific columns:

*   **Line Size:** Nominal pipe size.
*   **ID:** Internal Diameter.
*   **A:** Dimension A.
*   **B(ID):** Internal Diameter B.
*   **C (ID):** Internal Diameter C.
*   **D(ID):** Internal Diameter D.
*   **H (OD):** External Diameter H.
*   **Q:** Dimension Q.
*   **R (OD):** External Diameter R.
*   **O (OD):** External Diameter O.
*   **P:** Dimension P.
*   **Base:** Base Filter Area.
*   **Lateral:** Lateral Filter Area.
*   **L/B:** Length to Breadth Ratio.
*   **Total:** Total Filter Area.
*   **Pipe area:** Area of the pipe.
*   **Ratio:** A calculated ratio.
*   **Flow:** Flow rate.
*   **Annular area:** Annular area.

Additional sub-headers for specific calculations or ratios include:
*   **A/ID**
*   **B/ID**
*   **C/ID**
*   **THK** (Thickness)
*   **1.0**
*   **2.0**
*   **1/2**
*   **area**
*   **pipe**
*   **E**
*   **OD**
*   **D/H**

The [[mack_iron_strainer_data_table_units]] page provides the units corresponding to these headers. A summary of the data contained within this table can be found on the [[mack_iron_strainer_data_table_summary]] page.
