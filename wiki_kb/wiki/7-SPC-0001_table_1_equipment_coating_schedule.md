# 7-SPC-0001 Table 1: Equipment Coating Schedule

This page describes the content of Table 1 from `7-SPC-0001 Protective Coating Specification`. This table lists the specific equipment items that **must** be coated, along with the corresponding paint system to be applied.

The table serves as a direct reference for the application of protective coatings, linking individual equipment pieces to the appropriate paint system defined in [[7-SPC-0001_paint_systems_and_temperature_ratings]]. Adherence to this schedule is mandatory to ensure all components receive the specified corrosion protection.
