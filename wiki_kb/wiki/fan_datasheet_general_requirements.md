# Fan Datasheet General Requirements

This page details the general mandatory fields and specifications required for completing the [[fan_datasheet_administration|Fan Datasheet Template]] (4-DST-XXXX-R0). Adherence to these requirements ensures comprehensive and consistent documentation for all fan equipment.

**Mandatory Fields**
The following fields **must** be completed for each fan:
*   **Tag No.**: This is a required field for unique equipment identification. Refer to [[equipment_tag_numbering]] for guidelines.
*   **Location**: This is a required field, specifying the physical installation location of the fan. Refer to [[equipment_location_specification]] for details.
*   **Quantity**: This is a required field, indicating the total number of units. Refer to [[equipment_quantity_specification]] for guidelines.
*   **Operating Quantity**: This is a required field, specifying the number of units actively in operation.
*   **Installed Spare Quantity**: This is a required field, indicating the number of spare units installed.
*   **Equipment Type**: This is a required field, classifying the type of fan. Refer to [[equipment_type_classification]] for available types.
*   **Equipment Operation**: This is a required field, describing the operational mode or function of the fan. Refer to [[equipment_operation_modes]] for common operational descriptions.
