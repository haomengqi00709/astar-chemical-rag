# 9-LST-0723 Lighting System Installation Field Check List

The 9-LST-0723 Lighting System Installation Field Check List is a specific document used during the [[9-PRC-0004_electrical_field_checkout_documentation|Electrical Field Checkout Procedure (9-PRC-0004)]] to verify the correct installation of the lighting system. This checklist ensures that all lighting fixtures, wiring, and controls are installed according to engineering specifications and drawings.
