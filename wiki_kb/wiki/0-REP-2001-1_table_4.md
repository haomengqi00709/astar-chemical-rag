# Monthly Progress Report Reimbursable Project Costs Table

The table 0-REP-2001-1_table_4 is an integral part of the [[0-rep-2001_monthly_progress_report_format|Monthly Progress Report]] for reimbursable projects. It provides a detailed breakdown of costs, the format of which depends on the specific contract pricing structure. This includes engineering expenditures based on actuals, budget, and estimates calculated at an average rate of $[xxx]/hr. All values **must** be presented in CAD.
