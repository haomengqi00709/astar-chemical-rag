# Chiller/Refrigeration Unit Component Types

The Chiller/Refrigeration Unit, as specified in datasheet [[4-PDS-XXXX-R1_template_chiller_refrigeration_unit_datasheet_administration]], comprises several key components, each with specific type requirements. These details are crucial for understanding the unit's mechanical configuration and operational principles.

The datasheet includes fields for specifying the "Type" of the following components:
*   **Compressor:** Includes fields for "Stages" and "Seal Type". As per [[chiller_refrigeration_unit_general_equipment_specifications]], the compressor **shall** be a screw type with a sliding vane for capacity control from 0 to 100%.
*   **Evaporator**
*   **Condenser**
*   **Absorber**
*   **Concentrator (Generator)**
*   **Recuperator (Heat Exchanger)**
*   **Purge Pump**

These component types are selected based on the overall [[chiller_refrigeration_unit_process_design_conditions]] and the chosen refrigeration cycle (mechanical or absorption). For material specifications of these components, refer to [[chiller_refrigeration_unit_materials_of_construction]].

For the **Compressor**, in addition to its type and stages, the **Seal Type** is also specified.
