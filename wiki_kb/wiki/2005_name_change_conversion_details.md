# 2005 Name Change Conversion Details

In 2005, a name change conversion was implemented across project documentation. It is important to note that no new revision number was used for this 2005 name change, and the changes were not explicitly marked within the documents.

For further information on document revision history, refer to [[aker_kvaerner_chemetics_name_change_history]].
