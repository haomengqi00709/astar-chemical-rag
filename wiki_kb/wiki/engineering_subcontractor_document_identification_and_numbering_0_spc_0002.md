# Engineering Subcontractor Document Identification and Numbering (0-SPC-0002)

Engineering Subcontractors are required to adhere to strict guidelines for document identification and numbering as specified in 0-SPC-0002. This ensures proper integration and traceability within the overall project documentation system.

**Document Numbering and Titles**
Subcontractors **must** accurately insert the following identification details into all documents:
*   Aker Kvaerner document numbers.
*   Aker Kvaerner document titles.
*   Owner document numbers.

All document numbering **must** be in strict accordance with the procedures outlined in [[0-PRC-0002_document_numbering]].

**File Naming Conventions**
Subcontractors are responsible for assigning document file names. These file names **must** comply with the conventions detailed in [[0-PRC-0003_file_structure]].

**Prohibition of Proprietary Systems**
To maintain consistency and avoid conflicts within the project's document management system, Subcontractors **shall not** use any proprietary document numbering systems or proprietary file numbering systems for deliverables to Aker Kvaerner.

Further details on general vendor document identification can be found in [[vendor_document_identification_and_numbering]].
