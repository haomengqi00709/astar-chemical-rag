# Converter Instrumentation Installation

This page details the mandatory requirements for the installation of all instrumentation and related components within and around the converter.

**Mandatory Instrumentation Installation Requirements:**
*   **General Instrumentation:** All instrumentation must be installed.
*   **Thermowells:** All Thermowells must be installed.
*   **Isolation Valves:** Isolation valves must be installed on sample/pressure points.
