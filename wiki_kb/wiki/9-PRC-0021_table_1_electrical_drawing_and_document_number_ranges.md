# Electrical Drawing and Document Number Ranges (9-PRC-0021 Table 1)

[[9-PRC-0021_electrical_numbering_and_identification_procedure|Procedure 9-PRC-0021]] references an internal table, likely designated as Table 1, which specifies the available ranges for electrical drawing and document numbers on a project-specific basis. This table is crucial for the systematic allocation and management of document identifiers.

The table outlines distinct number ranges for various types of electrical documentation, including but not limited to:
*   Detail Drawings (DTL)
*   General Arrangement Drawings (GAD)
*   Lists (LST)
*   Schematics (SCM)
*   Manuals (MAN)
*   Calculations (CAL)

These ranges ensure that each document type is assigned a unique and identifiable series of numbers, facilitating efficient organization and retrieval throughout the project lifecycle. Any changes to these allocated ranges **shall** require the authorization of the Aker Kvaerner Chemetics Electrical department manager, as detailed in [[electrical_department_document_control]].
