# Gasket Colour Code Chart

The Gasket Colour Code Chart provides a standardized system for identifying different [[gasket_specification|gasket materials]] based on their color. This chart is a critical reference document used during [[flange_inspection_requirements_5_prc_0007|flange inspection]] to visually confirm that the correct gasket material has been installed in accordance with project specifications. Proper gasket selection and installation are essential for maintaining the integrity and leak-tightness of flanged connections in piping systems.
