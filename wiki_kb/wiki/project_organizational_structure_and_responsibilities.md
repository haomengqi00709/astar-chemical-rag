# Project Organizational Structure and Responsibilities

The project organizational structure defines key roles, reporting lines, and specific responsibilities to ensure efficient project execution.

**Key Roles and Reporting:**
*   **Project Manager:** Holds overall responsibility for the Project. The Project Manager **shall** approve all project expenditures and maintain control of all Owner correspondence files.
*   **Project Engineer:** Manages the engineering execution of the project through the various [[discipline_lead_and_approver_roles|Discipline Leads]]. The Project Engineer and other key project personnel **shall** report directly to the Project Manager.
*   **Quality Assurance Auditor:** If assigned to the project, the Quality Assurance Auditor **shall** functionally report directly to the President.
*   **Project Buyer:** Responsible for all communications between Aker Kvaerner and Vendors. The Project Buyer **shall** maintain complete Vendor correspondence files.
*   **Discipline Leads:** Responsible for managing engineering Subcontractor communications and Statutory Authority communications. The Discipline Lead **shall** maintain the Statutory Authority correspondence files.

Key project personnel and their specific assignments are detailed in the Project Responsibility form.

**Specific Responsibilities:**
*   The Project Buyer is responsible for expediting Vendor documents from Vendors.
*   The Project Engineer is responsible for expediting the internal review and return of Vendor documents.

For further details on the formal assignment of project roles, refer to [[assignment_of_project_responsibilities]].

**Project Engineer Responsibilities:**
*   The Project Engineer will manage the engineering execution through the Discipline Leads.

**Reporting Lines:**
*   The Project Engineer and other key project personnel will report to the Project Manager.
*   The Quality Assurance Auditor, if assigned, will functionally report directly to the President.
*   Key project personnel are listed in [[0-LST-2004_project_responsibility]].
