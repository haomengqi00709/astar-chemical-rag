# Procurement Document Roles and Responsibilities

This page details the preparation, checking, and approval responsibilities for various documents and steps within the procurement process, as outlined in the Control System Design and Specification Procedure ([[control_system_design_procedure_overview]]).

**Requisition for Quotation (REQ):**
*   **Prepared by:** DDE
*   **Approved by:** n/a

**Vendor Document Requirements (VDR):**
*   **Prepared by:** DDE
*   **Checked by:** Quality Assurance
*   **Approved by:** DDE

**Quality Documentation Sheets (QDS):**
*   **Prepared by:** DDE
*   **Approved by:** Quality Assurance

**Request for Quotation (RFQ):**
*   **Prepared by:** Procurement

**Order Value Approval Responsibilities:**
*   **Order value < CAD 10 K:**
    *   **Prepared by:** DDE
    *   **Approved by:** DDE
*   **Order value < CAD 200 K:**
    *   **Prepared by:** DDE
    *   **Approved by:** Project Engineer
*   **Order value > CAD 200 K:**
    *   **Prepared by:** DDE
    *   **Approved by:** Project Engineer

**Final Cost Tabulation:**
*   **Prepared by:** DDE
*   **Approved by:** Project Manager

**Commercial Bid Tabulation:**
*   **Prepared by:** Procurement
*   **Approved by:** Manager of Procurement

**Financial Evaluation:**
*   **Prepared by:** Finance

**Technical Bid Tabulation:**
*   **Prepared by:** DDE
*   **Checked by:** Other disciplines
*   **Approved by:** DDE

**Risk Assessment Responsibilities:**
*   **Value < CAD 10K:**
    *   **Prepared by:** n/a
*   **Value < CAD 200K:**
    *   **Prepared by:** DDE
    *   **Approved by:** Project Engineer
*   **Value > CAD 200K:**
    *   **Prepared by:** DDE
    *   **Approved by:** Project Manager

**Final Review and Vendor Selection:**
*   **Prepared by:** Instrument
*   **Approved by:** Project Engineer, Project Manager, Procurement

**Requisition for Purchase Order (REQ):**
*   **Prepared by:** DDE
*   **Approved by:** n/a

**Purchase Order:**
*   **Prepared by:** Procurement
*   **Checked by:** Project Engineer
*   **Approved by:** Project Manager

**Vendor Document Review:**
*   **Approved by:** DDE
