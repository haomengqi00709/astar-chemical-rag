# 0-PRC-2005 Project Responsibility Document

The document titled "0-PRC-2005 — Procedure" serves to delineate the main project execution responsibilities among key personnel within the firm.

**Purpose and Scope**
The primary intent of the responsibility list detailed within 0-PRC-2005 is to clearly define the roles and responsibilities between key project personnel. It is important to note that this list is not intended to be the absolute limit of responsibilities for any individual. Personnel are expected to undertake additional duties as required for the successful execution of the project.

**Assignment of Key Personnel**
The assignment of critical roles such as [[project_manager_and_engineer_assignment|Project Manager]], [[discipline_lead_and_approver_roles|Discipline Lead]], and [[commissioning_manager_assignment|Commissioning Manager]] is conducted in accordance with the guidelines specified in [[assignment_of_project_responsibilities|0-PRC-2001: Assignment of Project Responsibilities]].

In instances where a Project Engineer is not formally assigned to a project, the [[project_manager_and_engineer_assignment|Project Manager]] **shall** undertake the responsibilities typically associated with the Project Engineer role. This ensures continuity and comprehensive coverage of all necessary project functions, maintaining project momentum and accountability.
