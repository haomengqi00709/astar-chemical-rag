# Instrument Documentation - General

A comprehensive set of instrument drawings and documentation **will** be prepared for the design package and included as part of the installation contract, typically within installation work packs.

**Types of Instrument Drawings and Documents:**
*   [[instrument_index_and_tagging|Instrument Index]]
*   I/O Schedules
*   [[instrument_calibration_and_testing|Instrument Specification Sheets]]
*   Instrument location plans
*   Instrument loop drawings
*   Cable block diagrams
*   Instrument cable schedule
*   Termination drawings/schedules
*   Instrument installation detail drawings
*   Installation Specification
*   Instrument Test Specification

**Drawing Content and Layout:**
*   Equipment location drawings **will** clearly show the location of every instrument, local panel, junction box, and other equipment items.
*   Cable ladders and conduits, including all underground and in-slab cable runs, **shall** be shown on drawings.
*   Minor aboveground runs of conduit, ladder, or strut to single items of equipment may be site run and may be omitted from layout drawings.

**As-Built Documentation:**
Documents such as Instrument Loop Diagrams, Instrument Specification Sheets, Instrument Index, and Instrument I/O List **shall** be revised to "as-built" status to reflect the final installation for future operations, maintenance, and project expansion. This is further detailed in [[roles_and_documentation_management|Roles and Documentation Management]].

**Supplier Documentation:**
All necessary documentation from suppliers, including item catalogues, technical servicing documentation, and full and correct circuit diagrams, **will** be provided in correct, clear, and concise English. There **will** be no exceptions to the standard and type of documentation supplied. Documentation **will** be provided in an acceptable form for quality reproduction, with one copy in an approved electronic format (PDF if direct electronic format is unavailable).
