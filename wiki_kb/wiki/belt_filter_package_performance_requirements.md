# Belt Filter Package Performance Requirements

This page outlines the performance requirements for the Template Belt Filter Package, as specified in Document ID **4-PDS-XXXX-R1**. These requirements define the expected characteristics of the processed material at the unit's outlet.

The datasheet includes a dedicated section titled "PERFORMANCE REQUIREMENTS", which specifically addresses the "Product Outlet".

**Product Outlet Specifications:**
*   **Product Outlet Stream Composition:** Measured in %w/w (weight by weight)
*   **Product Outlet Temperature:** Measured in oC (degrees Celsius)
*   **Product Outlet Flow:** Measured in lb/hr (pounds per hour)

These specifications ensure that the belt filter unit achieves the desired separation and processing efficiency for the final product. For examples of performance results for other equipment, refer to [[dry_tower_performance_results|Dry Tower Performance Results]].
