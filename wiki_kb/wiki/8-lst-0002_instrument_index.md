# Instrument Index (8-LST-0002)

The Instrument Index (8-LST-0002) is a critical document that provides a comprehensive listing and cross-referencing of all instrumentation within a project.

**Content Requirements:**
The Instrument Index (8-LST-0002) **shall** contain, as a minimum:
*   Instrument Tag Number
*   Client Instrument Tag Number
*   Description of Service
*   Instrument Description
*   Physical Location (DCS, Field, MCC etc:)
*   Supplier
*   Manufacturer
*   P&ID Reference
*   Loop Diagram Reference
*   Installation Detail Reference
*   Instrument Location Drawing Reference
*   PO Number
*   I/O Type
*   Device Comments

**Document Preparation and Approval:**
*   **Prepared by:** Field Instrument Engineer (FIE)
*   **Approved by:** Field Instrument Engineer (FIE)

**Development and Maintenance:**
The FIE will commence the Instrument Index after Stage III [[p_id_development_and_approval_1_prc_0003_instrumentation]] have been issued "Approved for Design". Where required by contract, the FIE will use the client's instrument tag number as the key field in the Instrument Index. If client instrument numbers are not required, the standard instrument number will be the key field.

The FIE is responsible for all Instrument Tag updates to the Instrument Index and for managing dual numbering requirements as per the project contract documents. Commencement of the Instrument Index database **should** be delayed as late as possible to ensure maximum accuracy from approved P&IDs.

The FIE will cross-reference client Instrument Tag/Loop numbers to standard numbers as per Stage III P&ID’s. The FIE is responsible for maintaining this cross-reference for the duration of the project.

**Updates and Coordination:**
The FIE will provide the Instrument Engineer with a marked-up Instrument Index complete with [[8-dtl-xxxx_instrument_installation_details]] cross-referencing. The Instrument Engineer will then co-ordinate with the FIE to update the Instrument Index accordingly, and the updated Instrument Index will be issued to the Detail Design Engineer (DDE).
