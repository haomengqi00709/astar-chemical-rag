# Instrument Installation Details (8-DTL-XXXX)

The [[instrument_installation_details_8_dtl_xxxx]] (8-DTL-XXXX) drawings provide detailed instructions and requirements for the physical installation of field instruments.

**Content Requirements:**
The Instrument Installation Details (8-DTL-XXXX) **shall** contain:
*   Representation of field instrument installation requirements.
*   Bill of materials for bulk installation materials.
*   Reference to the site paint specification where applicable.
*   Reference to the Site conditions.
*   Installation connections for piping and instrumentation.

**Document Preparation and Approval:**
*   **Prepared by:** Detail Design Engineer (DDE)
*   **Approved by:** Detail Design Engineer (DDE)

**Development and Application:**
The DDE will provide Instrument Installation Details, which will be created for the various types of field instruments being provided on the project. Specific Instrument Tag numbers **are not** to be detailed on these drawings; instead, specific Instrument Tag numbers will be referenced in the [[8-lst-0002_instrument_index]] to the applicable Installation Detail.

The DDE will provide the Instrument Engineer with a marked-up Instrument Index complete with Installation Detail cross-referencing. The Instrument Engineer will co-ordinate with the Field Instrument Engineer (FIE) to update the Instrument Index accordingly, and the updated Instrument Index will be issued to the DDE.

Typical Instrument Installation details will be provided to the DDE as examples, but ultimate responsibility for the project Installation Details will remain with the DDE.

**Handling Variances in Piping Connections:**
Where the FIE is unable to provide instruments that mate directly to the sizes as listed in the [[5-lst-0011_standard_ansi_piping_connections_for_instrumentation]], the DDE will provide the necessary adapters on the Instrument Installation Details to complete the installation.
