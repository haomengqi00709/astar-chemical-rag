# Project Document Control and Archiving

Effective document control and archiving are fundamental to the quality management of the project. All documentation prepared for the Project **must** adhere to established procedures for numbering, style, approval, publishing, and storage.

**Document Preparation and Approval**
All project documentation **must** comply with:
*   [[0-prc-0002_document_numbering]]: Document Numbering standards.
*   [[0_prc_0004_document_style_and_format]]: Style of Textual Documents.

Before any project document is issued for use by others, it **must** be thoroughly checked and approved. Furthermore, all project documents **must** be published to create an unalterable record prior to their issuance. The processes for checking and approval of documents are governed by:
*   [[publishing_project_documents]]: Publishing of Project Documents.
*   [[0-prc-7004_checking_and_approval_of_design]]: Checking and Approval of Design.

**Document Storage and Accessibility**
The project maintains a dual storage system for documents:
*   **Electronic Files:** A copy of all published documents, affixed with encrypted digital signatures, is stored in an electronic file. The latest working version of all project documents in their native format is also stored electronically. The structure of these electronic files **must** conform to [[file_structure]]. This electronic file is accessible to all project team members and is archived daily to prevent data loss.
*   **Paper Files:** Any paper documents received from Vendors or generated through the publishing process are retained in a physical paper file. These paper documents are also scanned to facilitate their inclusion in the electronic file system.

**Document Logging, Issuance, and Distribution**
Published documents are systematically logged, issued, and distributed in accordance with [[0-prc-0006_control_of_project_documents]]. This ensures that all stakeholders receive the correct and most current versions of documents.

**Final Project Archives**
The final project archives are comprehensive and consist of:
*   Electronic files of all published documents.
*   The latest version of all documents in their native electronic format.
*   All data files associated with the 3-D models.

These final project archives are transferred to compact discs. Copies of the final project archives are provided to the Owner, fulfilling the requirements specified in the Contract.

All documentation prepared for the Project complies with 0-PRC-0002: Document Numbering and 0-PRC-0004: Style of Textual Documents.

**Document Storage and Accessibility**
A copy of all published documents with encrypted digital signatures affixed is stored in an electronic file. The latest working version of all project documents in native format is also stored in an electronic file. The electronic file structure is maintained in accordance with 0-PRC-0003: File Structure.

Any paper documents received from Vendors or created through publishing are retained in a paper file. These paper documents are scanned to allow filing in the electronic file. The electronic file is accessible to all project team members and is archived daily to prevent loss of data.

Published documents are logged, issued and distributed in accordance with 0-PRC-0006: Control of Project Documentation.

**Final Project Archives**
Final project archives also consist of all data files associated with the 3-D models. These archives are transferred to compact discs, and copies are provided to the Owner in accordance with the requirements of the Contract.
