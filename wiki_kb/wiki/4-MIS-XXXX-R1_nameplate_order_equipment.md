# Nameplate Order (Equipment) Document Details

The document with [[0-PRC-0002_document_numbering|document ID]] **4-MIS-XXXX-R1**, titled "Nameplate Order — Unknown", outlines the requirements for ordering equipment nameplates. This document defines four distinct nameplate sheet types, each with specific characteristics for identifying equipment.

**Nameplate Types**
The four defined nameplate sheet types are:
*   Type 1: Proprietary Large
*   Type 2: Proprietary Small
*   Type 3: Large
*   Type 4: Small

**Common Mandatory Fields**
All four nameplate types **must** include the following fields:
*   "From:"
*   "Send to:"
*   "P.O. Number:" (referencing [[0-SPC-5001_purchase_order_overview|Purchase Order]])
*   Company Name: "CHEMETICS A Division of [[aker_kvaerner_chemetics_company_details|Aker Kvaerner Canada Inc.]] Vancouver, Canada"
*   "EQUIP/ITEM No." (for [[plant_equipment_identification_4_prc_0001|equipment identification]])
*   "DESCRIPTION"
*   "PROJECT No." (referencing [[project_number_definition|Project Number]])
*   "FAB. DATE"

**Type-Specific Details**

*   **Nameplate Type 1 (Proprietary Large):** This type **must** include a "Project Number:" field and is explicitly labeled "PROPRIETARY EQUIPMENT".
*   **Nameplate Type 2 (Proprietary Small):** This type **must** include a "Proj. Number:" field and is explicitly labeled "PROPRIETARY EQUIPMENT".
*   **Nameplate Type 3 (Large):** This type **must** include a "Project Number:" field but **does not** include the "PROPRIETARY EQUIPMENT" label.
*   **Nameplate Type 4 (Small):** This type **must** include a "Proj. Number:" field but **does not** include the "PROPRIETARY EQUIPMENT" label.

**Field Repetition**
All four nameplate sheet types (Type 1, Type 2, Type 3, Type 4) **must** include three instances of the "EQUIP/ITEM No.", "DESCRIPTION", "PROJECT No.", and "FAB. DATE" fields.

The four defined nameplate sheet types are:
*   **Type 1 - Proprietary Large**
*   **Type 2 - Proprietary Small**
*   **Type 3 - Large**
*   **Type 4 - Small**

All nameplate types share several common fields:
*   "From:"
*   "Send to:"
*   "P.O. Number:"
*   The company name "CHEMETICS A Division of Aker Kvaerner Canada Inc. Vancouver, Canada"
*   "EQUIP/ITEM No."
*   "DESCRIPTION"
*   "PROJECT No."
*   "FAB. DATE"

For all four nameplate types, the "EQUIP/ITEM No.", "DESCRIPTION", "PROJECT No.", and "FAB. DATE" fields appear three times.

Specific characteristics for each type include:
*   **Type 1 (Proprietary Large):** Includes a "Project Number:" field and the label "PROPRIETARY EQUIPMENT".
*   **Type 2 (Proprietary Small):** Includes a "Proj. Number:" field and the label "PROPRIETARY EQUIPMENT".
*   **Type 3 (Large):** Includes a "Project Number:" field. It does not include the label "PROPRIETARY EQUIPMENT".
*   **Type 4 (Small):** Includes a "Proj. Number:" field. It does not include the label "PROPRIETARY EQUIPMENT".
