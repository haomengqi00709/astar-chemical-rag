# Pump Calculation Documentation and Storage

Proper documentation and storage of pump calculations are essential for project traceability, auditing, and future reference. This page outlines the requirements for electronic and hard copy storage, file naming, and content.

### Electronic Storage

All calculations **will** be stored electronically in the project directory.
*   **Location:** `4-Equipment/Cal/Hydraulic`.
*   **Pipe-Flo Table Files:** Where [[pipe_specifications|pipe specifications]] or fluid data tables are not found within Pipe-Flo’s standard list and **must** be created, ensure that the table files (`*.ptbl`, `*.ftbl`) are saved in the project directory along with the calculation.
*   **Table File Location:** `4-Equipment/Cal/Hydraulic/Tables`.
*   **File Sharing:** These files may be copied to departmental directories for use on other projects.
*   **Text File Export:** A text file **will** be created using ‘Save Text File’ in Pipe-Flo.
*   **Excel Import:** The `*.txt` file **will** be imported into Microsoft Excel.
*   **Spreadsheet Content:**
    *   A calculation summary **must** be added to the spreadsheet.
    *   A title block **must** be added to the spreadsheet.
    *   A revision block **must** be added to the spreadsheet.
*   **Updating Files:** The electronic file used for preliminary calculations **will** be updated for final calculations. Preliminary calculations do not need to be saved to an ‘old’ directory.

### Hard Copy Storage

Hard copies of calculations **will** be stored in a binder.
*   **Binder Location:** The hard copy **will** be placed in a calculation binder.
*   **Tab Requirements:** The calculation binder **must** have a tab for the pump tag.
*   **Multiple Pumps:** If a system includes more than one pump, the hard copy calculation **will** be placed with the primary pump. Notes **must** be placed with other pumps directing to the primary pump where the calculation is filed.
*   **Printed Output:**
    *   The spreadsheet file can be printed and added to the binder. Spreadsheet output is easier to check than other Pipe-Flo output.
    *   The Pipe-Flo graphical output **must** be added to the binder.
*   **Supporting Documents:** Copies of the [[4-PDS-XXXX-R2_template_pump_datasheet_administration|PDS]] and [[4-DST-XXXX-R2_template_pump_datasheet_administration|DST]] **must** be kept for each pump in the binder, for each stage of the sizing process.

### Usage of Calculation Files

Pump calculation files **will** be used for:
*   Determining control valve pressure drop requirements.
*   Setting restriction orifice plate sizing criteria.

### Electronic Storage
Where pipe specifications or fluid data tables are not found within Pipe-Flo’s standard list and must be created, ensure that the table files (*.ptbl *.ftbl ) are saved in the project directory along with the calculation.
These files are located in the directory `4-Equipment /Cal/Hydraulic/Tables`.
Files **may** be copied to departmental directories for use on other projects.

The electronic file used for preliminary calculations **will** be updated for final calculations. Preliminary calculations **do not** need to be saved to an ‘old’ directory.
