# Coatings Erection (0-SPC-6X97)

This page describes the requirements for Coatings Erection as outlined in document 0-SPC-6X97. The Subcontractor **must** adhere to these specifications for all coating application activities related to the construction subcontract. This includes, but is not limited to, protective coatings for corrosion resistance and aesthetic finishes.

Refer to [[0-SUB-6_construction_subcontract_scope_of_works]] for the specific application of this specification within the overall project scope.
