# Published Document Logging Requirements

Upon the publication of any project document, it is a mandatory requirement that the document be logged into the [[document_control_database]]. This logging process ensures that a comprehensive and accessible record of all published documents is maintained.

The following essential information must be accurately logged for each published document:
*   Document Title
*   Document Number
*   Document Revision Number
*   Date Published
*   Document Status (as defined in [[document_status_definitions]])

Following the logging of a published document, a notification containing identical information as listed above (Section 4.1 in the source document) must be issued promptly to the Project Engineer and all relevant Discipline Leads. This ensures that key project personnel are immediately informed of new publications and their associated details.
