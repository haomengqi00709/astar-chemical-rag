# Project Reporting Requirements (0-PRC-2012)

This procedure, identified as 0-PRC-2012, establishes the requirements for formal project reporting. The scope of reporting encompasses both internal stakeholders and external clients.

The primary objectives of these reporting activities are to:
*   Communicate the current status and progress of the project.
*   Provide a comprehensive record of project progress over time.
*   Document project costs.
*   Identify and track project risks.

The procedure differentiates between external reporting, primarily for the client, and internal reporting, which supports project management and senior management reviews. Adherence to these guidelines ensures consistent and accurate communication regarding project performance.
