# Procurement and Vendor Documentation Procedures

This page outlines the procedures and responsibilities for documents related to enquiry, purchase, and vendor document review within the control system project lifecycle.

**Typical Document Number:** No typical document number
**Usage:** Procurement

**Related Procedures:**
Documents for enquiry, order, and vendor document review are covered in the following listed procedures:
*   [[0-PRC-0007_review_of_vendor_documentation|0-PRC-0007: Review of Vendor Documentation]]
*   [[0-PRC-5003_bid_evaluation_and_approval|0-PRC-5003: Bid Evaluation and Approval]]
*   [[0-PRC-5002_request_for_quotation_or_purchase_order|0-PRC-5002: Request for Quotation or Purchase Order]]
*   [[0-PRC-5005_issue_of_request_for_quotation_or_purchase_order|0-PRC-5005: Issue of Request for Quotation or Purchase Order]]

Section 4 of the main procedure (8-PRC-0004-R1) provides a table detailing instrument and electrical subcontractors’ responsibility for these documents.

**Key Procurement Documents and Responsibilities:**

*   **Requisition for Quotation (REQ):**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: n/a
*   **Vendor Document Requirements (VDR):**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Checked By: Quality Assurance
    *   Approved By: [[roles_and_responsibilities_control_system|DDE]]
*   **Quality Documentation Sheets (QDS):**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: Quality Assurance
*   **Request for Quotation (RFQ):**
    *   Prepared By: Procurement

**Order Value-Based Responsibilities:**

*   **Order value < CAD 10 K:**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: [[roles_and_responsibilities_control_system|DDE]]
*   **Order value < CAD 200 K:**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: Project Engineer
*   **Order value > CAD 200 K:**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: Project Engineer

**Bid Evaluation and Selection Documents:**

*   **Final Cost Tabulation:**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: Project Manager
*   **Commercial Bid Tabulation:**
    *   Prepared By: Procurement
    *   Approved By: Manager of Procurement
*   **Financial Evaluation:**
    *   Prepared By: Finance
*   **Technical Bid Tabulation:**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Checked By: Other disciplines
    *   Approved By: [[roles_and_responsibilities_control_system|DDE]]
*   **Risk Assessment - Value < CAD 10K:**
    *   Prepared By: n/a
*   **Risk Assessment - Value < CAD 200K:**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: Project Engineer
*   **Risk Assessment - Value > CAD 200K:**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: Project Manager
*   **Final Review and Vendor Selection:**
    *   Prepared By: Instrument
    *   Approved By: Project Engineer, Project Manager, Procurement

**Purchase Order Documents:**

*   **Requisition for Purchase Order (REQ):**
    *   Prepared By: [[roles_and_responsibilities_control_system|DDE]]
    *   Approved By: n/a
*   **Purchase Order:**
    *   Prepared By: Procurement
    *   Checked By: Project Engineer
    *   Approved By: Project Manager
*   **Vendor Document Review:**
    *   Approved By: [[roles_and_responsibilities_control_system|DDE]]
