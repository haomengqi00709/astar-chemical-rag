# Project Procurement Planning (0-LST-5001)

The Project Manager is responsible for developing the preliminary procurement strategy, documented in 0-LST-5001: Procurement Plan.

**0-LST-5001: Procurement Plan Development:**
The Project Manager **must** develop 0-LST-5001: [Template] Procurement Plan. This document serves as a preliminary listing of all Purchase Orders (POs) to be placed for the project.

The scope of each Purchase Order **must** be clearly stated by reference to:
*   Aker Kvaerner Chemetics standard equipment identification numbers.
*   Bulk material types or classes.
*   Instrument types.

**Potential Bidders:**
The Procurement Plan **must** identify potential bidders, which include:
*   Any nominated suppliers specified in the Contract.
*   Suppliers whose information was used in the project estimate.

**Purchasing and Logistics Database (0-DAT-5001):**
Procurement **must** enter preliminary information from the Procurement Plan into [[procurement_and_logistics_strategy|0-DAT-5001: Purchasing and Logistics Database]].

Data available in SQL: 0-LST-5001, 0-DAT-5001
