# Check-Valve Installation

Check-valve installation refers to the process of correctly integrating a check-valve into a piping system to prevent backflow. Proper installation is essential for the safety and efficiency of the system. Key aspects include ensuring the valve is installed with the correct flow direction, confirming accessibility for maintenance, and verifying that the valve type and tag match design specifications as part of [[strainers_check_valves_steam_traps_inspection_5_prc_0007|mechanical checkout]].
