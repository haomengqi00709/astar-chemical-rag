# Construction Subcontract Compensation Event Quotations

Subcontractor quotations for compensation events **must** be presented with a clear breakdown of costs. These quotations **shall** include:
*   The Prices for Direct Work Items.
*   The Prices for Indirect Work Items.
*   The Prices for Insurance, Financing, and Security, applied at the same rates as provided on the [[0-LST-6X11_construction_subcontract_price_list]].
*   The Price for Overhead and Profit, determined using the rates specified in the [[0-SUB-6X00_construction_subcontract_agreement]].

**Approval Conditions for Indirect Work and Labour:**
*   A quotation for [[construction_subcontract_indirect_work_costs|Indirect Work Items]] **will only be approved** if the compensation event is demonstrably shown to cause an extension of time on the site for the claimed items.
*   A quotation for Indirect Labour **will only be approved** if the person for whom costs are claimed is explicitly identified on the [[0-LST-6X14_construction_subcontract_indirect_labour_schedule]].
*   The costs of personnel not identified on the [[0-LST-6X14_construction_subcontract_indirect_labour_schedule]] **will be assumed** to be included within the [[construction_subcontract_overhead_costs|Overhead]] component of the subcontract.
