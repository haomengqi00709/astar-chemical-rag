# Vendor Document Transmittal Requirements

All documents delivered to Aker Kvaerner Chemetics **must** be accompanied by a formal Transmittal. This ensures proper tracking, identification, and processing of incoming vendor documentation.

**Transmittal Content:**
The Transmittal **must** contain the following information in a clear, tabular format:
*   The [[purchase_order_commercial_and_contractual_terms|Purchase Order Number]].
*   The Vendor’s document titles.
*   The Vendor’s document numbers.
*   The Vendor’s document [[document_control_revisions|revision number]].
*   The Vendor’s document [[document_status_definitions|status]].

**Email Transmittal Specifics:**
*   In cases where documents are delivered via e-mail, the Transmittal **shall** be provided as a Microsoft Word or Excel file.
*   This file **must** be named "Transmittal".

Adherence to these transmittal requirements is essential for efficient [[incoming_vendor_document_processing|processing of incoming vendor documents]] and maintaining accurate document control records.
