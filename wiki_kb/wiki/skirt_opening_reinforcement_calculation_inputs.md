# Skirt Opening Reinforcement Calculation Inputs

The calculation for skirt opening reinforcement, as detailed in [[4-cal-0024_skirt_opening_reinforcement_calculation_administration]], requires precise input variables to accurately determine the necessary structural properties and reinforcement dimensions. These inputs are typically derived from the detailed [[equipment_data_sheets_4_dst_xxxx]] and [[design_standards_and_reference_materials]] relevant to the vessel and its components. They collectively define the critical geometric parameters of both the vessel skirt and the proposed reinforcing ring.

The mandatory input variables for this calculation are:
*   **Skirt Outside Diameter (OD):** Expressed in millimeters (mm). This value represents the overall external diameter of the cylindrical vessel skirt.
*   **Skirt Thickness (t):** Expressed in millimeters (mm). This refers to the nominal wall thickness of the skirt itself.
*   **Skirt Opening Inside Width (w):** Expressed in millimeters (mm). This defines the internal dimension of the opening that requires reinforcement.
*   **Reinforcing Ring Thickness (tr):** Expressed in millimeters (mm). This is the specified thickness of the material intended for the reinforcing ring.
*   **Reinforcing Ring Width (wr):** Expressed in millimeters (mm). This denotes the width of the reinforcing ring, measured perpendicular to the skirt surface.

The accuracy of these input variables is paramount for ensuring the reliability and safety of the reinforcement design. These values directly impact the subsequent calculations of the moment of inertia for both the removed skirt section and the proposed reinforcing elements, which are further elaborated in the [[skirt_opening_reinforcement_calculation_methodology]]. Proper documentation and verification of these inputs are essential steps in the overall [[process_calculations]] workflow.

### Key Input Variables
The following are the primary input variables required for the calculation:
*   **Skirt Outside Diameter (OD):** in mm
*   **Skirt Thickness (t):** in mm
*   **Skirt Opening Inside Width (w):** in mm
*   **Reinforcing Ring Thickness (tr):** in mm
*   **Reinforcing Ring Width (wr):** in mm
