# Instrument Types and Application Scope for 0-QDS-7801

Quality Data Sheet (QDS) 0-QDS-7801, "Type 1 Instr.", is a template designed for a range of common instrumentation and related bulk materials. This document specifies the quality requirements for the procurement and manufacturing of these items.

**Application of this Template**
This template is applicable to, but not limited to, the following types of instruments and materials:
*   pH / Conductivity / ORP Transmitters
*   Insertion Magnetic Flowmeters
*   Temperature Elements
*   Thermowells
*   Manometers
*   Speed / Level Switches
*   Oxygen Analyzers
*   Field Junction boxes
*   Instrument Cables / Accessories / Bulk Materials

**Mandatory Template Instruction**
The row detailing the application of this Template **must** be deleted before publishing the document for project use. This ensures that the final project-specific document is concise and directly relevant to the procured items.

For general information on instrument numbering and identification, refer to [[plant_instrument_numbering_8_prc_0001]]. Further details on the use of QDS templates can be found in [[0-QDS-7XXX_template_quality_data_sheet]].
