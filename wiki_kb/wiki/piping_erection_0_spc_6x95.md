# Piping Erection (0-SPC-6X95)

This page describes the requirements for Piping Erection as outlined in document 0-SPC-6X95. The Subcontractor **must** adhere to these specifications for all piping installation and erection activities related to the construction subcontract. This includes, but is not limited to, pipe routing, welding, fitting, and testing of piping systems.

Refer to [[0-SUB-6_construction_subcontract_scope_of_works]] for the specific application of this specification within the overall project scope.
