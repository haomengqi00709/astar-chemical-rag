# Specification 0-SPC-6 Administration

Specification 0-SPC-6 is a foundational document that outlines the scope of work for subcontractors, specifically detailing tasks related to the [Major Work Division]. This specification serves as a critical reference for ensuring that all subcontracted work aligns with the firm's standards and project requirements.

**Purpose and Scope**
The primary purpose of Specification 0-SPC-6 is to describe the [Major Work Division] work that **shall** be executed by the Subcontractor. It sets the framework for the quality and compliance expected from all parties involved in the construction and erection phases of a project.
