# Construction Subcontract Document Numbering and History

### Document Numbering
Construction Subcontract Agreements are assigned an identification number following the format 6X00, where 'X' represents a sequential series (1, 2, 3, etc.). An example identification number is 98C12300-0-SUB-6100-RA. This numbering convention adheres to the guidelines set forth in 0-PRC-0002: Document Numbering.

### Historical Name Changes
A name change has been implemented for Aker Kvaerner Chemetics. It is important to note that no new revision number was used to reflect this name change, and the changes themselves were not explicitly marked within the documents.

Similarly, a 2005 name change conversion was also implemented. For this conversion, no new revision number was used, and the changes were not marked.
