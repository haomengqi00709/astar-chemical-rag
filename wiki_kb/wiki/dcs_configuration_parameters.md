# Process Control - DCS Configuration Parameters (8-LST-0104)

The **Process Control - DCS Configuration Parameters** (8-LST-0104) document provides the essential information required by the DCS programmer to configure the basic control and monitoring elements of the control system.

**Document ID:** 8-LST-0104
**Usage:** Design
**Data available in SQL:** 8-LST-0104

**Content Requirements:**
This document **WILL CONTAIN** the basic information needed for the DCS programmer to configure the basic control and monitoring elements of the control system. It **MUST** contain, as a minimum:
*   PID reference.
*   Loop number.
*   Loop description.
*   Type of control or monitoring element.
*   Scale of measurement.
*   Units of measurement for instruments.
*   Control action.
*   Fail position of valves and instruments.
*   Output.
*   Comments.
