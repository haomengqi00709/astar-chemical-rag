# Design Software and Modeling Tools

Aker Kvaerner Chemetics will maximise the use of PDMS (Plant Design Management System) for design work on this project.

**PDMS Usage:**
PDMS will be utilized for the production of various design deliverables, including:
*   Equipment layout drawings
*   Civil criteria general arrangements drawings
*   Structural general arrangements drawings
*   Piping general arrangements drawings
*   Piping isometrics drawings
*   Cable tray layout criteria drawings
*   Instrument location general arrangements drawings

The design model within PDMS will be structured such that each plant module constitutes a separate PDMS "area" to facilitate organization and management.

**PDS Plant Model Deliverable:**
A PDS (Plant Design System) plant model is a contractual deliverable. This PDS model will be derived through a translation process from the primary PDMS model. This translation **shall** be performed only once, at the conclusion of the project.

**Other Drawing and Document Tools:**
*   Other drawings not produced in PDMS will be drafted using AutoCAD.
*   The Contract explicitly requires drawings to be presented using MicroStation. Therefore, drawings produced in AutoCAD will be translated to MicroStation once only, at the conclusion of the project.
*   Textual documents and lists will be prepared using Microsoft Office products. The Microsoft Office format is acceptable to the Owner.

**PDMS Model Structure:**
The design model will be set-up so that each plant module is a separate PDMS “area”.

**PDS Plant Model Deliverable:**
One of the Contract deliverables is a PDS plant model. This PDS plant model will be derived by translating from the PDMS model. The PDS model translation will only be done once, at the conclusion of the project.

**Other Design Tools and Deliverables:**
*   Other drawings will be drafted using AutoCAD.
*   The Contract requires drawings to be presented using MicroStation. Drawings will be translated from AutoCAD to MicroStation once only, at the conclusion of the project.
*   Textual documents and lists will be prepared using Microsoft Office products, a format acceptable to the Owner.
