# Metal Ductwork Fabrication Specification Overview (5-SPC-0010)

This specification (5-SPC-0010) defines Aker Kvaerner Chemetics’ requirements for the fabrication of metal ductwork. It is used in combination with details provided on the specific ductwork drawings.

All work and materials **must** be in accordance with the codes or standards listed within this specification. This includes adherence to the ASME Boiler and Pressure Vessel Code and ASTM standards.

This specification is written primarily for the ASME code. If required to work to codes from other jurisdictions, this specification **must** be modified to reflect the particular code. The Vendor's supply **must** strictly conform to all Aker Kvaerner Chemetics drawings and specifications.
