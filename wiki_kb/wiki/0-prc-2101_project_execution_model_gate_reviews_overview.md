# Project Execution Model (PEM) Control Level Milestone Gate Reviews Overview

This procedure (Document ID: 0-PRC-2101) outlines the methodology for conducting, recording, and reporting Project Execution Model (PEM) Control Level Milestone Gate Reviews.

**Applicability**
This procedure applies to projects that meet either of the following criteria:
*   Projects larger than CAD $3,000,000 in value.
*   Projects requiring more than 3,500 home-office hours.

**Purpose**
The primary goal of this procedure is to ensure systematic review and control at critical project milestones, fostering adherence to project objectives and facilitating continuous improvement.
