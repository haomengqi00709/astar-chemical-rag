# Project Document and Data File Storage Structure

Procedure 0-PRC-0003 outlines the comprehensive structure for the storage of all project documentation and data files. This includes published documents, documents in native format, and work-in-progress files. Documentation can be stored as either physical paper files or within computer directory structures, typically on a P Drive.

The foundational level of organization for project documentation is based on major work subjects. These subjects categorize all project-related activities and deliverables. The defined major work subjects are:
*   **0: Administration**
*   **1: Process Technology**
*   **2: Civil and Site Preparation**
*   **3: Structural and Buildings**
*   **4: Equipment**
*   **5: Piping and Layout**
*   **6: Insulation**
*   **7: Coatings**
*   **8: Instrumentation and Control**
*   **9: Electrical**

For a detailed breakdown of the specific sub-folders and their contents within each major work subject, refer to the dedicated wiki pages such as [[0_administration_document_structure]], [[1_process_technology_document_structure]], [[2_civil_and_site_preparation_document_structure]], [[3_structural_and_buildings_document_structure]], [[4_equipment_document_structure]], [[5_piping_and_layout_document_structure]], [[6_insulation_document_structure]], [[7_coatings_document_structure]], [[8_instrumentation_and_control_document_structure]], and [[9_electrical_document_structure]].

Only the "0 Administration" major work subject is further subdivided into a series of minor work divisions to manage administrative documentation effectively. These minor divisions include:
*   **0-0: Documentation**
*   **0-1: Proposals**
*   **0-2: Project Administration**
*   **0-3: Planning**
*   **0-4: Cost Control**
*   **0-5: Procurement**
*   **0-6: Construction**
*   **0-7: Quality Assurance**
*   **0-8: HSE (Health, Safety & Environment)**
*   **0-9: Corporate**

Further categorization is applied for each relevant document type within both major and minor work divisions. Other file categories will be established as necessary to accommodate project requirements.

**General Principles for File Structure:**
*   When creating a new project or proposal directory, folders and sub-folders **shall** be set up in accordance with the attached listing (as detailed in the specific document structure pages).
*   The file structure is designed to mirror the document number itself, facilitating easy location of documents.
*   The type and subject of the document will normally allow it to be located efficiently within the established directory structure.
*   Top-level directory names **should** be set up with no spaces.

**Revision History:**
*   **Revision 12:** Combined "0-8 Engineering Administration" with "0-2 Project Administration." The "0-8" division was subsequently changed to "HSE." Additionally, "0-9 Corporate" was added.
*   **2005 Name Change Conversion:** This conversion was implemented without using a new revision number or marking the changes.

**Special Folders:**
*   **ALIB folder:** This folder is exclusively for use by CAE (Computer-Aided Engineering) personnel.
*   **USER folder:** This folder contains "XXX" for project personnel scrap storage, intended for temporary or personal work files.

Document numbering conventions, which inform the file structure, are defined in [[document_number_format_and_components]].

The first level of division for project documentation is arranged by major work subject. Further categorisation is made for each relevant document type within major and minor work divisions. Other file categories will be established where necessary.

When creating a new project or proposal directory, folders and sub-folders will be set up in accordance with the attached listing. The file structure mirrors the document number itself. Printing of file paths on documents is redundant. The type and subject of the document will normally allow it to be located within the directory structure. Top-level directory names should be set up with no spaces.
