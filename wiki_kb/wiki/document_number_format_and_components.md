# Document Number Format and Components

The standard document number format is a structured identifier used across all project and standard documents. An example of this format is `98C12300-4-DTL-7801-5-R2`. Each segment of this format conveys specific information about the document.

The document number is composed of the following mandatory components:

1.  **Project Number**: `98C12300`
    *   This is an eight-digit proposal or project number. For standard documents not associated with a specific project, "Standard" shall be used as the Project Number.
    *   Refer to [[project_number_definition]] for more details.

2.  **Major Work Division**: `4`
    *   This is a one-digit code that designates the primary engineering discipline or work area the document pertains to.
    *   Refer to [[major_work_division_codes]] for a complete list of codes and their designations.

3.  **Document Type Code**: `DTL`
    *   This is a three-digit code that identifies the specific type of document (e.g., drawing, specification, list).
    *   Refer to [[document_type_codes]] for a comprehensive list of codes and their meanings.

4.  **Identification Number**: `7801`
    *   This number uniquely identifies the subject matter of the document within its Major Work Division and Document Type. Its structure varies based on the type of item or area it relates to.
    *   Refer to [[identification_number_rules]] for detailed guidelines on assigning identification numbers.

5.  **Sheet / Section Number**: `5`
    *   This number is used when a document is broken into multiple sheets or sections.
    *   Refer to [[sheet_section_number_guidelines]] for usage criteria.

6.  **Revision Number**: `R2`
    *   This alphanumeric code indicates the current revision status of the document. The numbering scheme differs for standard documents and project documentation.
    *   Refer to [[revision_numbering_rules]] for detailed revision numbering protocols.

This structured format ensures clarity, traceability, and efficient management of all technical documentation.
