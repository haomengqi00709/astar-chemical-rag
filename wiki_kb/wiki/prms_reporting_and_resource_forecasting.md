# PRMS Reporting and Resource Forecasting

The Project Resource Management System (PRMS) is a vital tool for generating standard management reports and facilitating resource forecasting. These outputs are crucial for project oversight and strategic planning.

**Resource Forecasting:**
The PRMS includes a dedicated worksheet for resource forecasting.
*   This worksheet stores a time-based record of total actual hours.
*   At the time of each update, the total forecast hours for each department are transferred into this resource forecasting worksheet.
*   "Hours to go" are manually distributed over the remaining duration of the project, taking into consideration the requirements outlined in the [[0-dat-3001_project_schedule|0-DAT-3001 Project Schedule]].
*   Details from the resource forecasting worksheet are made available to the Project Engineer, Discipline Leads, and department heads. These details assist significantly in resource planning and project assignments.
*   A record of the first distribution of resource requirements (the budget distribution) is kept on the resource forecast worksheet, serving as a reference point.

**Standard System Management Reports:**
Standard system management reports are generally prepared immediately following each PRMS update. These reports are for inclusion in the Project Manager’s reports, in accordance with [[project_instructions_0_prc_2002|0-PRC-2002: Project Instructions]].

The following reports are generated:

1.  **Project Design Resources Report:**
    *   This report is a copy of the design total worksheet.
    *   It shows, for each department: Budget Hours, Earned Hours, Actual Hours, Productivity, Progress, Forecast Hours, Hours to Go, Assumed Productivity, Actual Productivity, and Quantity Change.

2.  **Project Overhead Resources Report:**
    *   This report is a copy of the overhead worksheet.
    *   It shows, for each department: Budget Hours, Actual Hours, Productivity, Forecast Hours, and Progress.

3.  **Project S-Curves Report:**
    *   This report displays four curves on a single chart for project totals:
        *   Budget distribution of hours
        *   Forecast earned hours
        *   Actual hours to date
        *   Earned hours to date

**Report Printing and Distribution:**
*   After each update, the "Totals," "Budget," "admin," and "S-curve" worksheets **should** be printed.
*   These printed worksheets **should** then be appended to the Project Manager’s monthly report.
*   The EMF (Earned Manpower Forecast) worksheet **should** be used to inform department managers about project manpower requirements. When printing for manpower requirements, only the forecast from the current date onwards **shall** be included; past forecasts **shall not** be printed.
