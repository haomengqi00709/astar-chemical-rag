# Template VOC-SCR Package Vendor Information and Documentation Requirements

This page specifies the critical information and documentation that vendors **must** provide as part of their quotation for the Template VOC-SCR Package, as outlined in document 4-PDS-XXXX-R1. These requirements ensure that Chemetics receives sufficient technical detail to evaluate proposals thoroughly and to integrate the vendor's package into the overall project design.

**Required Vendor Information:**

Vendors **must** advise on the following key aspects of their catalyst system:
*   Catalyst volumes: The total volume of catalyst required for both the VOC and NOx sections.
*   Estimated catalyst life: The projected operational lifespan of the catalyst under specified conditions.

**Required Vendor Documentation with Quote:**

In addition to the technical information, vendors **must** include the following documentation with their quotation:
*   A Process & Instrumentation Diagram (P&ID) for the proposed VOC-SCR package. This diagram **shall** clearly illustrate all major equipment, piping, instrumentation, and control loops. Refer to [[piping_and_instrumentation_drawings]] for P&ID standards.
*   A comprehensive description of the controls for the unit. This **shall** include a narrative of the control philosophy, key control loops, interlocks, and any proprietary control strategies.

These documentation requirements are essential for the technical evaluation of bids and for ensuring compatibility with the plant's existing systems. All vendor documentation **must** comply with the general [[vendor_document_requirements]] and [[procurement_and_vendor_documentation]] procedures.
