# Document Type Codes

The Document Type Code is a three-digit identifier that specifies the nature or category of a document within the firm's numbering system, as defined in [[document_numbering_procedure_0_prc_0002]]. This code is essential for quickly understanding the content and purpose of a document.

**Code Structure:**
The Document Type Code is a three-digit alphanumeric code. It is the third segment in the document number format, following the Major Work Division (e.g., `98C12300-4-**DTL**-7801-5-R2`).

**Designations:**
The following codes and their corresponding designations shall be used:

*   **CAL**: Calculation
*   **DAT**: Data (View of data files such as Schedules, Expediting, Document Status)
*   **DST**: Data Sheet
*   **DTL**: Detail Drawing (e.g., Equipment, Instrument Installation)
*   **GAD**: General Arrangement Drawing (e.g., Layouts)
*   **HAZ**: HazOp Record
*   **ISO**: Piping Isometric
*   **LOP**: Loop Diagram
*   **LST**: List
*   **MAN**: Manual
*   **NCR**: Non-Conformance Report (e.g., [[non_conformance_report_0_ncr_7]])
*   **OTL**: Outline Drawing
*   **PDS**: Process Data Sheet (Equipment)
*   **PFD**: Process Flow Diagram (e.g., [[pfd_overview]])
*   **PID**: Piping & Instrument Diagram (e.g., [[piping_and_instrumentation_drawings]])
*   **PKG**: Package Data Sheet
*   **POL**: Policy
*   **PRC**: Procedure
*   **PRP**: Equipment Proprietary Detail Drawing (Never issued to Owner)
*   **PSI**: Piping Specialty Item
*   **QDS**: Quality Data Sheet
*   **REL**: Inspection Release
*   **REP**: Reports
*   **REQ**: Requisition
*   **SCM**: Schematic (e.g., Motor Control, Logic, SAMA Diagram)
*   **SCR**: Support Loading Criteria
*   **SPC**: Specification
*   **SUB**: Subcontracts
*   **SUP**: Piping Support Detail
*   **TAB**: Bid Tabulation
*   **VDR**: Vendor Document Requirements
*   **VEN**: Vendor Document

**Proprietary Detail Drawings (PRP):**
The Document Type code PRP (Equipment Proprietary Detail Drawing) shall generally only be used to prevent the Owner from obtaining design details of specific equipment. An example of equipment for which PRP use is appropriate includes sodium chlorate electrolyser components. For more information, refer to [[equipment_proprietary_detail_drawing_prp]].

These codes are crucial for the accurate classification and retrieval of documents, forming an integral part of the [[document_number_format_and_components]].
