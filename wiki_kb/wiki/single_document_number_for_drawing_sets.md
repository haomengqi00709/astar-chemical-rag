# Single Document Number for Drawing Sets

The Document Numbering Procedure (0-PRC-0002) includes a provision that allows for the assignment of a single document number to a set of related drawings. This approach streamlines documentation for complex items or assemblies that require multiple views or details.

**Application:**
This provision is particularly useful for items such as the fabrication of a vessel, which may involve numerous detail drawings (e.g., general arrangement, nozzle details, internal components, welding details). Instead of assigning a unique document number to each individual drawing within the set, a single overarching document number can be used.

**Benefits:**
*   **Simplified Management:** Reduces the number of distinct document entries, simplifying tracking and retrieval.
*   **Logical Grouping:** Ensures that all drawings pertaining to a single complex item are clearly grouped under one identifier.
*   **Consistency:** Promotes a consistent approach to documenting multi-part fabrications or assemblies.

When a single document number is used for a set of drawings, individual drawings within the set may still be differentiated using the [[sheet_section_number_guidelines|Sheet / Section Number]] component of the document number, if applicable, or through internal drawing references. This ensures that while the set has a unified identifier, individual components remain distinguishable.

This flexibility in numbering supports efficient documentation practices for complex engineering deliverables, as part of the broader [[standard_document_number_index]].
