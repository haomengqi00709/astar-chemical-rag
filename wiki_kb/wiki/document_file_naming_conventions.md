# Document File Naming Conventions

Consistent and clear file naming is crucial for effective document management. Document numbering, which forms the basis for file names, is defined in [[document_number_format_and_components]] (Procedure 0-PRC-0002).

**General Document File Naming Rules:**
*   File names for documents **must** be the entire number sequence of the document, omitting the project number.
*   File names for documents **must** insert the sheet / section number if one is used.
*   An example file name adhering to these rules is `4-DTL-1035-1-R2`.
*   File names may have the document title appended, as directed by specific project job instructions.
*   For DOS-based programs that impose a file name length restriction of 8 digits, file names **must** be abbreviated as necessary.
*   The printing of file paths on documents is considered redundant and **shall** be avoided.

**Vendor-Issued Documents:**
*   File names for Vendor-issued documents **must** be identical to the assigned document number.
*   The control of Vendor Documentation, including naming and submission requirements, is further defined in [[procurement_and_vendor_documentation]] (Procedure 0-PRC-0007).

**Owner-Issued Documents:**
*   File names for Owner-issued documents **must** be identical to the Owner’s file number if applicable.
*   File names for Owner-issued documents **must** also be identical to the Owner’s document number, including the Owner’s revision number, as specifically directed by project job instructions.

**Documents Not Covered by 0-PRC-0002:**
*   File names for any documents not explicitly covered by the guidelines in [[document_number_format_and_components]] (0-PRC-0002) **must** be assigned in accordance with specific project job instructions.

*   File names for documents **must** be the entire number sequence of the document, omitting the project number.
*   File names for documents **must** insert the sheet / section number (if used).
*   An example file name is `4-DTL-1035-1-R2`.
*   File names may have the document title appended as directed by project job instructions.
*   File names for Vendor-issued documents must be identical to the assigned document number.
*   File names for Owner-issued documents must be identical to the Owner’s file number if applicable, or identical to the Owner’s document number (including the Owner’s revision number), as directed by project job instructions.
*   File names for documents not covered by 0-PRC-0002 must be assigned in accordance with project job instructions.
*   For DOS-based programs that do not allow file names longer than 8 digits, file names must be abbreviated as necessary.
