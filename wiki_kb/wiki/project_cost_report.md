# Project Cost Report

The Project Cost Report provides a detailed breakdown of project expenditures. For reimbursable projects, this report may be based on client costs and is included as an attachment to the [[0-rep-2001_monthly_progress_report_format|Monthly Progress Report]] to provide comprehensive financial transparency.
