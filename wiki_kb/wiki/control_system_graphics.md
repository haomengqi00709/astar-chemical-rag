# Control System Graphics

**Control System Graphics** refer to the displayed graphical interfaces used for process monitoring and control within the Distributed Control System (DCS).

**Typical Document Number:** No typical document number
**Usage:** Design

**Content and Design Principles:**
Control system graphics **WILL CONTAIN** displayed graphics for process monitoring and control. They **WILL BE LAID OUT** to provide a logical, efficient, and complete interface between the plant operations personnel and the Control system.

Design principles for graphics include:
*   Displayed graphics for monitoring and control details **WILL BE KEPT TO A MINIMUM** to reduce confusion.
*   Displayed graphics for monitoring and control details **WILL BE SUFFICIENT** to allow operations personnel to completely control the process as intended.
*   Graphics **SHOULD BE SIMPLE**.
*   Graphics **SHOULD BE LOGICAL**.
*   Graphics **SHOULD MINIMISE FRILLS**.
*   Graphics **SHOULD BE VISUALLY APPEALING**.
