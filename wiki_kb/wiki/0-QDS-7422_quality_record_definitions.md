# Mist Eliminator Quality Record Definitions

This page defines the abbreviations used for quality record requirements within the context of the Mist Eliminator Quality Data Sheet ([[0-QDS-7422_quality_data_sheet_administration]]). These definitions specify how documentation is to be prepared and included in the Quality Assurance Documentation Package.

**Definitions**
*   **AP (As Prepared):** This designation means that the quality record is required "As Prepared" by the Vendor. It indicates that the document should be submitted in its original prepared format.
*   **FP (Included in Quality Assurance Documentation Package):** This designation means that the quality record is "Included in Quality Assurance Documentation Package." It signifies that the document **must** be part of the comprehensive set of quality documentation submitted by the Vendor.
