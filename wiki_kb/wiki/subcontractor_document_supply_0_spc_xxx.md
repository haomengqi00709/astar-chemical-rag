# Subcontractor Document Supply (0-SPC-XXX)

This document, 0-SPC-XXX, specifies the requirements for documentation to be supplied by subcontractors for the Project. It details the types of documents, formats, submittal dates, and "hold" designations.

The Subcontractor **will** be issued Vendor Document Requirements documents as required, which describe the documentation to be supplied, provide submittal dates, and designate certain documents as “hold”. “Hold” documents require review by Aker Kvaerner Chemetics before the Subcontractor proceeds with fabrication/construction. Compliance with this specification is crucial for effective [[construction_subcontract_management_and_site_quality]] and [[project_document_control_and_archiving]].
