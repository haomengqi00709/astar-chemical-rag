# Project Scheduling and Resource Management

Project Controls plays a crucial role in establishing and managing the project schedule and resource allocation.

**Project Scheduling:**
Project Controls **must** schedule the project in accordance with 0-PRC-3002: Project Scheduling. They **must** create [[0-dat-3001_project_schedule|0-DAT-3001: Project Schedule]].
*   The initial schedule **must** be checked by the Project Manager.
*   The initial schedule **must** be approved by the Director of Projects.

**Project Resource Management System (PRMS):**
Project Controls **must** set up the Project Resource Management System (PRMS) for the project in accordance with 0-PRC-3003: Project Resource Management. They **must** create [[project_resource_management_system_0_dat_3002|0-DAT-3002: Project Resource Management System (PRMS)]].
*   The PRMS **must** be checked by the Project Manager.
*   The PRMS **must** be approved by the Director of Projects.

Progress measurement for the project is conducted within the PRMS, not on the [[project_document_list_0_lst_0001|Document List (0-LST-0001)]].
