# Document Revision Flagging and Management

Effective management and clear flagging of revisions are critical for maintaining accurate and up-to-date textual documents within Aker Kvaerner Chemetics. This ensures that all users can easily identify changes between document versions, promoting transparency and reducing errors.

**Revision Flagging Method:**
*   Revisions *must* be flagged on textual documents by placing a vertical line in the left margin. This vertical line serves as a visual indicator, highlighting all changes made between the previous and the most recently revised version of the document.

**Configuring Track Changes (Microsoft Word):**
To ensure consistent revision flagging, the following settings *must* be applied within the "Track Changes" feature, typically found under the "Tools" menu in Microsoft Word:
1.  Navigate to `Tools > Track Changes > Highlight Changes > Options`.
2.  Configure the following settings for change marking:
    *   **Inserted text:** Select "Mark: (none)" and "Colour: Auto".
    *   **Deleted text:** Select "Mark: (none)" and "Colour: Auto".
    *   **Changed formatting:** Select "Mark: (none)" and "Colour: Auto".
    *   **Changed lines:** Select "Mark: Left border" and "Colour: Auto".
3.  After setting these options, press "OK" on the "Options" dialog box. Then, ensure all relevant boxes on the subsequent "Highlight Changes" dialog box are selected, and press "OK" again. A toolbar for track changes *should* be visible for easy access, facilitating efficient revision management.

**Clearing Revision Marks:**
Once a document revision is finalized and accepted, all revision marks *must* be cleared. This is achieved by navigating to `Tools > Track Changes > Accept or Reject Changes`, then pressing "Accept All," confirming with "Yes," and finally pressing "Close." This step prepares the document for its next official version without carrying over previous revision indicators.

**Managing Track Changes for Header and Revision Log Modifications:**
*   When making modifications to the document header or the revision log, the "Track Changes" feature *must* be temporarily turned off. To do this, go to `Tools > Track Changes > Highlight Changes` and uncheck "Track changes while editing."
*   After completing the necessary modifications to the header or revision log, "Track changes while editing" *must* be reselected to resume tracking subsequent content edits. This ensures that administrative changes do not clutter the revision history of the main content.

**Document Revision Workflow:**
The standard workflow for revising an existing document is as follows:
1.  Open the existing document.
2.  Immediately save the document under its new name (if applicable) or as a new version.
3.  Accept all existing changes from previous revisions to start with a clean base.
4.  Make necessary modifications to the document header and revision log, ensuring "Track Changes" is temporarily off during this step.
5.  Turn "Track Changes" back on.
6.  Begin editing the document content, allowing all new changes to be flagged according to the configured settings.

**Revision Flagging**
Revisions will be flagged on textual documents by placing a vertical line in the left margin. The vertical line shows changes between the previous and most recent version.
Revision numbers should be included on Requisitions, Purchase Orders, and Subcontract Document Lists where commercial consequences exist from subsequent revisions.

**Track Changes Configuration**
To flag revisions, select Tools, Track Changes, Highlight Changes, Options.
For Inserted text, select "Mark: (none)" and "Colour: Auto".
For Deleted text, select "Mark: (none)" and "Colour: Auto".
For Changed formatting, select "Mark: (none)" and "Colour: Auto".
For Changed lines, select "Mark: Left border" and "Colour: Auto".
After setting revision flagging options, press OK, select all boxes on the dialog box, then press OK. There should be a toolbar for track changes.

**Managing Track Changes**
To clear revision marks, select Tools, Track Changes, Accept or Reject Changes, press Accept All, press Yes, press Close.
When modifying the header or revision log, turn change tracking off by selecting Tools, Track Changes, Highlight Changes, and unchecking "Track changes while editing". Reselect "Track changes while editing" after modifying the header or revision log.

**Document Revision Process**
When revising a document, open the existing document, save it under the new name, accept all changes, make changes to the header and revision log, then turn on track changes and begin editing.
