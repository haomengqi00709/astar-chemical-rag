# Trough Distributor Design Guidelines and Requirements

This page outlines key guidelines and mandatory requirements for the design and evaluation of trough distributors, as referenced in calculation document [[1-cal-7834-r0_trough_distributor_document_details]].

**General Guidelines**
*   **Consultation Requirement**: Users **must** consult with the Technology Manager prior to modifying parameters that are not highlighted in blue within the calculation document.
*   **Design Basis (Data Input)**: Design Basis (placeholder)
*   **Case Description (Data Input)**: Case Description (placeholder)
*   **Diagram Reference**: Please refer to the diagrams provided in the source document for a detailed description of A1, A2, and A3 dimensions.
*   **Downcomer Dimensions**: Downcomer dimensions are to be confirmed on the detailed layout drawings.

**Design Case and Flow Evaluation**
*   The design case parameters are transferred directly to the [[4-pds-7834-r0_trough_distributor_process_data_sheet]].
*   **Mandatory Evaluation**: The maximum flow case **must** be evaluated to determine that the trough will not overflow under peak operating conditions.
