# Eductor Equipment Data and Operation Types

The **Equipment Data** section of the Eductor Datasheet (4-PDS-XXXX-R1) provides general specifications and operational characteristics for the eductor, in line with [[general_equipment_requirements_specification]].

### Type of Operation
The eductor can be configured for various operations, which must be clearly indicated:
*   Pumping
*   Mixing
*   Other (specify as applicable)

### Equipment Design Limits
*   **Maximum Pressure:** The maximum design pressure for the equipment, specified in kPa(g).
*   **Maximum Temperature:** The maximum design temperature for the equipment, specified in oC.

### Quantity Information
The datasheet also includes fields for [[eductor_quantity_and_scope]]:
*   **Quantity:** Total number of eductors required.
*   **Operating quantity:** Number of eductors in continuous operation.
*   **Installed Spare quantity:** Number of eductors installed as spares.

If the eductor's operation type includes mixing, refer to [[eductor_mixing_conditions]] for specific parameters related to the mixing environment.
