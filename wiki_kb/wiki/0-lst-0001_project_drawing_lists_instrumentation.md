# Project Drawing Lists - Instrumentation (0-LST-0001)

The Project Drawing List (0-LST-0001) serves as a comprehensive record of all project drawings, specifically detailing those related to field instruments and other detail design drawings.

**Content Requirements:**
The Project Drawing List – Field Instruments (0-LST-0001) and Project Drawing list – Detail Design Drawings (0-LST-0001) **shall** contain, as a minimum:
*   Document Number
*   Document Title
*   Current Revision
*   Date of most recent issue

**Responsibilities:**

**For Field Instruments:**
*   **Prepared by:** Field Instrument Engineer (FIE)
*   **Checked by:** Project Engineer
*   **Approved by:** Project Engineer

The FIE is responsible for creating and maintaining a current project drawing list, which **must** include contract deliverables. The project document "[[0-lst-0001_equipment_list_details]]" will be provided to the FIE to form the basis of this list. The FIE will update the project drawing list and return it to the Project Engineer as required. The Project Engineer will then update and maintain the project file accordingly. The FIE **shall** update the project drawing list on a regular basis and provide it to the Project Engineer as required.

**For Detail Design Drawings:**
*   **Prepared by:** Detail Design Engineer (DDE)
*   **Checked by:** Project Engineer
*   **Approved by:** Project Engineer

The DDE is responsible for creating and maintaining a current project drawing list for Detail Design Drawings, which **must** include contract deliverables. The project document "[[0-lst-0001_equipment_list_details]]" will be updated and maintained in a current state by the DDE.
