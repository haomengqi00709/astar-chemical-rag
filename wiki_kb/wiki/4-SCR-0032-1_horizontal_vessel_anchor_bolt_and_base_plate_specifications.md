# Horizontal Vessel Anchor Bolt and Base Plate Specifications (4-SCR-0032-1)

This page details the specific dimensions, materials, and critical requirements for anchor bolts and base plates used in the support of horizontal vessels on concrete and grout foundations, as outlined in document 4-SCR-0032-1. These specifications are paramount for ensuring the structural integrity, securement, and long-term stability of the vessel against operational and environmental loads.

**Anchor Bolt and Base Plate Dimensions:**
All dimensions are specified in millimeters (mm):
*   **Anchor Bolt 'AB' Diameter:** The diameter of the primary anchor bolts.
*   **Base Plate Bolt 'AC' Diameter:** The diameter of bolts associated with the base plate.
*   **Dimension 'A' - Pad Size (Fixed End):** Pad size dimension for the fixed support end (See Note 3 in original document).
*   **Dimension 'B' - Pad Size (Fixed End):** Pad size dimension for the fixed support end (See Note 3 in original document).
*   **Dimension 'C' - Pad Size (Sliding End):** Pad size dimension for the sliding support end (See Note 3 in original document).
*   **Dimension 'D' - Pad Size (Sliding End):** Pad size dimension for the sliding support end (See Note 3 in original document).
*   **Dimension 'E1' - Bolt Position:** Specifies a bolt positioning dimension.
*   **Dimension 'E2' - Bolt Position:** Specifies another bolt positioning dimension.
*   **Dimension 'F' - Support Spacing:** The distance between the vessel's support points.
*   **Dimension 'G' - Datum Offset:** Offset from a specified datum point.
*   **Dimension 'H' - Equip. Anchor Height:** The height of the equipment anchor.
*   **Dimension 'L' - Plate Length:** Length of the base plate.
*   **Dimension 'M' - Plate Width:** Width of the base plate.
*   **Dimension 'P1' - Bolt Projection (Fixed):** Projection of the anchor bolt at the fixed end (c/w Double Nut).
*   **Dimension 'P2' - Bolt Length (Sliding):** Length of the anchor bolt at the sliding end (c/w Double Nut).
*   **Dimension 'T' - Base Plate Thickness:** Thickness of the base plate.
*   **Dimension 'Y' - Grout:** Dimension related to the grout layer beneath the base plate.

**Material Specifications:**
*   **Anchor Bolt Material:** The specific material required for the anchor bolts, selected for strength and corrosion resistance.
*   **Nut Material:** The specific material required for the nuts, compatible with the anchor bolt material.

**Mandatory Requirements:**
*   The minimum "Bolt to Edge" distance **must** be 100mm. This requirement is critical for preventing concrete spalling and ensuring adequate embedment and load transfer.

**Additional Notes:**
*   Refer to sheet 2 of the original document for the detailed anchor bolt 'AB' layout.

These specifications are integral to the [[equipment_support_criteria]] and must be strictly followed during [[anchor_bolt_installation_requirements]] and [[equipment_grouting_requirements]]. Further details on material selection can be found in [[anchor_bolt_and_nut_material]].

In addition to anchor bolt and base plate diameters, the document specifies various critical dimensions in mm:
*   **Pad Sizes:** Dimension 'A' (Fixed End), Dimension 'B' (Fixed End), Dimension 'C' (Sliding End), Dimension 'D' (Sliding End). (See Note 3 for further details).
*   **Bolt Positions:** Dimension 'E1', Dimension 'E2'.
*   **Support Geometry:** Dimension 'F' (Support Spacing), Dimension 'G' (Datum Offset), Dimension 'H' (Equip. Anchor Height).
*   **Plate Dimensions:** Dimension 'L' (Plate Length), Dimension 'M' (Plate Width), Dimension 'T' (Base Plate Thickness).
*   **Bolt Projections/Lengths:** Dimension 'P1' (Bolt Projection, Fixed, c/w Double Nut), Dimension 'P2' (Bolt Length, Sliding, c/w Double Nut).
*   **Grout:** Dimension 'Y' (Grout).

The material for nuts is also specified. A minimum "Bolt to Edge" distance of 100mm is required. For the detailed anchor bolt 'AB' layout, refer to sheet 2 of the document.
