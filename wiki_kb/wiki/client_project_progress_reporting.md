# Client Project Progress Reporting

The project progress report, which **shall** be issued to the client, **must** adhere to the format specified in [[0-rep-2001_monthly_progress_report_format]]. This format serves as a baseline, though it can be modified to align with specific client reporting requirements as stipulated by contract. For smaller projects, the progress report may be simplified, but **shall** retain all major headings.

Each monthly progress report will be published as a new sheet under the same document number, ensuring continuity and historical tracking. The precise timing for the issuance of these progress reports is defined within the [[project_coordination_0_prc_2004]] procedure.

The compilation of the client progress report requires input from various project functions:
*   **Safety Report:** Input **must** be provided by the HSE Manager, Construction Lead, or Commissioning Lead.
*   **Discipline Reports:** Contributions from individual disciplines are required, as detailed in [[discipline_reporting]].
*   **Procurement Report:** A narrative and report **must** be supplied by the Procurement/Logistic Lead.
*   **Quality Management Report:** A narrative and report **must** be supplied by the Quality Manager.
*   **Progress Curves:** Narrative and data **must** be provided by Project Controls.
*   **Updated Schedule:** Narrative and data **must** be provided by Project Controls.
*   **Cost and Manhour Reports:** Input **must** be provided by Project Controls and Project Accounting.
*   **Accounts Receivables Report:** Input **must** be provided by Project Accounting.
*   **Change Order Log and PCN Log:** Input **must** be provided by Project Controls.

This comprehensive approach ensures that the client receives a holistic and accurate overview of the project's status, performance, and any significant developments.
