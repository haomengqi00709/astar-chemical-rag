# Fan Datasheet Drive System Specifications

This page details the mandatory specifications for the fan's drive system, as required by the [[fan_datasheet_administration|Fan Datasheet Template]] (4-DST-XXXX-R0). These specifications are essential for ensuring compatibility, performance, and reliable operation of the fan.

**Mandatory Drive System Requirements**
The following information regarding the drive system **must** be provided:
*   **Drive System**: General description or type of the drive system. Refer to [[fan_drive_system_specification]].
*   **Drive System Supply by**: The entity responsible for supplying the drive system. Refer to [[drive_system_vendor_supply]].
*   **Drive System Mount by**: The entity responsible for mounting the drive system. Refer to [[drive_system_installation_responsibility]].
*   **Drive System Specification**: Detailed technical specifications for the drive system components. Refer to [[drive_system_technical_specification]].
*   **Drive System Size**: The size or capacity of the drive system. Refer to [[drive_system_sizing]].
