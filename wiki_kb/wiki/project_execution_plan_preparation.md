# Project Execution Plan Preparation

The Project Execution Plan (PEP) is a critical document that guides the project's implementation. The Project Manager **must** prepare the 0-PRC-2003: Project Execution Plan.

**Preparation and Approval Process:**
*   The Project Execution Plan **must** utilize the standard template available on the Q Drive.
*   The prepared plan **must** be checked by the Manager of Project Controls.
*   Final approval for the Project Execution Plan **must** be granted by the Director of Projects.

**Scope Definition and Documentation:**
The Project Execution Plan refers to specific documents that define the scope of supply by Aker Kvaerner Chemetics. These scope definition documents are generally based on similar documents provided by the proposal team during the [[project_initiation_and_contract_handover|project initiation phase]].

These documents **must** be verified for accuracy and **must** contain additional information as described in the relevant procedures. Once finalized, these scope definition documents **must** be issued with the status "Approved for Design."
