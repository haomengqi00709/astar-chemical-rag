# Template Non-Conformance Report (0-NCR-7XXX)

The 0-NCR-7XXX is a template for the Non-Conformance Report. This form is used by Inspectors to document any failure by a Vendor to fulfill a requirement of the Purchase Order, as described in the [[vendor_non_conformance_reporting]] procedure. It captures details such as the non-conformance description, proposed corrective and preventive actions, and re-inspection results.

The template also includes fields for numbering information, which follows [[0-PRC-0002_document_numbering]]. The identification number of the NCR must be identical to that of the reference Quality Data Sheet. For multiple NCRs related to the same goods, they are numbered as multiple sheets or sections of the same document.
