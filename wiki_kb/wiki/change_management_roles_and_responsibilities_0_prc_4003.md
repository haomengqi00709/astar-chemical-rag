# Change Management Roles and Responsibilities (0-PRC-4003)

Effective change management is a collective responsibility within the project team. The following outlines the specific roles and responsibilities as defined by procedure 0-PRC-4003:

**All Project Team Members:**
*   Responsible for the overall effectiveness of the [[scope_change_control_0_prc_4003|Change Management Program]].
*   Have the responsibility to identify potential issues affecting changes in approved project parameters, including Scope & associated design, Cost, Schedule, Execution plan, and Cash flow.

**Project Controls Specialist/Analyst:**
*   Responsible for the administration of the project's Change Management system.
*   Responsible for ensuring all Changes are timely registered, tracked, and documented.
*   Responsible for assembling all required information for a Change, with assistance from the Project Engineer, Discipline Leads, Estimating, and Project Planner/Scheduler.
*   Responsible for updating the status of Changes, maintaining, and issuing the [[pvn_pcn_log_and_documentation_management|Change Log]] for periodic review.
*   Responsible for continuously reminding project management to timely resolve Variances.
*   Once a Change is approved, responsible for incorporating trends into cost, schedule, progress measurement, and cash flow for timely and accurate progress and forecast.

**Project Controls Manager:**
*   Responsible for ensuring the implementation of the change management program on each project.
*   Responsible for reviewing and approving cost and schedule impact analysis for proposed changes.
*   Responsible for the administration of this procedure (0-PRC-4003).

**Discipline Leads:**
*   Responsible for the proper implementation of this procedure in performing their work assignments.
*   Responsible for providing Man-hour estimates for the Change.
*   Responsible for providing schedule impact analysis for the Change.

**Project Engineer:**
*   Responsible for coordinating change impact analysis from all affected disciplines.
*   Responsible for providing assistance to the Project Manager to timely approve (or reject) changes.

**Project Manager:**
*   Responsible for ensuring all project team members understand the project scope basis.
*   Responsible for timely approving or rejecting Changes.
*   Responsible for obtaining the Project Director’s approval for Changes exceeding 5% of the contract price or budgeted Man-hours.
*   Responsible for communicating with clients and obtaining clients’ approval for external Changes (PCN).

**Discipline Managers:**
*   Responsible for the proper implementation of this procedure within their respective disciplines.
*   Responsible for assisting Discipline Leads in project planning and Man-hour estimates regarding Changes.

**Director of Projects:**
*   Responsible for the approval of any Change exceeding 5% of the contract price or budgeted Man-hours.
*   Responsible for the proper implementation of this procedure within Chemetics.
*   Responsible for the approval of this procedure (0-PRC-4003).
