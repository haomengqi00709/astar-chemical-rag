# Purchase Order Document Numbering and Revisions

All Request for Quotations (RFQs) and Purchase Orders (POs) adhere to a standardized document numbering system to ensure traceability and organization. The document number format is exemplified by `98C12300-4021-R2`.

**Document Number Components:**
*   **Project Number (e.g., 98C12300):** This eight-character code represents the specific project. Project numbering conventions are defined in [[document_numbering_and_name_change_conventions]].
*   **Identification Number (e.g., 4021):** This four-digit number uniquely identifies the document within the project.
    *   The first digit (e.g., 4) indicates the Major Work Division. Major Work Division numbering is defined in [[major_work_division_codes]].
    *   The last three digits (e.g., 021) serve as a sequential addendum, ensuring unique identification.
*   **Revision Number (e.g., R2):** This alphanumeric code indicates the revision status of the document.

**RFQ and PO Document Number Relationship:**
A Request for Quotation and its subsequent Purchase Order **shall** share the same base document number, with the exception of their revision numbers. This ensures continuity from the quotation phase to the final order.

**Revision Numbering Rules:**
*   **Request for Quotation (RFQ):** RFQs **shall** utilize letter revisions (e.g., RA, RB, RC).
*   **Purchase Order (PO):** POs **shall** utilize number revisions (e.g., R1, R2, R3).

**Document Number Allocation:**
Document numbers for RFQs and POs are formally allocated within the [[project_planning_0_prc_3001]]. This procedure outlines the process for assigning and managing document numbers throughout the project lifecycle.
