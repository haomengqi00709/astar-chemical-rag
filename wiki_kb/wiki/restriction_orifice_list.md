# Restriction Orifice List

The Restriction Orifice List is a comprehensive document detailing the specifications for all restriction orifices used within a project. This list typically includes information such as the tag number, material of construction, type (e.g., plate, integral), and bore size for each orifice. It serves as a crucial reference during [[restriction_orifice_inspection_5_prc_0007|restriction orifice inspection]] to verify that the installed components match the design requirements for flow control.
