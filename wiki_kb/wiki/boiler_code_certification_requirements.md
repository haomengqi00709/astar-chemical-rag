# Boiler Code Certification Requirements

This page details the mandatory boiler code certification requirements for relevant equipment, such as [[vessel_and_tank_mechanical_checkout|vessels and tanks]] and [[packaged_equipment_mechanical_checkout|packaged equipment]]. Compliance with these codes is essential for ensuring the safety and regulatory approval of pressure-containing equipment.
