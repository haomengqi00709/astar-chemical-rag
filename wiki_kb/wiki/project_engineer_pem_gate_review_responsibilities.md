# Project Engineer Responsibilities for PEM Gate Reviews

The Project Engineer provides critical support to the Project Manager in the context of [[0-prc-2101_project_execution_model_gate_reviews_overview|Project Execution Model (PEM) Milestone Gate Reviews]], particularly concerning the development and tracking of action plans.

**Action Plan Management**
*   The Project Engineer is responsible for preparing the Action Plan that follows a [[pem_milestone_gate_review_process|Milestone Gate Review]].
*   The Project Engineer is responsible for expediting actions that result from the approved Report to the [[pem_steering_committee_roles|PEM Steering Committee]].
*   The Project Engineer **must** maintain the Action Plan current, ensuring all updates are recorded.
*   The Project Engineer **must** update the Action Plan as actions are completed.

**Gate Clearance**
*   Completion of all actions documented in the Action Plan constitutes the clearing of the PEM gate, signifying successful closure of the review phase.

**Action Plan Management**
The Action Plan is prepared by the Project Engineer. The Project Engineer is also responsible for:
*   Expediting actions resulting from the approved Report.
*   Maintaining the Action Plan current.
*   Updating the Action Plan as actions are completed.
