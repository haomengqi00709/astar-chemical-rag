# Gas/Gas Heat Exchanger Shell Types

Radial flow gas/gas heat exchangers are designed with five distinct shell types, primarily categorized by their shell side inlet and outlet configurations. These types dictate the flow path of the shell side fluid.

*   **Shell Type 1:**
    *   Features an axial flow inlet and outlet.
    *   Flow enters and exits through the central core of the exchanger.
*   **Shell Type 2:**
    *   Features a radial flow inlet and outlet.
    *   Flow enters and exits via a shell side nozzle located on the periphery of the shell.
*   **Shell Type 3:**
    *   Features an axial flow inlet or outlet at the bottom of the shell.
    *   Features a radial flow inlet or outlet at the top of the shell.
*   **Shell Type 4:**
    *   Features an axial flow inlet or outlet at the top of the shell.
    *   Features a radial flow inlet or outlet at the bottom of the shell.
*   **Shell Type 5:**
    *   Features both radial flow inlet and outlet, incorporating a core bypass pipe.
    *   Flow enters and exits the shell via slots that are uniformly spaced around the shell circumference.
    *   This shell type is exclusively used for internal heat exchangers, typically integrated within other equipment like converters.
