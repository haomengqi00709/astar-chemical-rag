# PVN/PCN Impact Analysis and Evaluation

Following the initiation of a Project Variance Notification (PVN) or Project Change Notification (PCN), a comprehensive impact analysis and evaluation process is undertaken to fully understand the implications of the proposed change.

**Distribution and Coordination:**
*   Once a PVN/PCN is initiated, the Project Controls Specialist/Project Analyst will distribute it to all related disciplines for their respective impact analyses.
*   The Project Engineer (or the Project Manager, if no Project Engineer is assigned) is responsible for coordinating the impact analysis inputs from all Discipline Leads.

**Discipline-Specific Impact Analysis:**
*   **Engineering Discipline Leads:**
    *   **Shall** evaluate the engineering impacts of the proposed change.
    *   **Shall** estimate the Man-hours required if the change is implemented.
    *   **Shall** make assessments on the schedule impact.
    *   Their assessments will be fed back to Project Controls for a comprehensive evaluation of the total cost and schedule impact.
    *   Discipline Leads **need** to input their "Recommended Actions" for the impacts they have identified.
*   **Other Disciplines:** Disciplines such as Procurement and Construction will provide their impact analysis if they are affected by the change.

**Overall Evaluation by Project Controls:**
*   The Project Controls Specialist/Project Analyst will gather all inputs from the various disciplines for an overall evaluation of the change.
*   The PVN/PCN form will then be updated with this consolidated information.
*   If a detailed estimate is required for the total cost of the change, Project Controls will formally request this estimate.
*   Project Controls will also request that [[project_risk_analysis_0_lst_2006|Risk Management]] review the change and provide input for the estimating process.
*   Project Controls will compile, summarize, and issue the formal cost estimate, which will be attached to the PVN/PCN.
*   A detailed breakdown of the cost per [[cost_code_structure|cost code]] and work code will be appended to the PVN/PCN, providing transparency and granular financial information.

This thorough analysis ensures that all potential consequences of a change are understood before it proceeds to the approval stage, allowing for informed decision-making.
