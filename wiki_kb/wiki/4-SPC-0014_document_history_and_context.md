# 4-SPC-0014 Document History and Context

This document, 4-SPC-0014, is a direct copy of the original specification ES44/W02 General Requirements for Welding High Nickel Austenitic Stainless Steels. It is intended to be used in accordance with 0-PRC-0001 Approval and Use of Standards.

There are plans to replace this document with a new one that fully complies with the requirements of the 0-PRC-0004 style for Textual Documents.

**Document Changes and Revisions**
*   A name change has been implemented for this document.
*   No new revision number was used for this name change, and the changes related to the name change have not been marked within the document.
*   No changes have been marked for fixing numbering issues within this document.
*   A "2005 Name Change Conversion" has also been implemented.
*   Similar to the initial name change, no new revision number was used for the 2005 Name Change Conversion, and the associated changes have not been marked.
