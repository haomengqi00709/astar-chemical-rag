# Construction Subcontract Document Control and Name Change (0-SUB-6)

This page addresses the document control aspects and the impact of a name change on Construction Subcontract Agreement 0-SUB-6.

**Applicable Documents:**
*   All drawings and specifications applicable to this subcontract **must** be listed on the [[document_transmittal_requirements]].

**Name Change Conversion:**
*   A name change conversion to "2005" has been implemented for this document.
*   It is important to note that no new revision number has been used for this name change.
*   Furthermore, changes related to the name change have not been marked within the document itself.
*   For general information regarding the impact of name changes on documentation, refer to [[aker_kvaerner_name_change_documentation_impact_0_spc_0002]].
