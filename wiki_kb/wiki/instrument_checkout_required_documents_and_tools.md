# Instrument Checkout Required Documents and Tools

Effective and accurate instrument checkout requires a specific set of tools and a comprehensive collection of engineering documents. Adherence to these requirements ensures that all verification steps are performed thoroughly and in accordance with project specifications.

**Required Tools**
The following tools are **mandatory** for conducting instrument checkout procedures:
*   A loop signal generator (calibrator)
*   A multimeter
*   A laptop computer with appropriate software (if required by the instrument)
*   A handheld field device communicator

**Required Engineering Documents**
The following engineering documents **must** be available and referenced during the instrument checkout process:
*   [[piping_and_instrumentation_drawings]] (P&ID’s)
*   [[instrument_loop_diagrams]] (Loop Sheets)
*   [[instrument_junction_box_drawings]] (Junction Box/Marwilling Cabinet detail drawings)
*   [[8-gad-00xx_instrument_location_drawings]] (Instrument Location Drawings)
*   [[instrument_installation_details_8_dtl_xxxx]] (Instrument Installation Details)
*   [[8-lst-0002_instrument_index]] (Instrument Index)
*   [[8-dst-xxxx_instrument_specification_sheets]] (Instrument Specification Sheets)
*   [[8-man-xxxx_project_instrument_manuals]] (Vendors Manuals, as required)

These documents provide the necessary design basis, installation instructions, and operational parameters against which the instruments are verified.
