# Administration Document Structure (Major Work Subject 0)

The "0 Administration" major work subject serves as the central repository for all project administrative documentation. This folder is uniquely structured with further minor work divisions, each containing specific sub-folders for detailed categorization. This structure ensures comprehensive management of project overheads, procedures, and communications.

The primary minor work divisions and their contents within the 0-Administration folder are:

**0-0 Documentation:**
*   **DAT:** Document Control Database.
*   **LST:** Document List, Transmittals. Data available in SQL: LST files.
*   **MAN:** Manual Table of Contents.
*   **OWN:** Owner-Issued Documents.
*   **PRC:** Project Specific Procedures.
*   **SPC:** Document Specifications. Data available in SQL: SPC files.
*   **TRN:** Transit File for Document Issues.

**0-2 Project Administration:**
*   **COR:** Correspondence with Owner, Internal, Site.
*   **CHG:** Contract, Change Orders. For more details on change orders, refer to [[change_order_documentation_requirements_0_chg_22]].
*   **LST:** Responsibility List. Data available in SQL: LST files.
*   **MIN:** Meeting Minutes.
*   **PRC:** Co-ordination and Project Specific Procedures.
*   **REP:** Monthly Reports.
*   **REQ:** Requisitions (Overheads).
*   **SPC:** Conditions for Subcontract. Data available in SQL: SPC files.
*   **SUB:** Engineering Subcontracts.
*   **TAB:** Bid Tabulations.

**0-3 Planning:**
*   **DAT:** Project Schedule, Project Resource Management.
*   **PRC:** Project Specific Procedures.

**0-4 Cost Control:**
*   **DAT:** Project Budget, Cost Forecasts.
*   **CHG:** Change Requests, Internal Notices of Change.
*   **PRC:** Project Specific Procedures.

**0-5 Procurement:**
*   **COR:** Correspondence with Vendors.
*   **DAT:** Purchasing and Logistics Database.
*   **LST:** Shipping Lists. Data available in SQL: LST files.
*   **POR:** Purchase Orders. For the form of purchase order, see [[form_of_purchase_order_0_prc_5001]].
*   **PRC:** Project Specific Procedures.
*   **REP:** Vendor Shop Surveys.
*   **SPC:** Conditions for Purchase, Packaging Specifications. Data available in SQL: SPC files.

**0-6 Construction:**
*   **COR:** Correspondence with Subcontractors.
*   **CHG:** Change Orders.
*   **MIN:** Meeting Minutes.
*   **PRC:** Project Specific Procedures.
*   **REQ:** Requisitions (Site Overheads).
*   **SPC:** Conditions for Subcontract. Data available in SQL: SPC files.
*   **SUB:** Construction Subcontracts.
*   **TAB:** Bid Tabulations.

**0-7 Quality Assurance:**
*   **NCR:** Non-Conformance Reports. For details, refer to [[non_conformance_report_0_ncr_7]].
*   **PRC:** Project Quality Assurance Procedures.
*   **QDS:** Quality Data Sheet.
*   **REL:** Inspection Releases.
*   **SPC:** Supplier Quality Assurance. Data available in SQL: SPC files.

**0-8 HSE (Health, Safety & Environment):**
*   This folder contains all documentation related to Health, Safety, and Environment.

**0-9 Corporate:**
*   **90XX:** General Corporate documents.
*   **91XX:** Human Resources documents.
*   **92XX:** Finance documents.
*   **93XX:** Information Technology documents.

This detailed structure ensures that all administrative documents are systematically organized and easily retrievable, supporting efficient project execution. For an overview of the entire project documentation structure, refer to [[document_control_1_prc_0003]]. The definitions of major work subjects are outlined in [[major_work_division_codes]].
