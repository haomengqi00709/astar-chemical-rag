# Process Design Criteria Document (1-PRC-0001)

The Process Design Criteria document, identified as **1-PRC-0001**, is a foundational procedural document within the chemical engineering firm. Its primary purpose is to consolidate and present the owner’s process requirements and contractual obligations for a given project to the entire project team. This document serves as a central reference point, summarizing critical design parameters and requirements that guide the plant's development.

**Purpose and Scope:**
The document records the owner’s process requirements for the project and presents a summary of both the process design criteria and contractual requirements to the project team. It ensures that all stakeholders have a clear and consistent understanding of the project's foundational parameters.

**Mandatory Contents:**
The Process Design Criteria document **must** contain the following elements, as applicable to the project:
*   Contract Requirements
*   [[process_description_overview|Process description]]
*   [[plant_design_basis_and_capacity|Plant capacity]]
*   [[plant_design_basis_and_capacity|Design basis]]
*   [[control_philosophy_and_dcs|Control philosophy]]
*   Reference to the appropriate Chemetics specification(s)
*   Any additional Chemetics general requirements for Plant design
*   [[design_standards_and_reference_materials|Reference materials and Design Tools]]

**Preparation and Approval Process:**
The preparation, checking, and approval of this critical document follow a defined workflow:

*   **Checked By:** Project Engineer
*   **Approved By:** Process
