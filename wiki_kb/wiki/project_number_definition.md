# Project Number Definition

The Project Number is a fundamental component of the firm's document numbering system, as defined in [[document_numbering_procedure_0_prc_0002]]. It serves to link documents directly to specific projects or to identify them as standard company documents.

**Format and Usage:**
The Project Number is an eight-digit code. For project-specific documents, this code represents the unique proposal or project number assigned to that endeavor (e.g., `98C12300`).

For standard documents, which are generic templates or procedures applicable across multiple projects, the term "Standard" shall be used as the Project Number. This clearly differentiates company-wide standards from project-specific deliverables.

The Project Number is the first segment of the full document number, preceding the Major Work Division. For example, in `98C12300-4-DTL-7801-5-R2`, `98C12300` is the Project Number.

This component is crucial for organizing documents by their originating project or their status as a company standard, facilitating efficient retrieval and management. It is an integral part of the [[document_number_format_and_components]].
