# 0-CHG-22 Change Order Documentation Requirements

Document 0-CHG-22 outlines specific requirements for the content of change order documentation, particularly concerning instructions to subcontractors, scope changes, and quotations.

### Instruction to Subcontractor
This section **must** list all revised documents or reproduce the instruction directly from a relevant communication.

### Change in Scope
This section **must** describe the re-work or additional work that is to be performed as a direct result of the instruction provided.

### Subcontractor Quotation
This section **must** provide a clear reference to the Subcontractor’s quotation, including its communication number.
If the Change Order is based on an assessment conducted by Aker Kvaerner Chemetics, this section **must** explicitly state: “Satisfactory quotation not received from Subcontractor. Change Order is based on assessment by Aker Kvaerner Chemetics.”

### Authorisation
The "Authorisation" section **requires** a specific [Position] to be filled. Authorisation for the change order is granted for and on behalf of Aker Kvaerner Chemetics.
