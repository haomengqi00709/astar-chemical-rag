# Coatings Documentation Structure

The project's coating requirements are comprehensively documented through a structured set of specifications and criteria. These documents ensure clarity, consistency, and compliance across all disciplines and for all Vendors involved in a project.

The primary documents comprising the coating requirements documentation are:

*   **[[coatings_design_criteria_7_prc_0001|Coatings Design Criteria (7-PRC-0001)]]:** This document establishes the fundamental principles and requirements for coating selection, incorporating statutory and owner-specific mandates.
*   **[[coating_specification_development_and_standards|Coating Specification]]:** This details the technical requirements for surface preparation, coating application, and material properties for various components.
*   **[[7-SPC-0006_coating_colour_specification|Coating Colour Specification (7-SPC-0006)]]:** This specifies the aesthetic and system requirements, including colours and coating systems for major plant components.

These documents collectively provide a complete technical description for all coating-related work, from initial design considerations to final application and inspection.
