# Process Control Configuration (Application Software)

The **Process Control Configuration (Application Software)** defines the plant-specific control algorithms, layouts, and operator interfaces necessary to fully control and monitor the Aker Kvaerner Chemetics process.

**Typical Document Number:** ----------
**Usage:** Design

**Content and Implementation:**
The Process Control Configuration (Application Software) **WILL CONTAIN** plant-specific control algorithms, layouts, and operator interfaces to completely control the Aker Kvaerner Chemetics process. It **WILL REFLECT** the specific requirements for efficiently controlling and monitoring the process.

This configuration **WILL BE IMPLEMENTED** in strict accordance with the [[process_logic_narrative]] and the [[logic_diagrams]] for the project. Specific interlocks, alarms, and trips **WILL BE IMPLEMENTED** within the configuration as per the Instrument Set Points, Alarms and Interlocks section in the operating manual (referencing [[alarms_interlocks_and_setpoints]]).

**Responsibilities:**
*   **Prepared By:** Instrumentation/Electrical
*   **Checked By:** Process
*   **Approved By:** Instrumentation/Electrical
