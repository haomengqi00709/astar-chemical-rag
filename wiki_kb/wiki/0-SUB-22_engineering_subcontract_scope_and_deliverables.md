# Engineering Subcontract 0-SUB-22 Scope and Deliverables

This page details the scope of services and deliverables required under Engineering Subcontract 0-SUB-22 between Aker Kvaerner Chemetics Australia and Back to the Drawing Board Pty Ltd.

**Subcontractor Services:**
The Subcontractor, Back to the Drawing Board Pty Ltd, **shall** supply services as described in the following specifications:
*   **Instrument Engineering:** Detailed in document ID 02C03000-0-SPC-88XX-RA.
*   **Electrical Engineering:** Detailed in document ID 02C03000-0-SPC-89XX-RA.

These specifications define the precise engineering tasks, methodologies, and expected outcomes for each discipline. The Subcontractor **must** adhere strictly to the requirements outlined in these documents to ensure compliance with the subcontract terms.
