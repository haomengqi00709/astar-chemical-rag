# 2.2 PR 2 Incident Investigation Procedure

This page refers to the Aker Kvaerner Group's 2.2 PR 2 Incident Investigation Procedure, a mandatory compliance document for the [[0-prc-8013_hse_incident_reporting]] procedure.

This procedure provides the methodology and requirements for conducting thorough investigations into all incidents, aiming to identify root causes and contributing factors to prevent recurrence.
