# Lime Handling System Quality Data Sheet 2 Component Inspection and Documentation Requirements

This section outlines the specific inspection and documentation requirements for key components of the Lime Handling System, as detailed in Quality Data Sheet 0-QDS-7434-2. All requirements marked with "Chemetics Witness" indicate that Chemetics personnel **must** be present during the specified activity.

**Quality Record Definitions:**
*   **AP:** "As Prepared" - Denotes documentation that is prepared by the vendor.
*   **FP:** "Included in Quality Assurance Documentation Package" - Denotes documentation that **must** be included in the final Quality Assurance Documentation Package.
For further details on quality record definitions, refer to [[quality_record_definitions]].

**Aeration Blower (If required):**
For any Aeration Blower supplied as part of the system, the following requirements **must** be met:
*   A **Certificate of Compliance is required** (FP, Chemetics Witness).
*   **External coating of CS is required** (FP, Chemetics Witness).
*   **Dimensional inspection is required** (FP, Chemetics Witness).
*   The unit **requires NEMA 4X construction**.
*   **Surfaces free from defects are required** (FP, Chemetics Witness).
*   **Cleanliness is required** (FP, Chemetics Witness).
*   **Packaging is required** (Chemetics Witness).

**Screw Feeder:**
For the Screw Feeder component, the following requirements **must** be fulfilled:
*   A **Certificate of Compliance is required** (FP, Chemetics Witness).
*   **External coating of CS is required** (FP, Chemetics Witness).
*   **Dimensional inspection is required** (FP, Chemetics Witness).
*   The unit **requires NEMA 4X construction**.
*   **Surfaces free from defects are required** (FP, Chemetics Witness).
*   **Cleanliness is required** (FP, Chemetics Witness).
*   **Packaging is required** (Chemetics Witness).

**Unloading Blower System:**
For the Unloading Blower System, the following requirements **must** be adhered to:
*   A **Certificate of Compliance is required** (FP, Chemetics Witness).
*   **External coating of CS is required** (FP, Chemetics Witness).
*   **Dimensional inspection is required** (FP, Chemetics Witness).
*   The unit **requires NEMA 4X construction**.
*   **Cleanliness is required** (FP, Chemetics Witness).
*   **Packaging is required** (Chemetics Witness).

These requirements ensure that all specified components meet the necessary quality, construction, and documentation standards before integration into the larger Lime Handling System. For inspection and documentation requirements related to Sheet 1 of this system, refer to [[0-QDS-7434-1_inspection_and_documentation_requirements]].
