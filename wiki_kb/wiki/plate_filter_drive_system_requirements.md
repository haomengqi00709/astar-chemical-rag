# Plate Filter Drive System Requirements

This page details the mandatory requirements for the drive system of the Plate Filter, as specified in Document ID 4-DST-XXXX-R0. Comprehensive information regarding the drive system is essential for proper integration and operation of the equipment.

**Mandatory Drive System Details**
The following details regarding the Plate Filter's drive system **shall** be provided:
*   **Drive System supply details:** Information on the vendor, model, and scope of supply for the drive system.
*   **Drive System mounting details:** Specifications for how the drive system is to be physically mounted to the Plate Filter or its supporting structure.
*   **Motor Specification:** Detailed specifications for the electric motor, including power, voltage, enclosure type, and any special features. This should align with [[electrical_equipment_specifications]].
*   **Drive System specification:** Overall technical specifications for the entire drive system, encompassing all components and their performance characteristics.

For general information on drive system specifications, refer to [[drive_system_specifications]].

The following details are mandatory for the drive system:
*   **Drive System Supply Details**
*   **Drive System Mounting Details**
*   **Motor Specification**
