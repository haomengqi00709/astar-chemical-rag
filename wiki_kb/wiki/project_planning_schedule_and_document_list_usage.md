# Project Planning Schedule and Document List Usage

The project planning schedule and the Document List (0-LST-0001) are key tools for managing project timelines and deliverables.

**Project Planning Schedule:**
Appendix A of 0-PRC-3001 contains the Project Planning Schedule. All planning activities **must** be carried out in accordance with this appended schedule. For projects requiring less than 5000 engineering man-hours, all planning activities **should** be completed within one week.

**0-LST-0001: Document List Functions:**
The [[project_document_control_and_numbering|Document List (0-LST-0001)]] serves several critical functions:
*   To assign Aker Kvaerner Chemetics and Owner document numbers.
*   To assign document names.
*   To plan document deliverables for the various disciplines.
*   To plan Engineering Subcontractor document deliverables.
*   To plan Subcontract document issue packages.

**Progress Measurement:**
It is important to note that progress measurement for the project is **not** done on the Document List (0-LST-0001). Instead, progress measurement is conducted within the [[project_scheduling_and_resource_management|Project Resource Management System (PRMS)]].
