# Requisition Document Numbering and Revisions (0-PRC-5002)

The numbering and revision control for Requisitions are critical for maintaining document integrity throughout the procurement process.

The identification number of a Requisition **must** be identical to the number assigned to the subsequent Purchase Order on the [[project_planning_0_prc_3001|Procurement Plan]] (0-PRC-3001).

Requisitions issued for a Request for Quotation (RFQ) and their subsequent Requisitions for a Purchase Order (PO) will share the same core document number. However, their revision numbering conventions differ:
*   Requisitions for the issue of an RFQ **shall** use letter revisions (e.g., RA, RB, RC).
*   Requisitions for the issue of a PO **shall** use number revisions (e.g., R1, R2, R3).

It is a mandatory requirement that all references to other documents within a Requisition **must** clearly show their correct and current revision number. This ensures that all parties are working with the most up-to-date information.

Following the issuance of a Requisition for a Purchase Order, any subsequent revisions to the documents referenced within it will necessitate the issuance of a new revision to the Requisition itself. This revised Requisition **must** contain the updated references to reflect the changes.
