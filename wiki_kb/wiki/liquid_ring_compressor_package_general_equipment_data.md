# Liquid Ring Compressor Package General Equipment Data

This page details the general equipment data requirements for the Liquid Ring Compressor Package, as specified in Datasheet 4-PKG-XXXX-R1. This section provides fundamental information regarding the quantity and operational characteristics of the compressor unit.

**Quantity Requirements**
The datasheet specifies the following quantities for the liquid ring compressor package:
*   **Operating Quantity:** The number of units required for continuous operation.
*   **Installed Spare Quantity:** The number of spare units that must be installed and ready for immediate use.

**Equipment Data**
The following essential data points must be provided for the equipment:
*   **Type:** The specific type or model of the liquid ring compressor.
*   **Number of Stages:** The total number of compression stages within the unit.
*   **Operation:** A description of the intended operational mode (e.g., continuous, intermittent).

Further details on the design and process parameters can be found under [[liquid_ring_compressor_design_and_process_parameters]].
