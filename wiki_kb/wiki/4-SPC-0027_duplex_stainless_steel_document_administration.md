# Duplex Stainless Steel Welding Standard Document Administration (4-SPC-0027)

This document, Specification 4-SPC-0027, serves as a critical standard for duplex stainless steel welding and fabrication. It is a direct copy of the original specification, PS10-003 Rev 01, titled "Basic Requirements for Welding/Fabricating SS 2205."

**Document Usage and Future Plans:**
The current version of this document **will** be used in strict accordance with the guidelines set forth in [[0-PRC-0001_standard_document_management_procedure]], which governs the approval and use of all standards within the organization. There are plans to replace this document with a new version that will fully comply with the stylistic and formatting requirements detailed in [[0-PRC-0004_document_style_and_format]]. This update aims to standardize the presentation and structure of technical documentation across the firm.

**Name Change Conversion:**
A significant administrative change occurred in 2005, involving a name change conversion to "Aker Kvaerner Chemetics." During this conversion, no new revision number was assigned to this document, and the changes related to the company name were not explicitly marked within the document text. For a comprehensive history of company name changes and their impact on documentation, please refer to [[aker_kvaerner_chemetics_name_change_history]].
