# TGAS/2 Program Limits

The [[tgas_2_thermal_design_software|TGAS/2 program]] has several hard-coded limits that **cannot** be exceeded during operation. These limits are integral to the software's design and computational framework:

*   **Shell Side Cross Passes:** The maximum hard-coded limit for shell side cross passes is 12.
*   **Acoustic Baffles:** The maximum hard-coded limit for the number of acoustic baffles is 9.
*   **Tube Groups:** The maximum hard-coded limit for the number of tube groups is 3.
*   **Total Number of Rows in Layout:** The maximum hard-coded limit for the total number of rows in a layout is 50.
