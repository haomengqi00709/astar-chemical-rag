# Design Execution Planning and Control

The execution of design for the Project carries the responsibility of ensuring the plant meets all performance guarantees specified in the Contract, as well as those required by applicable statutes and regulations. The design work **must** also satisfy all other Owner requirements detailed in the Contract and comply with all relevant statutes and regulations.

**Design Planning**
Planning for all design work is meticulously undertaken in accordance with the following procedures:
*   [[project_planning_0_prc_3001]]: Project Planning (0-PRC-3001).
*   [[0-prc-3002_project_scheduling_procedure_overview]]: Project Scheduling (0-PRC-3002).
*   [[project_resource_management_system_overview]]: Project Resource Management (0-PRC-3003).

Key deliverables resulting from this planning process include:
*   [[project_instructions_0_prc_2002]]: Project Instructions (0-PRC-2002).
*   [[0-prc-2003_project_execution_plan_overview]]: Project Execution Plan (0-PRC-2003).
*   [[project_coordination_0_prc_2004]]: Project Coordination (0-PRC-2004).
*   [[0-dat-3001_project_schedule]]: Project Schedule (0-DAT-3001). Data available in SQL: 0-DAT-3001
*   [[project_resource_management_system_overview]]: Project Resource Management (0-DAT-3002).

**Cost Management**
All costs incurred for the Project are charged using standard cost codes, in adherence to [[0-prc-4001_cost_code_procedure_overview]]. This ensures accurate financial tracking and reporting.

**Progress Monitoring and Reporting**
The progress of design work is continuously monitored by comparing actual resource expenditure against earned values, which are determined by achieved milestones.
*   Progress is reported monthly.
*   A forecast of design resource requirements is also reported monthly.

Both progress reporting and forecasting activities are conducted in accordance with [[project_resource_management_system_overview]]: Project Resource Management (0-PRC-3003). This systematic approach ensures that design activities remain on track and resources are managed efficiently.

**Design Progress Monitoring and Reporting**
Progress of the design work is monitored by comparing actual resource expenditure against earned values determined from milestones achieved. Progress is reported monthly, and a forecast of design resource requirements is also reported monthly. Progress reporting and forecasting are conducted in accordance with 0-PRC-3003: Project Resource Management.
