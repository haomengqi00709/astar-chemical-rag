# Design Standards and Reference Materials

The Design Standards and Reference Materials section, an essential part of the [[process_design_criteria_document]], identifies the authoritative guidelines, specifications, and resources that govern the plant's design and engineering. Adherence to these standards ensures consistency, quality, and compliance with industry best practices and internal company policies.

**Chemetics Standards and Procedures:**
*   The Plant **will** be designed following Chemetics standards.
*   The Plant **will** be designed following Chemetics procedures.
*   Chemetics standards and procedures are described in Q drive, providing a centralized repository for all relevant internal documentation.

**Reference Materials and Design Tools:**
The Process Design Criteria document **will** contain reference to the appropriate Chemetics specification(s) and any additional Chemetics general requirements for Plant design. It **will** also list Reference materials and Design Tools used in the project.

**Mandatory Listing of Reference Documents and Tools:**
*   Process design programs **must** be listed. This includes all software tools utilized for process simulation, modeling, and calculations.
*   Design manuals **must** be listed as references. These provide detailed technical guidance and methodologies.
*   Design files **must** be listed as references. This includes relevant engineering drawings, data sheets, and other project-specific documentation.
*   Previous project designs **must** be listed as references. Leveraging past project experience helps in applying proven solutions and avoiding common pitfalls.

**Specific Reference Documents:**
*   **Reference document:** 1-DST-0001 Site Design Conditions. This document provides critical environmental and geographical data relevant to the plant's location.
*   **Reference document:** 1-LST-0001 Battery Limit Conditions. This document specifies the conditions at the interfaces between different plant units or between the plant and external facilities.
    *   Data available in SQL: 1-LST-0001

This comprehensive listing of standards and references ensures that the design process is systematic, well-documented, and aligned with established engineering principles and company policies. It provides the necessary framework for all design activities, from initial conceptualization to detailed engineering.

Key reference documents include **1-DST-0001 Site Design Conditions** and **1-LST-0001 Battery Limit Conditions**.
Chemetics standards and procedures, which govern the plant's design, are described in the Q drive.
Process design programs, design manuals, design files, and previous project designs must all be listed as references.
