# Control System I/O List (8-LST-0003)

The **Control System I/O List** (8-LST-0003) details the DCS Input/Output assignments for process instrumentation and electrical devices that are monitored or controlled directly by the plant control system.

**Document ID:** 8-LST-0003
**Usage:** Design
**Data available in SQL:** 8-LST-0003

**Content Requirements:**
The Control System I/O List **WILL CONTAIN** DCS Input/Output assignments for Process Instrumentation. It **MUST** contain:
*   Instrument Tag Number that will be monitored and/or controlled directly from the plant control system.
*   Description of service.
*   DCS I/O Count and Definition showing the quantity and type of various I/O required throughout the project.

This list **WILL CONTAIN** all instrumentation and electrical devices that will be monitored and/or controlled directly from the plant control system. This includes all required electrical monitoring signals from MCC’s, Switchgear, Transformer Rectifiers, etc.

**Preparation and Details:**
The Control System I/O list **WILL BE PREPARED** in conjunction with the Instrument Index by the Subcontractor. A preliminary I/O list **WILL BE CREATED** during the same timeframe as the preliminary Instrument Index. The I/O list **WILL INCLUDE** individual totals of the various types of I/O required for the project.

When a dual Instrument numbering system is used for the project, the Client’s preferred Instrument numbering **WILL BE USED**. The power supply identified on the I/O list **WILL DEFINE** whether the Instrument is a 4-wire type device or a 2-wire type device, and **WILL DEFINE** the voltage requirements of the individual device.
