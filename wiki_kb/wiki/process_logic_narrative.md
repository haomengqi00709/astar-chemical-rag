# Process Logic Narrative (1-LST-0003)

The **Process Logic Narrative** (1-LST-0003) is a detailed written description of the operation and control of all automated equipment within the process. It serves as a primary document for control system design and operations.

**Document ID:** 1-LST-0003
**Usage:** Design
**Data available in SQL:** 1-LST-0003

**Content and Purpose:**
The Process Logic Narrative **WILL BE** a detailed written description of the operation and control of all automated equipment. It **MUST** contain:
*   Identification and locations of the control elements or devices.
*   Description of the specific control scheme required for the devices.
*   Commentaries and rationalizations as required.

This document provides a description of all process interlocks and alarms. It is the primary document used for the design of the [[logic_diagrams]] and/or the DCS control logic. The Logic Narrative is a co-joint effort between process and control engineers. Modifications, additions, and deletions **MUST** be originated from this document. It is used extensively in developing the operations manual.

Instrumentation will check the Logic Narrative for clarity, simplicity, and practicality to ensure ease of configuration for a typical DCS system. Specific interlocking and alarm requirements remain the responsibility of Process.

**Responsibilities:**
*   **Prepared By:** Process
*   **Checked By:** Technology
*   **Approved By:** Process
