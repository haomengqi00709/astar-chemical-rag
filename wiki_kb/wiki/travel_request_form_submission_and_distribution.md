# Travel Request Form Submission and Distribution

Upon completion and authorization, the [[travel_authorization_form_details_0_frm_9002]] **must** be submitted and distributed according to the following procedures:

**Form Completion and Signing:**
*   The travel request form can be completed and digitally signed using Adobe Acrobat. If completed digitally, the form should be circulated by email for approvals.
*   Alternatively, the travel request form can be printed, completed, and signed manually. If completed manually, the form **must** be scanned and forwarded as a .pdf file attached to an email.

**Mandatory Submission and Distribution:**
Once the travel request form has received all necessary approvals (as outlined in [[travel_authorization_approvals_0_frm_9002]]), the final approver **must** email the fully approved form to the designated distribution list: **DL-ECVAN-Travel**.

A copy of the fully approved travel request **must** also be emailed directly to the traveller.

**DL-ECVAN-Travel Distribution List Recipients:**
The DL-ECVAN-Travel distribution list ensures that all relevant parties are informed and can act on the approved travel request. This list includes:
*   The Aker Kvaerner Chemetics designated travel agency, which will proceed with booking arrangements as per [[travel_booking_process_and_agency_guidelines]].
*   Human Resources.
*   The HSE Manager.
*   Accounting.
*   The Aker Kvaerner Chemetics designated travel medical services provider, for any necessary health-related services as described in [[travel_health_and_documentation_support]].

**Form Completion and Signing:**
*   The travel request form can be completed and digitally signed using Adobe Acrobat. If completed digitally, the travel request form should be circulated by email for approvals.
*   Alternatively, the travel request form can be printed out and completed and signed manually. If completed manually, the travel request form **must** be scanned and forwarded as a .pdf file attached to an email.

**Final Submission and Distribution:**
The fully approved travel request **must** be emailed by the final approver to the distribution list DL-ECVAN-Travel. A copy of the fully approved travel request **must** also be emailed to the traveller.

The DL-ECVAN-Travel distribution list includes:
*   The Aker Kvaerner Chemetics designated travel agency.
*   Human Resources.
*   The HSE Manager.
*   Accounting.
*   The Aker Kvaerner Chemetics designated travel medical services provider.
