# Document Revision Numbering Rules

The Revision Number is a critical component of the document numbering system, indicating the current version and status of a document. The rules for revision numbering differ based on whether the document is a standard or project-specific documentation, as detailed in [[document_numbering_procedure_0_prc_0002]].

**Revision Number for Standards:**
*   Drafts of Standards shall be numbered `R0`.
*   Subsequent revisions of Standards shall be numbered sequentially (e.g., `R1`, `R2`, `R3`...).
*   Revision numbering for Standards is in accordance with [[standard_document_management_procedure_0_prc_0001]]: Approval and Use of Standards.

**Revision Number for Project Documentation:**
The revision numbering for project documentation is determined by its status and follows a dual system of letters and numbers:

*   **Letter Designations (RA, RB, etc.):**
    Revisions of project documentation shall be designated as letters (e.g., `RA`, `RB`, `RC`...) when the status is:
    *   Issued for Owner Review
    *   Issued for Quotation
    *   Approved for Design [by Aker Kvaerner Chemetics or Subcontractors]

*   **Number Designations (R1, R2, etc.):**
    Revisions of project documentation shall be designated as numbers (e.g., `R1`, `R2`, `R3`...) when the status is:
    *   Approved for Fabrication
    *   Approved for Construction
    *   Approved Instruction
    *   As Built

*   Revision numbering for project documentation is in accordance with [[control_of_project_documents_0_prc_0006]]: Control of Project Documents.

**Name Change Conversion:**
A name change was implemented (referring to the 2005 Name Change Conversion). No new revision number was used for this conversion, and the changes made during this conversion have not been marked within the documents. Further details can be found in [[document_name_change_impact_on_revision]].

The Revision Number is the final segment in the full document number format (e.g., `98C12300-4-DTL-7801-5-**R2**`). Adherence to these rules is essential for maintaining accurate document history and status, forming a key part of the [[document_number_format_and_components]].
