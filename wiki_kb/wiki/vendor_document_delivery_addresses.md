# Vendor Document Delivery Addresses

Vendors **must** use the following designated channels for delivering documents to Aker Kvaerner Chemetics to ensure they reach the correct department for processing.

**Email Delivery:**
*   Documents **shall** be delivered to Aker Kvaerner Chemetics via e-mail at: **Chemetics.doccontrol@akerkvaerner.com**.
*   For email deliveries, refer to [[outgoing_document_issuance_and_transmittals]] for specific transmittal file requirements.

**Courier Delivery:**
*   Documents **shall** be delivered to Aker Kvaerner Chemetics by courier to the following address:
    *   **Aker Kvaerner Chemetics**
    *   **1818 Cornwall Avenue**
    *   **Vancouver, British Columbia**
    *   **Canada**
*   Courier deliveries **must** be marked for the attention of the **Document Control Department**.
*   The telephone number for courier inquiries is **604-734-1200**.

Using these specified delivery methods ensures that all vendor documentation is received and managed efficiently by the appropriate Aker Kvaerner Chemetics personnel.
