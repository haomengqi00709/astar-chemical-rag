# Plate Filter Operational Specifications and Performance Requirements

This page outlines the operational specifications and critical performance requirements for the Plate Filter Package, as detailed in Document ID 4-PKG-XXXX-R1. Adherence to these specifications is mandatory for effective filtration and equipment longevity.

**Operational Specifications**
*   **Type of Filter:** Dry Cake Discharge
*   **Type of Operation:** An equipment data point that must be specified.
*   **Filtration Area:** Measured in m2
*   **Filter Volume:** Measured in m3
*   **Method of Cleaning:** An equipment data point that must be specified.
*   **Sluicing Fluid:** An equipment data point that must be specified.
*   **Precoat:** An equipment data point that must be specified.
*   **Filter Aid:** An equipment data point that must be specified.

**Cycle and Batch Timing**
*   **Cycle Time:** Measured in hours (h)
*   **Batch Volume:** 0.0 m3
*   **Batch Time:** Measured in hours (h)
*   **Cleaning Time:** Measured in hours (h)

**Performance Requirements**
The following are mandatory performance requirements:
*   **Filter Media Pore Size:** This is a mandatory VTA (Vendor Technical Acceptance) requirement.
*   **VTC (Vendor Technical Compliance) related to Filtrate Pressure and Flow/Area:** This is a mandatory performance requirement.
*   **Filter Cake Density:** Measured in kg/m3
*   **Design Cake Thickness:** Measured in mm
*   **VTA (Vendor Technical Acceptance) related to Filter Cake Density and Design Cake Thickness:** This is a mandatory performance requirement.
*   **Filtrate Quality:** Measured in mg/l SS
*   **Cake Moisture:** Measured in % H2O
*   **VTC (Vendor Technical Compliance) related to Filtrate Quality and Cake Moisture:** This is a mandatory performance requirement.
*   **Maximum Pressure Drop:** Measured in kPa
*   **VTC (Vendor Technical Compliance) related to Maximum Pressure Drop:** This is a mandatory performance requirement.
