# Subcontract Communication Guidelines

Effective and standardized communication is paramount for the successful execution of engineering subcontracts. All communication related to subcontracts must adhere to the guidelines outlined herein, ensuring clarity, traceability, and compliance with contractual obligations.

**Communication Medium**
All official communication between Aker Kvaerner Chemetics and the Subcontractor will primarily be conducted via e-mail.

**Compliance Requirements**
Communication **must** be in accordance with the requirements specified in:
*   [[standard_conditions_engineering_subcontract]]: Standard Conditions for Engineering Subcontracts (0-SPC-01).
*   [[special_conditions_engineering_subcontract]]: Special Conditions for Engineering Subcontracts (0-SPC-02).

**Communication Numbering Format**
To maintain clear traceability, all communications will be sequentially numbered using specific formats:
*   **From Aker Kvaerner Chemetics to Subcontractor:** Communications will use the format -[SUB]-XXX, where "XXX" represents a sequential number.
*   **From Subcontractor to Aker Kvaerner Chemetics:** Communications will use the format [SUB]--XXX, where "XXX" represents a sequential number.

**E-mail Subject Line**
The subject line of all e-mails **shall** contain the assigned communication number, immediately followed by a brief, descriptive summary of the e-mail's content. This ensures quick identification and categorization of correspondence.

**E-mail Notification for File Transfers**
When files are placed on the [[file_transfer_site_usage]], an e-mail notification **must** be sent to advise the receiving party. This e-mail **must** include the transmittal as described in the [[document_transmittal_requirements]] section.

**Document Control Contact**
All e-mail notifications regarding file transfers **must** be sent to Aker Kvaerner Chemetics Document Control at the following address: Aker Kvaerner Chemetics.doccontrol@akerkvaerner.com.

**File Download Link in E-mail**
The e-mail notification **must** include a direct link to the uploaded file on the File Transfer Site. The link **must** be in the format: `ftp://ftp.kvaerner.com/incoming/uploaded_file_name.zip`.

**Browser Error During Download**
Should a browser issue an error message during the download process, the user **must** contact Aker Kvaerner Chemetics Document Control immediately. Such an error typically indicates either an incorrect link or that the file has been automatically deleted due to exceeding the 24-hour retention period on the File Transfer Site.

**Communication Medium and Standards**
All general communication will be conducted by e-mail.
Communication must be in accordance with the requirements of 0-SPC-01: Standard Conditions for Engineering Subcontracts and 0-SPC-02: Special Conditions for Engineering Subcontracts.

**Communication Numbering**
Communication from Aker Kvaerner Chemetics to the Subcontractor will be sequentially numbered using the format -[SUB]-XXX, where XXX is a sequential number.
Communication from the Subcontractor to Aker Kvaerner Chemetics will be sequentially numbered using the format [SUB]--XXX.

**E-mail Subject Lines**
The subject line of e-mails will contain the communication number followed by a brief description of the content.
