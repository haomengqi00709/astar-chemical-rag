# Project Number Format and Assignment

The Project Number is a critical component of the overall [[cost_code_structure]], serving as the primary identifier for any project or internal initiative. Its format is standardized as `98C12300` and comprises four distinct elements:

1.  **Year of Initiation:** The first two digits, e.g., `98`, denote the year in which the project or proposal was first initiated.
    *   For proposals and projects, the year of initiation **shall** be assigned when the first proposal is initiated.
    *   For internally funded projects, project numbers **shall** be re-established annually, and the year of initiation **shall** always be the current year.

2.  **Technology Identifier:** The single letter, e.g., `C`, specifies the core technology associated with the project.
    *   'C' means **Chemicals**.
    *   'H' means **Sulphuric Acid**.
    *   'V' means **Internally Funded Projects**.

3.  **Sequential Number:** The three digits, e.g., `123`, provide a unique sequential identifier within the given year and technology.
    *   For proposals and projects, the Sales Group **shall** assign the Sequential Number when initiating the first proposal. In any calendar year, a unique series of numbers beginning with `001` **shall** be assigned across all technologies for proposals and projects.
    *   For internally funded projects, the Sequential Number **shall** be assigned in range for each calendar year as the project is approved.

4.  **Breakdown Code:** The final two digits, e.g., `00`, allow for further categorization within a project.
    *   For proposals, the Sales Group **shall** assign the Breakdown Code as "PC" for prospect cultivation.
    *   For proposals, the Sales Group **shall** assign the Breakdown Code as "BP" for bids and proposals.
    *   For projects, `00` will generally be the only Breakdown Code used during execution.
    *   Additional Breakdown Codes are used for specific project-related activities such as spare parts supply, remedial work, etc., for projects.
    *   For internally funded projects, `00` will be the only Breakdown Code used.
