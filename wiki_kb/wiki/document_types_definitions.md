# Document Types and Definitions

This page provides definitions for key document types used within Aker Kvaerner Chemetics, clarifying their purpose and scope.

**Procedures**
Procedures describe how Aker Kvaerner Chemetics will perform work.

**Specifications**
Specifications describe how Aker Kvaerner Chemetics requires others (Suppliers and Subcontractors) to perform work.
