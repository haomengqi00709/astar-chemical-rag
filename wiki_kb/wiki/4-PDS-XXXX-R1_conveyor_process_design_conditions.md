# Conveyor Process Design Conditions (4-PDS-XXXX-R1)

This page details the process design conditions for conveyor equipment as specified in datasheet 4-PDS-XXXX-R1. These conditions are critical for the proper selection and sizing of conveyor systems.

**General Process Design Information:**
The following fields **must** be completed for each specific conveyor application:
*   **Case Description:** A detailed description of the operating scenario or process case.
*   **Design Basis:** The fundamental principles and data used for the design calculations.
*   **System Description:** An overview of the system in which the conveyor will operate.

**Quantity Requirements:**
*   **Operating:** Specifies the number of conveyors required for continuous operation.
*   **Installed Spare:** Specifies the number of spare conveyors to be installed for redundancy or maintenance.

**Solid Material Flow Parameters:**
*   **Solid Description Composition:** Expressed in %w/w.
*   **Solid Description Moisture Content:** Expressed in %w/w.
*   **Solid Description Flow Rate:** Measured in kg/h.
*   **Solid Description Minimum Flow Rate:** Measured in kg/h.
*   **Solid Description Temperature:** Measured in oC.

**Pneumatic Conveyor Air Flow Requirements:**
For pneumatic conveyor types, the following air flow rates **must** be specified:
*   **Normal Air Flow:** kg/h
*   **Average Air Flow:** kg/h
*   **Peak Air Flow:** kg/h

Further details on the physical and chemical characteristics of the solid material can be found in [[4-PDS-XXXX-R1_conveyor_solid_material_characteristics]]. For general equipment design criteria, refer to [[equipment_design_criteria_4_prc_0002]].
