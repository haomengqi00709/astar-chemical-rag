# Document Revisions for 5-SPC-0010

This page details the revision history and administrative changes for specification 5-SPC-0010. For an overview of the specification, refer to [[5-SPC-0010_metal_ductwork_fabrication_specification_overview]].

**Name Change**
The name change to Aker Kvaerner Chemetics was implemented without a new revision number or marked changes to the document.

**Revision 1**
This revision primarily involved a change to the painting reference specification.

**Revision 2**
This revision incorporated several corrections and updates:
*   Corrected the shipping reference specification numbers.
*   Deleted the requirement for electrodes for dissimilar welds, as this is now covered in applicable welding specifications such as [[4-SPC-0060_carbon_steel_welding_standard_overview]] and [[4-SPC-0061_austenitic_stainless_steel_welding_standard_overview]].
*   Replaced all references to “fabricator” with “Vendor” to align with current terminology.
