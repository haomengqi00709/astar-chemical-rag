# RFQ Register

The RFQ (Request for Quotation) Register is a log that tracks all requests for quotations issued for a project. It is an essential tool for managing the [[procurement_and_logistics_strategy|procurement process]] and is included as an attachment to the [[0-rep-2001_monthly_progress_report_format|Monthly Progress Report]].
