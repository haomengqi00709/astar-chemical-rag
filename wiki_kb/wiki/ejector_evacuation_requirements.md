# Ejector Evacuation Requirements

This page details the necessary evacuation requirements for systems utilizing ejectors, as specified in the Template Ejector Datasheet (Document ID [[template_ejector_datasheet_administration]]). These parameters are crucial for designing ejector systems capable of achieving desired vacuum levels within specified timeframes.

**Evacuation Requirement Parameters and Units:**
*   **System Volume:** m³
*   **Gas Temperature:** °C
*   **Initial Pressure:** kPa(a)
*   **Final Pressure:** kPa(a)
*   **Gas Molecular Weight:** kg/kmol
*   **Evacuation Time:** minutes
*   **Maximum Leakage of Air:** Am³/h

**Evacuation Parameters and Units:**
*   **System Volume:** m3
*   **Gas Temperature:** oC
*   **Initial Pressure:** kPa(a)
*   **Final Pressure:** kPa(a)
*   **Gas Molecular Weight:** kg/kmol
*   **Evacuation Time:** minutes
*   **Max Leakage of Air:** Am3/h
