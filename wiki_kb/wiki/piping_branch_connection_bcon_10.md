# Piping Branch Connection Specification BCON-10

BCON-10 specifies the requirements for branch connections applicable to piping specifications CS6, CS7, CS8, and CS9.

**Applicability:** Branch Connections for CS6, CS7, CS8 & CS9.

**Design Parameters:**
*   Design temperature: -29 to 204°C
*   Design pressure: Full Vacuum to 1034 kPag

**Legend for Branch Connection Types:**
*   **C:** Coupling
*   **R:** Reducing Tee
*   **T:** Straight Tee
*   **S:** Stub-in, unreinforced
*   **SX:** Stub-in with X mm wide reinforcement (cut from header pipe)

The allowable branch connections are defined in the [[5-SPC-0001_table_5]].

**Mandatory Requirements:**
*   All branch connections **shall** be in accordance with [[ASME_b31_3_chemical_plant_and_petroleum_refinery_piping]].
*   In the event of a conflict between B31.3 and this specification, B31.3 **shall** govern.
*   This specification applies to branch connections made at 90° only.
*   Branch connections **shall not** intersect with the longitudinal weld of the run pipe.
*   Substitutions are subject to prior approval by Aker Kvaerner Chemetics.

For general requirements applicable to all branch connections, refer to [[piping_branch_connection_general_requirements]].

Data available in SQL: 5-SPC-0001_table_5

**General Requirements**
*   The allowable branch connections are defined in the BCON-10 TABLE.
*   Substitutions are subject to prior approval by Aker Kvaerner Chemetics.
*   All branch connections will be in accordance with ASME B31.3.
*   In the event of a conflict between B31.3 and this specification, B31.3 will govern.
*   This TABLE applies to branch connections made at 90° only.
*   Branch connections will not intersect with the longitudinal weld of the run.
