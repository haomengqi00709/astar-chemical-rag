# DCS Operating System Configuration

The **DCS Operating System Configuration** encompasses all system-wide proprietary software configuration, hardware interconnection setup, and performance documentation for the Distributed Control System.

**Typical Document Number:** No typical document number
**Usage:** Design

**Content and Vendor Responsibility:**
The DCS Operating System Configuration **WILL CONTAIN**:
*   All system-wide proprietary software configuration.
*   Hardware interconnection set-up.
*   Performance tests for hardware and software.
*   Documentation of performance parameters.
*   Backup procedures.
*   Maintenance requirements.
*   Upgrade issues and licensing.

The Vendor sets up the Control System Software Configuration (Operating System) under the direction of the Instrumentation/Electrical Engineer. Documentation of the Control System Software Configuration is usually directly accessible from the Control system itself and **WILL BECOME PART** of the [[control_system_manuals]] when the system is installed.

**Responsibilities:**
*   **Prepared By:** Vendor/Mfr.
