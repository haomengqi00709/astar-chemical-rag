# 0-PRC-2002 Project Administration Overview

The document with ID **0-PRC-2002** outlines the administrative details for project execution. This procedure, in conjunction with [[0-prc-2003_project_execution_plan]], [[project_coordination_0_prc_2004]], and [[0-prc-7003_quality_plan]], forms the comprehensive set of instructions for carrying out project work.

The detailed description of the project's scope of work is specifically referenced within the [[0-prc-2003_project_execution_plan]].

This procedure is intended for issuance to the Aker Kvaerner project team and office support personnel following internal approval. For some project contributors, this document may serve as the sole administrative reference for the project.

All work undertaken on the project **must** be performed in strict accordance with applicable [[corporate_policies]]. Where required by contract, the Project Engineer **shall** modify standard procedures and templates to incorporate specific Owner requirements.

The project description provided **must** be brief and easily understandable by all project contributors. Throughout this document, "Aker Kvaerner" is used as an abbreviation.
