# 9-LST-0722 Lightning Protection System Installation Field Check List

The 9-LST-0722 Lightning Protection System Installation Field Check List is a specific document used during the [[9-PRC-0004_electrical_field_checkout_documentation|Electrical Field Checkout Procedure (9-PRC-0004)]] to verify the correct installation of the lightning protection system. This checklist ensures that all components are installed according to engineering specifications and drawings to provide adequate protection.
