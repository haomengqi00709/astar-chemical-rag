# 0-SPC-7002 Document Administration and Name Changes

Document 0-SPC-7002 reflects the implementation of a name change for Aker Kvaerner Chemetics. For this name change, no new revision number was used, and the changes were not explicitly marked within the document.

Similarly, the 2005 name change conversion was implemented without using a new revision number, and the changes were not marked.

For further details on company name changes, refer to [[aker_kvaerner_chemetics_name_change_history]].
