# Vendor Document Review and Approval Process

Aker Kvaerner Chemetics implements a structured review and approval process for all vendor-supplied documentation, distinguishing between "hold" and "non-hold" documents to manage project progress and risk effectively.

**Hold Document Procedure:**
*   **Prohibition of Work**: The Vendor **may not** commence any work shown on a document that is marked as "hold" on the [[vendor_document_requirements|VDR]] until the document has been reviewed by Aker Kvaerner Chemetics and explicit approval to proceed has been given.
*   **Revised Hold Documents**: If a hold document has been revised, work on the revised portion **may not** commence until the revised document has been reviewed by Aker Kvaerner Chemetics and approval to proceed has been given.
*   **Aker Kvaerner Chemetics Response Time**: Upon receipt of a hold document, Aker Kvaerner Chemetics **will** respond within **7 working days**.
*   **Aker Kvaerner Chemetics Response Format**: The response to a hold document **will** be a marked-up copy provided in Adobe Portable Document Format (PDF).
*   **Aker Kvaerner Chemetics Response Directions**: The response **will** contain one of the following mandatory directions:
    *   "No Revisions Required; Proceed with Work Shown"
    *   "Revise as Marked and Reissue; Proceed with Work Shown"
    *   "Revise as Marked and Reissue; Do Not Proceed with Work Shown"

**Non-Hold Document Procedure:**
*   **Response Trigger**: Upon receipt of a "non-hold" document, Aker Kvaerner Chemetics **will only** respond if the document is found not to be in compliance with the requirements of the [[purchase_order_commercial_and_contractual_terms|Purchase Order]].
*   **Aker Kvaerner Chemetics Response Format**: If a response is required, it **will** be a marked-up copy provided in Adobe Portable Document Format (PDF).
*   **Aker Kvaerner Chemetics Response Direction**: The response **will** contain the mandatory direction: "Revise as Marked and Reissue; Proceed with Work Shown".

This rigorous review process ensures that all critical vendor documentation is thoroughly vetted and approved, minimizing potential issues during fabrication, construction, and operation.
