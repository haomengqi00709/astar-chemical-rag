# 0-QDS-7802 Document Column Definitions

This page defines the various column headers found within the Quality Data Sheet 0-QDS-7802, providing clarity on the information expected in each section.

**Key Column Headers:**
*   **Quality Record required:** This column specifies the type of quality record required for a given item or activity.
*   **Vendor will issue reports as prepared:** This column indicates whether the vendor is responsible for issuing reports as they are prepared.
*   **Required in Vendor I & T Plan:** This column denotes whether a particular item or activity must be included in the Vendor's Inspection and Test (I & T) Plan.
*   **I & T Plan:** This column refers to the Inspection and Test Plan, likely for recording status or reference.
*   **Witness:** This column is used to indicate or record activities that require Chemetics' personnel to witness.
*   **Hold:** This column is used to indicate or record activities that require a "Hold" point, meaning Chemetics' approval is needed before proceeding.
*   **Initials / Date:** This column is typically used for recording the initials of the person completing an action and the date it was completed.
