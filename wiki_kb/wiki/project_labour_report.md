# Project Labour Report

The Project Labour Report details the man-hours expended on a project, often breaking down labor by discipline or activity. This report is a key component for tracking resource utilization and is attached to the [[0-rep-2001_monthly_progress_report_format|Monthly Progress Report]] for reimbursable projects.
