# API 650 Welded Steel Tanks for Oil Storage

API Standard 650 specifies requirements for the design, fabrication, erection, and inspection of welded storage tanks for oil and other liquids. These tanks are typically used for atmospheric storage and are commonly found in the petroleum, petrochemical, and chemical industries. The standard covers material, design, welding, inspection, and testing.

This standard is referenced in [[4-SPC-0014_referenced_codes_and_definitions]] and specifically in [[4-SPC-0014_inspection_and_testing_requirements]] for the radiographic examination of tankage fabricated from Columbium Stabilized High Nickel Austenitic stainless steel. For such tankage, the minimum radiography requirements shall be spot radiography.

For detailed requirements on welded steel tanks for oil storage, refer to the latest edition of API 650.
