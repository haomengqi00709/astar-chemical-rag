# Publishing Project Documents (0-PRC-0005)

This page describes the process for publishing project documents, as outlined in procedure 0-PRC-0005.

The [[0_prc_0005_document_overview|0-PRC-0005 procedure]] governs the publishing of all project documents, ensuring they are formally released and made available with the correct status. This process is critical for maintaining document control and ensuring that all project stakeholders are working with the latest approved versions.

Key aspects of this procedure include:
*   **Formal Release:** Documents are formally released for specific purposes, such as "Issued for Quotation" or "Approved for Fabrication."
*   **Status Assignment:** Each published document is assigned a specific status, which dictates its permissible use within the project lifecycle.
*   **Controlled Distribution:** The procedure ensures controlled distribution of documents to relevant parties.

For Requisitions, documents referenced for a Request for Quotation (RFQ) **must** be published. If an "Approved for Fabrication" version is not available, the requisitioner **must** ensure the documents are published with the "Issued for Quotation" status. Documents referenced for a Purchase Order (PO) **must** have an "Approved for Fabrication" status prior to the Requisition's issue.

Refer to [[0_prc_5002_requisition_document_referencing_and_status]] for specific requirements regarding document status in Requisitions.
