# DCS Control Function Field Checkout Overview (8-PRC-0006)

This procedure, identified as document ID **8-PRC-0006**, outlines the Control Function Field Checkout for Distributed Control Systems (DCS). The primary purpose of this procedure is to verify that all DCS functions are configured and operating in accordance with engineering documents and specifications.

**Scope of Control Functions**
The control functions covered by this procedure include:
*   Graphic Displays
*   Alarm Displays
*   Trending Displays
*   Analog Control configuration
*   Discrete Control configuration
*   Logic Control configuration

**Personnel and Subcontractor Involvement**
A specialist and a DCS programmer are designated to perform the checks detailed in this procedure. Assistance from the subcontractor is required as needed to facilitate the checkout process.

**Completion and Readiness**
Upon the successful completion of this procedure, the DCS is deemed ready for [[water_and_air_trials_1_prc_0006|water batching and commissioning]].

**Efficiency Considerations**
DCS function checkout procedures are inherently time-consuming. It is generally recommended that these comprehensive checks be performed during the Factory Acceptance Test (FAT) at the DCS vendor's facility to optimize project timelines and resource allocation.

**Related Procedures and Documentation**
To gain a comprehensive understanding of this procedure and its inter-dependencies, a [[control_system_architecture_block_diagram|block diagram]] should be reviewed.

**Deficiency Management**
Any deficiencies identified during the checkout process **must** be recorded and submitted to the site supervisor/commissioning manager. The site supervisor/commissioning manager **shall** then collaborate with the specialist and DCS programmer to ensure all identified deficiencies are corrected.
