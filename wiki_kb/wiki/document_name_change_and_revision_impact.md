# Document Name Change Conventions

Administrative changes, such as name changes, are handled according to specific conventions to maintain document integrity while reflecting organizational or project updates.

**Key Conventions:**
*   Name changes, including the significant 2005 name change, have been implemented across documents.
*   For these administrative name changes, no new revision number has been used.
*   The changes resulting from name updates have not been explicitly marked within the documents themselves.

These conventions ensure that historical document references remain valid despite administrative title alterations.
