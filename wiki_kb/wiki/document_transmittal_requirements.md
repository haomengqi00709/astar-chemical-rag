# Document Transmittal Requirements

All documents exchanged between Aker Kvaerner Chemetics and the Subcontractor **must** be accompanied by a formal transmittal. These transmittals serve as a record of document exchange and provide essential metadata for document control.

**Subcontractor Transmittals to Aker Kvaerner Chemetics**
When the Subcontractor delivers documents to Aker Kvaerner Chemetics, these documents **must** be described in a formal transmittal that adheres to the following specifications:
*   **File Format:** Subcontractor Transmittals **must** be in the form of a Microsoft Excel file.
*   **File Naming:** The Excel file **must** be named "Transmittal".
*   **Tabular Content:** The transmittal **must** contain the following information in tabular form for each document being transmitted:
    *   Subcontract Number
    *   Document File Number
    *   Document Title
    *   Document Number
    *   Document Revision Number
    *   Document Status

The completed Excel transmittal file **must** be attached to the e-mail notification sent after uploading the documents to the [[file_transfer_site_usage]], as detailed in [[subcontract_communication_guidelines]].

**Aker Kvaerner Chemetics Transmittals to Subcontractor**
When Aker Kvaerner Chemetics delivers documents to the Subcontractor, these documents will also be described in a transmittal.
*   **File Format:** Aker Kvaerner Chemetics Transmittals will be in the form of an Adobe Portable Document Format (PDF) file.

These transmittal procedures ensure that all document exchanges are formally recorded and easily traceable, supporting efficient project management and quality assurance.

**Subcontractor Transmittals to Aker Kvaerner Chemetics**
When delivering documents to Aker Kvaerner Chemetics, Subcontractor Transmittals must be in the form of a Microsoft Excel file and must be named “Transmittal”.
These transmittals must contain the following information in tabular form: Subcontract Number, Document File Number, Document Title, Document Number, Document Revision Number, and Document Status.

**Aker Kvaerner Chemetics Transmittals to Subcontractor**
Documents delivered to the Subcontractor by Aker Kvaerner Chemetics will be described in a Transmittal, which will be in the form of an Adobe Portable Document Format file.
