# PEM Gate Review Facilitator Roles and Responsibilities

A dedicated Project Execution Model (PEM) Gate Review Facilitator is assigned to each project to guide and manage the [[0-prc-2101_project_execution_model_gate_reviews_overview|Milestone Gate Review]] process.

**Assignment**
The assignment of a PEM Gate Review Facilitator is conducted in accordance with the procedures outlined in [[0-prc-2001_document_overview|0-PRC-2001: Assignment of Project Responsibilities]].
*   Data available in SQL: 0-LST-2004 (Project Responsibility)

**Key Responsibilities**
The PEM Gate Review Facilitator is responsible for:
*   Preparing the template for the control object status checklist, which is a critical tool during the review process.
*   Leading the [[pem_milestone_gate_review_process|Review]] sessions with the project team, ensuring all necessary aspects are covered.
*   Preparation of the Summary of Findings at the conclusion of each review, documenting key observations and outcomes.

**Assignment**
The assignment of a PEM Gate Review Facilitator is conducted in accordance with:
*   0-PRC-2001: Assignment of Project Responsibilities
*   0-LST-2004: Project Responsibility

**Responsibilities**
The PEM Gate Review Facilitator is responsible for:
*   Preparing the template for the control object status check list.
*   Leading the Review with the project team.
*   Preparation of the Summary of Findings at the conclusion of the Review.
