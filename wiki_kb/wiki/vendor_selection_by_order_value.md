# Vendor Selection by Order Value

The process for Vendor selection varies based on the total value of the order. This section outlines the specific procedures for orders valued at less than CAD 10k, less than CAD 200k, and greater than CAD 200k.

### Orders Valued Less Than CAD 10k

For orders with a value of less than CAD 10,000, the Requisitioning Discipline **must** conduct a risk assessment. While this risk assessment uses the guidelines described in [[order_risk_assessment_procedure]], the process itself will not be formally documented. The objective is to select the lowest cost bid that presents acceptable business risks to Aker Kvaerner Chemetics. The selected Vendor **must** be identified on the [[preliminary_cost_and_technical_review|Cost Tabulation]].

If a more extended review is deemed necessary, the detailed technical evaluation process described in [[detailed_technical_bid_evaluation]] **must** be followed.

The Requisitioning Discipline **must** publish the Cost Tabulation using [[publishing_project_documents]] (0-PRC-0005). The Requisitioning Discipline Approver **must** approve this tabulation. The approved Cost Tabulation then provides authorization to issue the Purchase Order, following the procedure outlined in [[issue_of_request_for_quotation_or_purchase_order_0_prc_5005]].

### Orders Valued Less Than CAD 200k

For orders with a value of less than CAD 200,000, the Requisitioning Discipline **must** meet with the Project Engineer to:
*   Review the [[preliminary_cost_and_technical_review|Cost Tabulation]].
*   Conduct a risk assessment as described in [[order_risk_assessment_procedure]].
*   Select the Vendor.

The objective for these orders is to select the lowest cost bid that presents acceptable business risks to Aker Kvaerner Chemetics. The selected Vendor **must** be identified on the Cost Tabulation. The Project Engineer may direct that the order be split among two or more Vendors if this results in an overall lower cost to the project. If an order is split, the Cost Tabulation **must** be copied and re-numbered for each individual order, and a separate [[order_risk_assessment_procedure|Risk Assessment]] **must** be completed for each.

If a more extended review is required, the detailed evaluation procedures described in [[detailed_technical_bid_evaluation]] and [[detailed_cost_bid_evaluation]] **must** be followed.

The Requisitioning Discipline **must** publish the Cost Tabulation using [[publishing_project_documents]] (0-PRC-0005). The Project Engineer **must** approve this tabulation. The approved Cost Tabulation provides authorization to issue the Purchase Order, provided that the conditions described in the [[order_risk_assessment_procedure|Order Risk Assessment]] are met.

### Orders Valued Greater Than CAD 200k (Shortlisting)

For orders with a value greater than CAD 200,000, the Requisitioning Discipline **must** meet with the Project Engineer and the Project Manager to:
*   Review the [[preliminary_cost_and_technical_review|Cost Tabulation]].
*   Select a short-list of Vendors for further detailed evaluation.

The Project Manager will provide directions to the Requisitioning Discipline regarding:
*   Vendors requiring a [[vendor_shop_survey_requirements|shop survey]].
*   Vendors requiring a technical reference check.
*   Other disciplines that **must** conduct a technical evaluation.
*   Additional cost elements that **must** be quantified to complete the Cost Tabulation.
These directions **must** be recorded on the Cost Tabulation.

The Requisitioning Discipline **must** publish the Cost Tabulation using [[publishing_project_documents]] (0-PRC-0005), and the Project Engineer **must** approve it.

**Budget Overruns for Shortlisted Bids:**
*   If the lowest bid from the short-listed Vendors is over budget, the Project Manager **must** decide whether to proceed with the procurement.
*   If the Project Manager decides not to proceed, she **must** direct the Project Engineer to work with the project team to determine alternate design or procurement strategies to reduce the cost. This direction **must** be issued via memorandum, copied to the relevant Discipline Leads and the Director of Projects.
*   If the Project Manager decides to proceed, but the lowest bid from the short-listed Vendors is more than 10% over budget, she **must** issue a memo to the Director of Projects. This memo **must** advise of the decision, attach the Cost Tabulation, and explain why no further work to reduce cost will be done.
