# Control System Documentation Types and Usage

This page outlines the various documents required for Control System design and specification, categorizing them by their primary usage phase (Design, Procurement, Construction, or Operation and Maintenance). Each entry includes the document title, typical document ID (if available), and notes on its usage.

**Design Usage Documents:**

*   **Control System Design Criteria** (8-PRC-0017)
    *   Used for establishing fundamental design principles.
    *   [[control_system_design_criteria]]
*   **Piping and Instrumentation Drawings (P&IDs)** (Refer to 1-PRC-0003)
    *   Essential for process and instrumentation layout.
    *   [[piping_and_instrumentation_drawings]]
*   **Control System Architecture - Block Diagram** (8-DTL-XXXX)
    *   Illustrates the overall system structure.
    *   [[control_system_architecture_block_diagram]]
*   **Process Logic Narrative** (1-LST-0003)
    *   Detailed description of automated equipment operation.
    *   Data available in SQL: 1-LST-0003
    *   [[process_logic_narrative]]
*   **Process Control - DCS Configuration Parameters** (8-LST-0104)
    *   Basic information for DCS programming.
    *   Data available in SQL: 8-LST-0104
    *   [[dcs_configuration_parameters]]
*   **Alarms, Interlocks and Setpoints** (8-LST-0103)
    *   Process-specific information for control system configuration.
    *   Data available in SQL: 8-LST-0103
    *   [[alarms_interlocks_and_setpoints]]
*   **Electrical Control - Logic Narrative** (9-LST-0003)
    *   Describes electrical control schemes.
    *   Data available in SQL: 9-LST-0003
    *   [[electrical_control_logic_narrative]]
*   **Logic Diagrams** (8-SCM-XXXX)
    *   Detailed expansion of logic narratives (may be deprecated).
    *   [[logic_diagrams]]
*   **Control System I/O List** (8-LST-0003)
    *   DCS Input/Output assignments for process instrumentation.
    *   Data available in SQL: 8-LST-0003
    *   [[control_system_io_list]]
*   **Electrical System I/O List** (8-LST-0005)
    *   DCS Input/Output assignments for electrical instrumentation.
    *   Data available in SQL: 8-LST-0005
    *   [[electrical_system_io_list]]
*   **Control System Graphics Sketches** (No typical document number)
    *   Guidelines for DCS display screen layouts.
    *   [[control_system_graphics_sketches]]
*   **Control System Graphics** (No typical document number)
    *   Displayed graphics for process monitoring and control.
    *   [[control_system_graphics]]
*   **DCS Operating System Configuration** (No typical document number)
    *   System-wide proprietary software configuration.
    *   [[dcs_operating_system_configuration]]
*   **Process Control Configuration (Application Software)** (----------)
    *   Plant-specific control algorithms and operator interfaces.
    *   [[process_control_application_software_configuration]]
*   **Factory Acceptance Test** (----------)
    *   Procedures and results for factory testing.
    *   [[factory_acceptance_test]]

**Procurement Usage Documents:**

*   **Basic Control System Specification** (8-SPC-0004)
    *   Details technical requirements for procurement.
    *   Data available in SQL: 8-SPC-0004
    *   [[basic_control_system_specification]]
*   **Document for Enquiry / Purchase / Vendor Document Review** (No typical document number)
    *   Covers procedures for vendor interaction and document review.
    *   [[procurement_and_vendor_documentation]]

**Construction Usage Documents:**

*   **Control Equipment-Cabinet Layouts and Internal Interconnection Wiring** (No typical document number)
    *   Layouts and wiring details for control cabinets.
    *   [[control_equipment_cabinet_layouts]]
*   **Process Control – I/O Interface Wiring diagrams** (No typical document number)
    *   Termination details for field devices to I/O cards.
    *   [[io_interface_wiring_diagrams]]
*   **Control System Spare Parts List** (----------)
    *   List of required spare parts for construction and operation.
    *   [[control_system_spare_parts_list]]
*   **Construction Subcontract Supply and Erection Scope** (0-LST-6x90-1)
    *   Defines the scope of work for construction subcontracts.
    *   Data available in SQL: 0-LST-6x90-1
    *   [[construction_subcontract_scope]]

**Operation and Maintenance Usage Documents:**

*   **Control System Manuals** (8-MAN-0001)
    *   Comprehensive manuals for system operation and maintenance.
    *   [[control_system_manuals]]
*   **As Built Documentation** (No typical document number)
    *   Documentation reflecting the final installed system.
    *   [[as_built_documentation]]
