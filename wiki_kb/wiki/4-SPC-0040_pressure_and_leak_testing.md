# 4-SPC-0040 Pressure and Leak Testing

Specification 4-SPC-0040 outlines the mandatory requirements for pressure and leak testing of metallic process vessels and components.

**Hydrostatic and Pneumatic Testing:**
*   When required or specified, equipment **must** be subject to a hydrostatic or pneumatic test.
*   Testing **must** be in accordance with the applicable code or Aker Kvaerner Chemetics requirements.
*   Hydrostatic testing **must** be done using potable water at 18-24oC (65-75oF) unless otherwise limited by [[ASME_section_viii_div_1_pressure_vessels|ASME Code]].
*   If sweating occurs during hydrostatic testing, the water **must** be warmed sufficiently to allow inspection of dry surfaces.
*   The test pressure **must** be maintained for one hour per 25mm (1”) of maximum shell thickness during hydrostatic testing.
*   The minimum holding time for hydrostatic test pressure **must** be one hour.
*   A calibrated pressure gauge **must** be installed on the equipment during the hydrostatic test.
*   Hydrostatic testing of internal coils **must** be performed after all preliminary operations and N.D.T. have been carried out (e.g., forming, heat-treatment, descaling, etc.).
*   The minimum holding time for hydrostatic testing of internal coils **must** be two hours.
*   After hydrostatic testing, internal coil(s) **must** be inspected, thoroughly drained, and dried.

**Air/Soap Solution Test:**
*   The welds of each reinforcing pad or segment, together with associated nozzle welds, **must** be given an Air/Soap solution test.
*   Test hole(s) for reinforcing pads/nozzle welds **must** be left open after the Air/Soap solution test has been completed.
*   Unwelded tube to tubesheet joints **must** be given an Air/Soap solution test.
*   The shell side for unwelded tube to tubesheet joints **must** be pressurized to 35kPag (5 psig) max for the Air/Soap solution test.

**Vacuum Box Test:**
*   Flat-bottomed tanks **must** have any weld splices in the floor given a vacuum box test.
*   For non-[[API_650_welded_steel_tanks|API]] tanks, the vacuum box test requirement for floor splice welds is waived where the floor splice welds are subjected to 100% radiographic or dye penetrant examination.

**Helium Testing:**
*   When helium testing of tube to tubesheet joints is specified, it **must** be done using the Helium Mass Spectrometer Reverse Probe method.

**Air/Soap Solution Test:**
*   The welds of each reinforcing pad or segment, together with associated nozzle welds, **will** be given an Air/Soap solution test.
*   Test hole(s) for reinforcing pads/nozzle welds **will** be left open after the Air/Soap solution test has been completed.
*   Unwelded tube to tubesheet joints **will** be given an Air/Soap solution test.
*   The shell side for unwelded tube to tubesheet joints **will** be pressurized to 35kPag (5 psig) max for Air/Soap solution test.

**Vacuum Box Test:**
*   Flat-bottomed tanks **will** have any weld splices in the floor given a vacuum box test.
*   For non-API tanks, the vacuum box test requirement for floor splice welds is waived where the floor splice welds are subjected to 100% radiographic or dye penetrant examination.

**Helium Leak Test:**
*   When helium testing of tube to tubesheet joints is specified, it **will** be done using the Helium Mass Spectrometer Reverse Probe method.
