# Change Request

A Change Request is the initial formal document used to propose a modification to a project's established baseline. It marks the beginning of the [[project_change_initiation|Project Change Initiation]] phase within the [[0-PRC-4003-R1_project_change_management_flow_diagram|Project Change Management Flow Diagram]].

Change Requests can originate from various sources:
*   **Client**: A Client initiates a Change Request when they require alterations to the project scope, specifications, deliverables, or other contractual terms. This is a direct communication from the client indicating a desired modification.
*   **Internal Project Team**: While internal changes are often documented as Project Variation Notices (PVNs) or Project Change Notices (PCNs), the underlying concept is a request for change.

When a Client initiates a Change Request, the [[change_management_roles_and_responsibilities_0_prc_4003|Project Manager]] is responsible for formally accepting it. Upon acceptance, the Project Manager **must** then initiate a Project Change Notice (PCN) to formally enter the request into the project's internal change management system for [[project_change_evaluation|evaluation]].

The Change Request document typically includes:
*   A clear description of the proposed change.
*   The reason or justification for the change.
*   The potential impact on project scope, schedule, cost, and quality (though detailed impact analysis occurs in the evaluation phase).
*   The originator of the request.

As a foundational document in the [[change_management_document_types]] suite, the Change Request ensures that all proposed modifications are formally documented and enter a structured process for review and approval, preventing uncontrolled alterations to the project.
