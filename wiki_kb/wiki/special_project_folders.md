# Special Project Folders

In addition to the standard major and minor work subject folders, specific folders are designated for special purposes:

*   **ALIB Folder:** This folder is exclusively for use by CAE (Computer-Aided Engineering) personnel.
*   **USER Folder:** This folder contains an 'XXX' subdirectory, which is designated for project personnel scrap storage.
