# Digital Document Mark-up and Stamp Usage

For efficient and standardized review of vendor documents, specific tools and procedures for digital mark-up and stamp usage in Adobe Acrobat are mandated.

**Digital Mark-up Guidelines:**
*   Textual mark-ups of a PDF document **must** be done using the "Free Text Tool (S)". The "Fill Colour" property of the "Free Text Tool (S)" box **must** be set to white for these mark-ups.
*   Revision clouds **must** be drawn in freehand using the "Pencil Tool (N)". The "Line Colour" property of the "Pencil Tool (N)" **must** be set to red for revision clouds.
*   Vendor-scanned documents without optical character recognition (OCR) cannot be marked-up directly using Adobe Acrobat. For such documents, mark-ups **must** be done on a hard-copy, which is then scanned to create an electronic file.

**Digital Stamp Installation and Usage:**
A digital stamp is available for use with Adobe Acrobat to standardize certain annotations.

**Installation:**
To install the stamp, copy the file located at `Q:\AKER KVAERNER CHEMETICS\0 Administration\0 Documentation\Procedure\Vendor Stamp`.
*   For Adobe Acrobat 4.0, stamps are saved in `C:\Program Files\Adobe\Acrobat 4.0\Acrobat\plug_ins\Stamps`.
*   For Adobe Acrobat 5.0, stamps are saved in `C:\Program Files\Adobe\Acrobat 5.0\Acrobat\Plug_ins\Annotations\Stamps`.

**Usage:**
1.  Open the PDF document in Adobe Acrobat.
2.  Click on "Windows", then "Toolbar".
3.  "Basic Tools" **must** be chosen in the toolbar.
4.  Select the "Stamp Tool (S)" from the Basic Tools toolbar.
5.  Move the cursor to the desired stamp location on the page.
6.  Click and drag the mouse to size the stamp.
7.  Right-click on the stamp and select "Properties".
8.  In the Category box, click on the arrow and choose "Aker Kvaerner Chemetics".
9.  Click on the desired term.
10. Re-size and re-locate the stamp as desired.
11. Add [[applying_digital_signatures|Digital Signature]] as required.
12. Save the document.
