# Cable Tray Installation Details

Cable tray installation details provide specific instructions and component requirements for supporting and arranging cable trays throughout the plant. These details are essential for proper cable management and support.

**Content of Cable Tray Details**
Cable tray details **shall** show:
*   Cable tray supports on pipe racks.
*   Cable tray supports along walls.
*   Cable tray supports under walkways.
*   Vertical runs between horizontal runs.
*   Cable tray supports for multiple layers in straight runs horizontally.
*   Cable tray supports for multiple layers in straight runs vertically.
*   Cable tray supports for multiple layers in bends.

Cable tray and support materials **shall** be indicated on the drawings.
