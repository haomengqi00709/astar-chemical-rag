# Electrical Field Checkout: Documentation and Checklists (9-PRC-0004)

The Electrical Field Checkout Procedure (9-PRC-0004) relies on a comprehensive set of engineering documents and specific checklists to ensure the accurate inspection and verification of electrical systems.

**Engineering Documents for Inspection:**
The inspection process **shall utilize** the following engineering documents:
*   [[electrical_general_arrangement_drawings|Electrical Equipment Layouts]]
*   [[grounding_general_arrangement_drawings|Grounding Drawings]]
*   [[lighting_layout_drawings|Lighting Drawings]]
*   [[cable_tray_installation_details|Cable Tray Layouts]]
*   Electrical Cable Schedules (e.g., [[power_and_control_cables_list]])
*   [[electrical_equipment_manuals|Electrical Equipment Vendor Manuals]]
*   [[electrical_installation_details|Detail Installation Drawings]]
*   [[motor_control_schematic_wiring_diagrams|Motor and other Schematics]]
*   [[electrical_schematic_and_wiring_diagrams|Electrical Interconnection Diagrams]]
*   Electrical Junction Box/Marshalling Cabinet Detail Drawings (e.g., [[instrument_junction_box_drawings]])
*   [[electrical_installation_details|Electrical Installation Details]]
*   [[electrical_installation_specification|Electrical Construction Specification]]

**Electrical System Check Lists:**
Specific Check Lists are integral to the inspection process, ensuring all components are verified. These lists are attached to the [[9-PRC-0020_electrical_systems_contractor_checkout_procedure|Electrical Systems Contractor Checkout Procedure 9-PRC-0020]] and include, but are not limited to, the following:
*   9-LST-0721: [[grounding_installation_details|Grounding System Installation Field Check List]]
*   9-LST-0722: [[lightning_protection_installation_details|Lightning Protection System Installation Field Check List]]
*   9-LST-0723: [[lighting_installation_details|Lighting System Installation Field Check List]]
*   9-LST-0724: Welding Receptacle System Installation Field Check List
*   9-LST-0725: [[cable_tray_installation_details|Cable Tray System Installation Field Check List]]
*   9-LST-0726: [[cable_system_installation_field_check_list]]
*   9-LST-0727: HV Switchgear System Installation Field Check List
*   9-LST-0728: LV Switchgear System Installation Field Check List
*   9-LST-0729: LV Switchgear System Installation Field Check List
*   9-LST-0730: [[motor_installation_details|Motor System Installation Field Check List]]
*   9-LST-0731: Transformer/Rectifier Installation Field Check List

Additionally, Check Lists numbered 9-LST-0701 to 0711 are also attached to procedure 9-PRC-0020. [[motor_approval_tag|Motor Approval Tags]] are also considered part of procedure 9-PRC-0020.

Data relevant to this procedure is available in SQL: [[9-PRC-0004_table_1]].
