# Zirconium Fabrication Documentation and Records (4-SPC-0024)

This page outlines the mandatory documentation and record-keeping requirements for Zirconium (Grade 60702) fabrications, as specified in document **4-SPC-0024**.

**Fabricator's Report:**
*   The fabricator **will** furnish a report containing all data pertaining to each vessel or item.
*   Prior to the company's final inspection of each unit, the fabricator **will** have prepared three sets of records in finished form, excluding final test data.

**Required Documentation:**
The documentation package **must** include:
*   Material mill test reports.
*   Nameplate rubbing.
*   Hydrostatic test report.
*   A copy of all inspection and test reports.
*   Manufacturer's Affidavit.
*   [[0-REL-7XXX_template_inspection_release|Inspection/Release Form]].

**Documentation Package Assembly:**
*   These reports, together with final test data, **will** be assembled into three complete sets for each item.
*   In no case **will** a documentation package pertain to more than one vessel or item number.

**Inspector's Role in Documentation Collection:**
*   The Inspector **will**, at the time of witnessing the final tests and certifying the correctness of forms, collect the appropriate number of documentation packages for each item tested.
