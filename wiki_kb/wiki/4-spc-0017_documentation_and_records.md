# Documentation and Records for 6% Moly SS Fabrication (4-SPC-0017)

This section outlines the mandatory documentation and record-keeping requirements for 6 percent Moly austenitic stainless steel fabrications under Standard **4-SPC-0017**.

**Fabricator's Report and Record Sets**
The Fabricator **will** furnish a report containing all data pertaining to each item. The Fabricator **must** prepare three sets of records in finished form for each unit prior to Aker Kvaerner Chemetics' final inspection. These initial three sets of records exclude final test data.

**Required Records**
The following records **must** be included in the documentation package:
*   Mill test reports
*   Nameplate rubbing or facsimile (refer to [[nameplate_order_equipment]])
*   A copy of all inspection and test reports (refer to [[inspection_report_requirements]])
*   Manufacturer's affidavit
*   Shipping/Release form (refer to [[shipping_notice_requirements]])

**Documentation Package Assembly**
The listed reports, together with final test data, **must** be assembled into three complete sets for each item. A documentation package **must not** pertain to more than one vessel or item number.

**Inspector's Role**
The Inspector **will** collect the appropriate number of documentation packages for each item tested when witnessing final tests and certifying the correctness of forms.
