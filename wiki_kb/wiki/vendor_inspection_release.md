# Vendor Inspection Release

The Inspection Release is a formal document that permits a Vendor to package goods for shipment after successful inspection and resolution of any non-conformances. This process is governed by [[vendor_quality_assurance_0_prc_7005]].

**Conditions for Issuance**
For items with Surveillance Level 1, 2, 3, or 4, the Inspector **must** provide the Vendor with an approval in the form of a [[0-REL-7XXX_template_inspection_release]]. This Inspection Release authorizes the Vendor to proceed with packaging the goods for shipment.

The Inspection Release may list any remaining work required by the Vendor prior to packaging. However, this remaining work **must** only be of a minor nature and **must not** require re-inspection. An Inspection Release **will not** be issued until the goods have been re-inspected if any non-conformances were present, as detailed in [[vendor_non_conformance_reporting]].

**Numbering and Documentation**
The Inspection Release **must** be numbered according to [[document_numbering_0_prc_0002]]. Its identification number **must** be identical to that of the reference [[quality_data_sheets_qds]]. Multiple Inspection Releases for the same item or type of bulk materials **must** be numbered as multiple sheets or sections of the same document.

**Signing and Filing Procedure**
The Inspector **must** place the correct date in the electronic file version of the Inspection Release. Subsequently, the Inspector **must** print the Inspection Release and sign it using blue ink. The signed Inspection Release **must** then be handed to the Vendor.

For record-keeping, the electronic file version of the Inspection Release **must** be marked “Signed in the original by [Name]” above the signature line and placed in the project electronic file. File naming conventions for multiple sheets of the same document are described in Section 5 of [[file_structure]].

Revision 2 of [[vendor_quality_assurance_0_prc_7005]] clarified the printing, signing, and filing procedures for Inspection Releases.

**Remaining Work and Documentation**
The Inspection Release may list any remaining minor work required by the Vendor prior to packaging the goods. This remaining work must be of a minor nature and must not require re-inspection. An Inspection Release will not be issued until the goods have been re-inspected if non-conformances were present.

**Numbering and Filing**
The Inspection Release will be numbered according to [[0-PRC-0002_document_numbering]]. Its identification number must be identical to that of the reference Quality Data Sheet. Multiple Inspection Releases for the same item or type of bulk materials will be numbered as multiple sheets or sections of the same document.

**Inspector's Responsibilities**
The Inspector is responsible for placing the correct date in the electronic file version of the Inspection Release. After printing the document, the Inspector will sign the printed Inspection Release using blue ink and hand the signed original to the Vendor. The electronic file version will be marked “Signed in the original by [Name]” above the signature line and then placed in the project electronic file. File naming for multiple sheets of the same document is described in Section 5 of [[0-PRC-0003_file_structure]].
