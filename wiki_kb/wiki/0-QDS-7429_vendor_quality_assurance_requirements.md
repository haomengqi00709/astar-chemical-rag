# 0-QDS-7429 Vendor Quality Assurance Requirements

This page outlines the specific quality assurance requirements for vendors supplying SS Plate under Quality Data Sheet [[0-QDS-7429_document_administration]].

The vendor **shall** prepare a Quality Plan. This plan **must** be in accordance with [[0-SPC-7001_vendor_quality_assurance_equipment]]. The requirement for a Quality Plan is conditional; if not required for a specific order, the relevant cells in the Quality Data Sheet document **shall** be deleted.

The vendor's overall Quality Assurance program **shall** comply with the requirements specified in this Quality Data Sheet [[0-QDS-7429_document_administration]] and with [[0-SPC-7001_vendor_quality_assurance_equipment]].

Chemetics' surveillance level for this project is **Level 0.0**. All surveillance activities **shall** be conducted as explicitly set out within this Quality Data Sheet.
