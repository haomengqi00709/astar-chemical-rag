# CSA W47.2 Aluminium Welding Qualification Code

This page provides an overview of CSA W47.2, a key Canadian standard for the qualification of Aluminium welding.

**Overview**
CSA W47.2 is the Canadian Standards Association's code for the certification of companies for the fusion welding of Aluminium. It specifies requirements for welding procedures, welder qualifications, and quality control for Aluminium welding.

**Application**
In the context of the [[9-SPC-0001_aluminium_bus_welding_standard_overview|Aluminium Bus Welding Standard (9-SPC-0001)]], all welders employed on Aker Kvaerner Chemetics work **shall** be suitably qualified in accordance with relevant codes and standards, including CSA W47.2, for every procedure to be used. For field welding, any uncertified welder **shall** pass Qualification Tests laid out in CSA W47.2 prior to production welding.
