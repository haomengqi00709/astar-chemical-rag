# Vendor Document Control Procedure Overview

This procedure, identified as document **0-PRC-0007**, outlines the comprehensive steps for managing vendor-issued documents within Aker Kvaerner Chemetics projects. As a core Procedure document, it details the lifecycle of vendor documentation from receipt to final review and return.

The primary objectives of this procedure are:
*   To describe the steps for receiving and disseminating Vendor-issued documents to the Project Team.
*   To describe the steps for reviewing Vendor-issued documents and returning them to the Vendor with instructions, where required.

This document is integral to ensuring that all vendor documentation complies with project requirements and is efficiently processed and reviewed by the relevant project disciplines.

Refer to [[0-prc-0007_table_1_contents]] for guidelines on the scopes of reviews for different classes of equipment, which are appended to this procedure.
