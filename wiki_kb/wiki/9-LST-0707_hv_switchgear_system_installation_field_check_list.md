# HV Switchgear System Installation Field Check List (9-LST-0707)

Document 9-LST-0707 is the Field Check List for the installation of the HV (High Voltage) Switchgear System. This checklist forms part of the [[electrical_systems_contractor_checkout_procedure]] (9-PRC-0020), ensuring that all HV switchgear system components are installed in accordance with project specifications and drawings.
