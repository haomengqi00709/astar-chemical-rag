# Outgoing Vendor Document Processing

Once the [[vendor_document_review_process|vendor document review process]] is complete, Document Control is responsible for returning the marked-up documents and instructions to the Vendor.

**Return Process:**
The requisitioning Discipline Lead will advise Document Control that the Vendor document is ready to be returned. The Vendor document will then be logged into the Document Control Database. An Outgoing Transmittal will be created and copies issued, as referenced in [[control_of_project_documents_0_prc_0006|Document 0-PRC-0006: Control of Project Documentation]].

The [[document_status_definitions|document status]] and reason for issue will reflect the instruction assigned to the Vendor during the review process (e.g., "No Revisions Required; Proceed with Work Shown").

Document Control will return either a digital copy of the marked-up Adobe Portable Document Format Vendor document or a printed paper copy, along with a copy of the Outgoing Transmittal. Further details on returning documents to the Vendor are available in [[control_of_project_documents_0_prc_0006|Document 0-PRC-0006: Control of Project Documentation]].

**Vendor Document Return Report:**
A Vendor Document Return Report will be reviewed weekly by the Project Engineer. This report, also referenced in [[control_of_project_documents_0_prc_0006|Document 0-PRC-0006: Control of Project Documentation]], lists vendor documents that are overdue or scheduled to be received back from the Vendor after being sent out for revision. The Project Engineer uses this report to expedite the return process with the Vendor as necessary.

**"Non-Hold" Document Returns:**
"Non-hold" documents will only be returned to the Vendor if they are found not to be in compliance with the [[form_of_purchase_order_0_prc_5001|Purchase Order]]. If a "non-hold" document is returned, the instruction given will be: "Revise as Marked and Reissue; Proceed with Work Shown".
