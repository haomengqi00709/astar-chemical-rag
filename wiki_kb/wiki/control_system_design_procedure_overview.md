# Control System Design and Specification Procedure Overview

This wiki page provides an overview of the "Control System Design and Specification Procedure" document, identified as **8-PRC-0004-R1**. This procedure outlines the requirements for preparing comprehensive documentation related to Control System design for projects within Aker Kvaerner Chemetics.

**Procedure Purpose:**
Project personnel **MUST** prepare documentation as per project requirements described in this procedure. The documentation **MUST** provide a complete record of the Control System design for the project and **MUST** include a description of technical requirements to be issued to vendors and subcontractors. This procedure also assigns responsibilities to project personnel for document preparation, checking, and approval, as further detailed in [[roles_and_responsibilities_control_system]].
