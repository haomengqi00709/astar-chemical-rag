# Coating Colour and System Specification (7-SPC-0006)

The Coating Colour / System Specification, identified as 7-SPC-0006, defines the aesthetic and protective coating systems for all major components within a project. This includes equipment, piping, steel structures, and buildings.

**Content Requirements:**
*   Colour for all major plant components (equipment, piping, steel, building, etc.), as applicable, shall be specified.
*   The Coating System for all components, as applicable, shall be detailed.

**Preparation and Approval:**
*   The preparer for the Coating Colour / System Specification is not specified in the provided facts.
*   It will be checked by the Materials Engineer.
*   It will be approved by the Project Engineer.

**Implementation and Verification:**
This specification will define the coating colour and system for all project components. The specified coating colour and system will be back-checked against vendor documents upon their submission to ensure compliance. Coating system recommendations will be made by the appropriate Discipline Engineer and directed to the Project Engineer for review and incorporation.
