# Aker Kvaerner Chemetics Name Change History

This page documents significant name and document ID changes related to Aker Kvaerner Chemetics and its associated entities, particularly impacting project documentation.

**Company Information:**
Aker Kvaerner Chemetics Australia is a division of Aker Kvaerner Canada Inc. It is important to note that Aker Kvaerner Canada Inc. is a Canadian company.

**Document ID and Reference Changes (2004-2005):**
A significant change in document numbering conventions occurred in **2004-2005**:
*   On **June 6, 2004**, the file name convention was updated. Specifically, references from `0-CHG-80XX-R0` were changed to `0-CHG-22XX-R0`.
*   Consequently, any references within documents that used the `80XX` identifier were systematically changed to `22XX`.
*   This name change conversion was fully implemented by **2005**.

**Impact on Documentation:**
*   **Revision Numbering:** No new revision number was used for the 2005 name change conversion. This means that documents affected by this change may not show an explicit revision increment solely for the purpose of the name change.
*   **Change Marking:** The changes made for the 2005 name change conversion were not marked within the documents. Users should be aware that historical documents may contain the older `80XX` references, while newer or updated documents will reflect the `22XX` convention without explicit change indicators.

This historical context is crucial for understanding document lineage and ensuring correct referencing across project files. For general information on document numbering and revision control, refer to [[document_numbering_0_prc_0002]] and [[document_control_revisions]].
