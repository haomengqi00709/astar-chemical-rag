# Document Control Periodic Reports

The [[document_control_database]] is utilized to generate a variety of periodic reports, providing essential insights into the status and flow of project documentation. These reports are crucial for project management and oversight.

All periodic reports produced from the Document Control Database must be forwarded to the Project Engineer for review and action.

The following types of periodic reports are generated:

*   **Vendor Document Expediting Report:** This report lists all Vendor documents that are either overdue for receipt or are scheduled to be received within the upcoming reporting period. It serves as a tool for proactive follow-up with vendors.
*   **Vendor Document Return Report:** This report specifically lists Vendor "hold" documents that are overdue for return or are scheduled to be returned in the upcoming period. It helps in managing critical review cycles.
*   **Published Document Status Report:** This comprehensive report provides a complete listing of all published documents, including their full revision history. It offers a snapshot of the current state of all official project documentation.
*   **Document Issue Summary Report:** This report summarizes all documents that have been issued to any single party, which may include Vendors, Subcontractors, the Owner, or Aker Kvaerner Chemetics field supervisors. It provides an overview of document distribution to specific entities.
*   **Exception Reports:** These reports highlight discrepancies in document distribution, specifically listing all parties who have received earlier revisions of documents but have not yet been issued the latest versions. This ensures that all stakeholders are working with the most current information.

*Note: The description of the Vendor Document Status Report was added in Revision 2 of the procedure.*
