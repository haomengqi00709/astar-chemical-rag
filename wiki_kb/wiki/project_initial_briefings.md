# Project Initial Briefings and Team Assignment

Following the [[project_initiation_and_contract_handover|contract handover]], the Project Manager is responsible for conducting a series of initial briefings to disseminate project information and assign personnel.

**Summary of Project Requirements:**
The Project Manager **must** prepare a summary of the project requirements to ensure a clear understanding across all involved departments.

**Briefing Operations Department Heads:**
The Project Manager **must** convene a meeting to brief operations department heads on:
*   Overall project requirements.
*   The specific scope of work to be delivered by each department.
*   The immediate need for personnel to be assigned to the project.

**Project Team Assignment:**
Project Team Assignment refers to [[assignment_of_project_responsibilities|0-PRC-2001: Assignment of Project Responsibilities]]. The Project Manager **must** advise department heads of the immediate need for personnel to be assigned to the project.

**Briefing Discipline Leads and Key Team Members:**
The Project Manager **must** issue preliminary scope information, preliminary schedule information, and copies of relevant parts of the Contract to the assigned Discipline Leads.

Additionally, the Project Manager **must** arrange a meeting involving key assigned project team members, proposal personnel, and marketing personnel. The purpose of this meeting is to facilitate a complete and orderly handover of all project requirements from the proposal stage to the project execution phase. During this meeting, planning priorities and short-term work priorities **must** be agreed upon with the project team members.
