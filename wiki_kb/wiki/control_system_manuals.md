# Control System Manuals (8-MAN-0001)

**Control System Manuals** (8-MAN-0001) are comprehensive documents provided for the operation and maintenance of the installed control system.

**Document ID:** 8-MAN-0001
**Usage:** Operation and Maintenance

**Content Requirements:**
Project Control System Manuals **WILL CONTAIN**, as a minimum:
*   Block diagrams, physical layouts, and detailed schematics.
*   Specifications and performance criteria.
*   Vendor Manuals (Operation and Maintenance) for all supplied equipment.

Documentation of the [[dcs_operating_system_configuration]] **WILL BECOME PART** of the Control System Manual when the system is installed. These manuals are essential for plant operators and maintenance personnel to understand, operate, and troubleshoot the control system effectively.
