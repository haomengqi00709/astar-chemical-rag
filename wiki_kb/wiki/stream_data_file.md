# Stream Data File for PFDs

The Stream Data File is a crucial component in the development of [[pfd_overview|Process Flow Diagrams (PFDs)]], providing quantitative information about the various streams within the process.

**Content of the Stream Data File:**
The Stream Data File will contain the following elements, as applicable:
*   Steady state balanced and maximum flows.
*   Steady state and maximum temperatures.
*   Steady state and maximum pressures.
*   Physical properties (e.g., density, as required for the PFD).

**Production:**
The Stream Data File is produced by the Process department, deriving its information directly from the [[process_calculations|Process Calculations]].

**Integration:**
The Stream Data File is subsequently merged with the [[pfd_sketch_and_graphics|PFD Graphics]] by the Design department to produce the complete Stage 1 PFD.

For details on the calculation methods and software used to generate this data, refer to [[stream_data_calculation_and_integration]].
