# Product Stripper Calculation Data Banks

This page describes the data banks utilized in the Product Stripper calculations, outlining the matrices and vectors they contain.

**Data Bank Contents**
The calculation data bank for the Product Stripper contains the following matrices and vectors:
*   **VISD:** (5,6) matrix
*   **DEND:** (6,3) matrix
*   **AW:** (6) vector
*   **PACK:** (18,13) matrix
*   **GASES:** (3,2) matrix
*   **VS:** (5,11) matrix
*   **PC:** (5) vector
*   **TP:** (11) vector

**NTU Program Data Usage**
*   Data from TWR is used in the NTU program.
