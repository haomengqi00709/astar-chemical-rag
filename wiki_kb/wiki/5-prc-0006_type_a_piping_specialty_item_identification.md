# Type A Piping Specialty Item Identification

The identification system for Type A Piping Specialty Items follows a specific format designed to categorize and uniquely identify components associated with particular equipment.

**Number Format**
The standard identification number for a Type A Piping Specialty Item is structured as **R-780302**. This format is broken down into three distinct components:

*   **Device Type (R):** A single letter or abbreviation designating the type of device.
*   **Associated Equipment Number (7803):** A four-digit number linking the specialty item to its primary equipment.
*   **Serial Number (02):** A unique two-digit number assigned sequentially.

**Device Type A Codes**
The following codes are used to designate specific device types for Type A piping specialty items:

*   **RO:** Restriction orifice
*   **PSI:** Piping specialty item
*   **SP:** Spectacle

**Serial Number Assignment**
A unique two-digit number **must** be assigned as the serial number for each Type A piping specialty item that belongs to the same associated equipment. This ensures that each item has a distinct identifier within its equipment group.

For a comprehensive list of codes, refer to [[5-prc-0006_table_1_piping_specialty_item_codes]].
This identification system is part of the broader [[5-prc-0006_piping_specialty_item_identification_procedure_overview]].

**Number Format Breakdown**
The components of the Type A identification number are defined as follows:
*   **R**: Designates the Device Type.
*   **7803**: Designates the Associated Equipment Number.
*   **02**: Designates the Serial Number. A unique two-digit number is assigned for each Type A piping specialty item belonging to the same equipment.
