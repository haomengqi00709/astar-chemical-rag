# Document Revision History and Naming for 0-CHG-22XX-R0

This page documents the specific name change and revision history for documents related to the 0-CHG-22XX-R0 series, as referenced in 0-SPC-2202-1.

### File Name and Reference Changes
On June 6, 2004, the file name for documents in this series was changed from 0-CHG-80XX-R0 to 0-CHG-22XX-R0. Concurrently, all internal references within these documents from "80XX" were updated to "22XX".

### 2005 Name Change Conversion
The 2005 Name Change Conversion has been implemented across these documents. It is important to note the following regarding this conversion:
*   **Revision Number:** No new revision number was used specifically for the name change conversion.
*   **Marking of Changes:** Changes made as part of the name change conversion have not been explicitly marked within the documents.

For broader context on document naming conventions and revision management, refer to [[document_name_change_history_0_prc_2203]] and [[aker_kvaerner_chemetics_name_change_history]]. The impact of such changes on document numbering is further elaborated in [[aker_kvaerner_name_change_documentation_impact_0_spc_0002]].
