# Related Procedures and Documents for 0-PRC-0005

The document publishing procedure (0-PRC-0005) integrates with several other key procedures and documents within Aker Kvaerner Chemetics to ensure comprehensive document control and project management. Understanding these relationships is crucial for effective implementation of publishing activities.

### Referenced Procedures and Documents:

*   **0-PRC-7004: Checking and Approval of Design**
    *   This procedure governs the formal checking and approval processes for design documents. The publishing activities described in 0-PRC-0005 occur prior to or in conjunction with these approval stages.
    *   Related WikiLink: [[document_approval_and_revision_process]]

*   **0-PRC-0006: Control of Project Documentation**
    *   This procedure outlines the overarching control mechanisms for all project documentation. It also covers the management of the project Document Control Database, which is updated by Document Control upon completion of publishing and approval processes as per 0-PRC-0005.
    *   Related WikiLink: [[control_of_project_documents_0_prc_0006]]

*   **0-PRC-0003: Project File Structure**
    *   This procedure defines the organizational structure for both the project electronic file and the project paper file. Published documents, whether digital or scanned paper, **must** be stored according to the structures defined in 0-PRC-0003.
    *   Related WikiLink: [[document_control_1_prc_0003]]

*   **0-PRC-2001: Assignment of Project Responsibilities**
    *   This procedure details the allocation of roles and responsibilities within a project. The responsible Discipline Lead, as defined by 0-PRC-2001, is tasked with advising Document Control upon the completion of document publication and approval.
    *   Related WikiLink: [[authorization_roles]]

*   **0-PRC-0002: Document Numbering**
    *   This procedure specifies the requirements for document numbering and file naming conventions. All published files, regardless of the application used for publishing, **must** adhere to the naming standards outlined in 0-PRC-0002 to ensure proper identification and organization within the project directories.
    *   Related WikiLink: [[document_number_format_and_components]]

These interconnected procedures ensure a robust framework for managing project documents from creation and publishing through to approval and archival. For an overview of the publishing process itself, refer to [[0_prc_0005_document_overview]].
