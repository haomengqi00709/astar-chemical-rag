# Project Cost Code Structure

The firm utilizes a standardized Cost Code Format to categorize and track all project and internal work expenses. This format is exemplified by `98C12300-MAT-4-7801` and is composed of four distinct parts, each providing specific information about the nature of the cost.

The four mandatory components of the Cost Code are:
1.  **Project Number:** The first part, such as `98C12300`, identifies the specific project or initiative. For detailed information on its structure and assignment, refer to [[project_number_format_and_assignment]].
2.  **Cost Type:** The second part, a three-letter code like `MAT`, specifies the general category of the cost (e.g., materials, engineering). Definitions for each cost type can be found in [[cost_type_definitions]].
3.  **Major Work Division:** The third part, a single-digit code like `4`, indicates the primary discipline or area of work (e.g., equipment, civil). A comprehensive list of these divisions is available in [[major_work_division_codes]].
4.  **Detail Code:** The fourth part, a four-digit code such as `7801`, provides granular detail about the specific activity or item within the Major Work Division and Cost Type. For more information on these codes and their listings, see [[detail_code_listings_and_usage]].

Any further breakdown of a project's cost structure beyond the established components and categories described in this procedure **shall** require explicit approval from the relevant authority. This ensures consistency and prevents unnecessary complexity in the cost coding system.

The four mandatory components of the Cost Code are:
*   The first part (e.g., `98C12300`) is the [[project_number_format_and_assignment|Project Number]].
*   The second part (e.g., `MAT`) is the [[cost_type_definitions|Cost Type]].
*   The third part (e.g., `4`) is the [[major_work_division_codes|Major Work Division]].
*   The fourth part (e.g., `7801`) is the [[detail_code_listings_and_usage|Detail Code]].
