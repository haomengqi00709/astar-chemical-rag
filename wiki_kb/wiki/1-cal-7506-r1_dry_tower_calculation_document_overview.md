# Dry Tower Calculation Document (1-CAL-7506-R1) Overview

This document, identified as 1-CAL-7506-R1, is a template for Dry Tower calculations. It was prepared for CHEMETICS, a division of [[aker_kvaerner_chemetics_name_change_history|Aker Kvaerner Canada Inc.]] located in Vancouver, Canada, for a project titled "Dry Tower" with Tag. No. 7506U. The client document number is Standard-1-CAL-7506-R1.

The signature sheet for this document includes column headers numbered 1.0 through 24.0. The "Calculation" field is associated with "CHEMETICS", while the "Location" field is present but unspecified.

**User Requirements and Specifications**
Users **must** consult with the Technology Manager prior to modifying any parameters not highlighted in blue.
On the Data Input sheet, the "Case Description" and "Design Basis" fields are present but unspecified. A directive "Do not Delete" is also present on this sheet.
For the "User provide properties?" setting, a value of 1 indicates "No" and 2 indicates "Yes".
