# Incoming Document Receipt and Processing

Upon the receipt of any documents from Owners, Vendors, or Subcontractors, a stringent logging and processing procedure must be followed to ensure proper record-keeping and distribution.

**Logging of Received Documents:**
All incoming documents must be logged into the [[document_control_database]]. The following information is mandatory for logging:
*   Date Received
*   Reference (Purchase Order, Subcontract or Owner’s Contract) Number
*   Issuer’s Name
*   Issuer’s Document Title
*   Issuer’s Document Number
*   Issuer’s Document Revision Number
*   Issuer’s Document Status
*   Aker Kvaerner Chemetics Document Number (if assigned)
*   Document Return Date (where applicable)

**Special Considerations for Owner-Issued Documents:**
*   Logging of Owner-Issued documents will not include a Reference Number.
*   Logging of Owner-Issued documents will not include an Aker Kvaerner Chemetics Document Number.
*   If the Owner re-issues the same revision of a document, it will be logged with the new receipt date but retain the same revision number.

**Incoming Transmittals:**
An Incoming Transmittal, containing identical information as listed above (Section 7.1 in the source document), must be sent to the Issuer as an acknowledgment of receipt.
*   Incoming Transmittals must be copied to the Project Engineer and all Discipline Leads.
*   Incoming Transmittals must be titled "Document Transmittal from [Parties Name] to Aker Kvaerner Chemetics -XXXX".
*   The "XXXX" in the transmittal title represents a unique sequential series, beginning with 0001. A distinct sequential series (XXXX) must be maintained for each party issuing documents to Aker Kvaerner Chemetics.
*   Incoming Transmittals must be published in accordance with [[0_prc_0005_document_overview]] and filed according to [[document_file_naming_conventions]] (reference: 0-PRC-0003: File Structure).

**Document Conversion and Filing:**
*   If received documents are not already in Adobe Portable Document Format (PDF), the [[document_control_department]] must convert native digital format documents to PDF.
*   For documents received in printed paper format, Document Control must scan them to create digital copies.
*   Document Control must place all processed documents in the correct folder within the project electronic file, adhering to the guidelines in [[document_file_naming_conventions]] (reference: 0-PRC-0003: File Structure).
*   Documents received in printed paper format must also be physically filed by Document Control.
*   No other file copy of documents received electronically will be kept, as the digital copy in the project electronic file serves as the official record.

Upon the receipt of any documents from Owners, Vendors, or Subcontractors, a stringent logging and processing procedure must be followed to ensure proper record-keeping and distribution.

**Logging of Received Documents:**
All incoming documents must be logged into the [[document_control_database]]. The information to be logged includes:
*   Date Received
*   Reference (Purchase Order, Subcontract or Owner’s Contract) Number
*   Issuer’s Name
*   Issuer’s Document Title
*   Issuer’s Document Number
*   Issuer’s Document Revision Number
*   Issuer’s Document Status
*   Aker Kvaerner Chemetics Document Number
*   Document Return Date (where applicable)

**Special Considerations for Owner-Issued Documents:**
*   Logging of Owner-Issued documents will not include a Reference Number.
*   Logging of Owner-Issued documents will not include an Aker Kvaerner Chemetics Document Number.
*   If the Owner re-issues the same revision of a document, it will be logged with the new receipt date but retain the same revision number.

**Incoming Transmittals:**
An Incoming Transmittal, containing identical information as listed for received documents, will be sent to the Issuer.
*   Incoming Transmittals will be copied to the Project Engineer and all Discipline Leads.
*   They will be titled "Document Transmittal from [Parties Name] to Aker Kvaerner Chemetics -XXXX".
*   The "XXXX" in the title represents a sequential series beginning with 0001. A unique sequential series (XXXX) will be maintained for each party issuing documents to Aker Kvaerner Chemetics.
*   Incoming Transmittals must be published (reference: [[0-prc-0005_publishing_of_project_documents]]) and filed (reference: [[0-prc-0003_file_structure]]).

**Processing Received Documents:**
*   If received documents are not already in Adobe Portable Document Format, Document Control will convert native digital format documents or scan printed paper documents as necessary.
*   Document Control will place the processed documents in the correct folder within the project electronic file (reference: [[0-prc-0003_file_structure]]).
*   Documents received in printed paper format will be physically filed by Document Control.
*   No other file copy of documents received electronically will be kept.
