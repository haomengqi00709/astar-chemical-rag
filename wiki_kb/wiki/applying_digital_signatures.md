# Applying Digital Signatures to Documents

Once your digital signature profile is created and its appearance configured, you can apply your digital signature to project documents. This process ensures the authenticity and integrity of the document.

### Prerequisites
*   Your digital signature profile **must** be set up as described in [[digital_signature_profile_creation]].
*   Your standard signature appearance **must** be configured as detailed in [[digital_signature_appearance_configuration]].
*   The document to be signed **must** be open in Adobe Acrobat or Adobe Approver.

### Step-by-Step Application
1.  **Log In (if necessary)**: If you are not already logged in, choose `Tools > Self-Sign Security > Log In`. Select your profile or browse to its storage location at `Q:\Signatures\Aker Kvaerner Chemetics`.
2.  **Select Signature Tool**: Select the signature tool from the toolbar within Adobe Acrobat or Adobe Approver.
3.  **Draw Signature Box**: Use your mouse to drag a box on the document where your signature will be placed. This defines the area where your initials graphic will appear.
4.  **Acknowledge Information**: Acknowledge any information window that appears by pressing the "Sign" button or the "OK" button.
5.  **Confirm Password**: In the "Sign Document" dialog box, enter your password in the "Confirm Password" text box.
6.  **Choose Signature Appearance**: Click "Show Options" and choose the signature appearance titled "Kvaerner Standard Signature".
7.  **Configure Signature Details**:
    *   **Do not** select or place a Reason for signing.
    *   **Do not** select or place a Location for signing.
    *   **Do** insert your e-mail address in the appropriate field.
    *   These settings will be saved to your profile and will not need to be repeated each time you sign a document.
8.  **Save Signed Document**: Click the "Save" button. The now signed document will be saved in the same file location with the same name, overwriting the unsigned version.

### Multiple Signatures and Verification
*   A document may be signed any number of times by different individuals.
*   Signatures will appear in the Signatures palette in the order that the document was signed.
*   The user profile name (e.g., John Smith) is the name seen in the Signatures palette when a signature is added to a document.
*   For information on verifying digital signatures, refer to [[digital_document_publishing]].

This process is a key part of the [[digital_document_publishing]] workflow, ensuring proper authorization and record-keeping.

### Signature Application Details
*   Acknowledge any information window by pressing the `Sign` button, or the `OK` button.
*   When a signature is added to a document, the user profile name is the name seen in the Signatures palette.
