# Aluminium Bus Welding Documentation and Marking

The Aluminium Bus Welding Standard (9-SPC-0001) specifies requirements for documentation and marking of fabricated Aluminium Bus systems.

**Identification Marking**
No paint **shall** be applied to the finished items, except for identification purposes. The order number and/or other identification marks **shall** either be painted in lead-free paint on each item or tagged as specified in the purchase order.

**Documentation Package**
The supplier **shall** provide Aker Kvaerner Chemetics with a comprehensive documentation package covering all relevant tests and inspections performed on the system. This documentation package **shall** include certification as required by Section 6.3 of this standard (referring to material certification).

For general requirements regarding vendor documentation, refer to [[vendor_document_requirements]].

**Identification Marking**
The order number and/or other identification marks **shall** either be painted in lead-free paint on each item or tagged as specified.
