# DCS Control Function Field Checkout Required Documents

The successful execution of the [[8-PRC-0006_dcs_control_function_checkout|DCS Control Function Field Checkout]] is heavily reliant on the availability and accuracy of a comprehensive set of engineering and operational documents. These documents serve as the primary reference for verifying the configuration and operation of the Distributed Control System (DCS).

The following engineering documents are explicitly required for the checkout procedure:

*   **Process Graphic Displays:** A hard copy of the Process Graphic Displays for all process areas **is required**. These displays provide a visual representation of the process and its control elements, essential for verifying graphic links and object presentation.
*   **DCS Generated Database List:** A printed-out database list, generated directly from the DCS, **is required**. This list details all configured points and their properties, serving as a critical reference for I/O testing and configuration verification.
*   **Piping & Instrumentation Diagrams (P&IDs):** [[p_id_development_and_approval_1_prc_0003|P&IDs]] are required engineering documents. They illustrate the piping and process equipment together with the instrumentation and control devices, crucial for understanding process interconnections and control strategies.
*   **Loop Sheets:** Loop sheets are required engineering documents. These provide detailed information for individual control loops, including wiring, instrument ranges, and control logic.
*   **Logic Diagrams:** [[logic_diagrams|Logic diagrams]] are required engineering documents. They graphically represent the interlock and control logic, which is essential for verifying the programmed logic functions.
*   **Motor Schematics:** Motor schematics are required engineering documents. These diagrams detail the electrical control circuits for motors, necessary for verifying motor control logic and field device interactions.
*   **I/O List:** The [[control_system_io_list|I/O list]] is a required engineering document. It provides a comprehensive list of all input/output points, their types, and associated field devices, fundamental for I/O testing.
*   **Operating Manual:** The [[operating_manual_1_man_0001|Operating manual]] is a required engineering document. It contains instructions for operating the plant and its systems, including the DCS, and can provide context for control function verification.

Ensuring that all these documents are readily available, current, and accessible to the specialists and programmers performing the checkout is a mandatory step for the procedure's effectiveness and compliance.
