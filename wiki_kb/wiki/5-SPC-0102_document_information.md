# 5-SPC-0102 Document Information and History

This page provides information regarding the origin, usage, and historical changes of Standard 5-SPC-0102.

**Document Origin and Usage**
*   This document is a direct copy of the original specification ES44/I05, titled "General Requirements for Testing & Flushing of Process Plant Piping System".
*   This document will be used in accordance with 0-PRC-0001, titled "Approval and Use of Standards".

**Future Plans**
*   This document is planned to be replaced at some time in the future. The replacement document must comply fully with the requirements of 0-PRC-0004 style of Textual Documents.

**Revision History**
*   A name change was implemented in 2005. No new revision number was used for this name change, and changes due to the name change have not been marked.
