# Stream Data Calculation and Integration

The generation and integration of stream data are critical steps in the development of [[pfd_overview|Process Flow Diagrams (PFDs)]]. This process involves using various software and methods to calculate data and then merging it with the graphical representation.

**Stream Data Calculation:**
The Process department is responsible for calculating the stream data, utilizing a range of tools:
*   **In-house software programs:** These can be FORTRAN or EXCEL-based applications.
*   **Process simulation software:** Commercial software such as ASPEN is used for complex simulations.
*   **EXCEL spreadsheet programs:** Used for direct calculations and data management.
*   **Hand calculations:** Employed where appropriate for specific calculations.

**Data Conversion and Export:**
Calculated results of stream data can be obtained directly using EXCEL spreadsheet programs or through hand calculations. When using other software, results are converted to an EXCEL spreadsheet either by direct output from the program or by manual input.

The Process department exports data in specific file formats based on the technology:
*   **Chemical and Weak Acid Technology:** Data is exported in ".xls" file form.
*   **Acid Technology:** Data is exported as a ".prn" file.

If required, data can also be written directly into a blank PFD table.

**Integration with PFD Graphics:**
The Drawing Office plays a key role in integrating the calculated stream data with the [[pfd_sketch_and_graphics|PFD Graphic Drawings]] to produce a complete PFD. This integration involves:
*   Merging PFD Graphic Drawings with stream data.
*   Converting chemical and weak acid technology files through "SPANNER.pdf" into the AutoCAD drawing environment.
*   Exporting the Acid technology *.prn file into the AutoCAD drawing environment.

This comprehensive approach ensures that the PFD accurately reflects both the visual layout and the quantitative process data. For details on the content of the stream data, refer to [[stream_data_file]].
