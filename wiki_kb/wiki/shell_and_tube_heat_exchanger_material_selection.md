# Shell and Tube Heat Exchanger Material Selection

This page specifies the materials of construction for various components of the Shell and Tube Heat Exchanger (Chemetics Equipment Number 10-10H, "Water Heater"). The selection of these materials is critical for ensuring the equipment's durability, corrosion resistance, and structural integrity under the specified process and mechanical design conditions.

For details on fabrication and marking, refer to [[shell_and_tube_heat_exchanger_fabrication_and_marking]]. Information on painting and insulation can be found at [[shell_and_tube_heat_exchanger_painting_and_insulation]].

**Component Material Specifications:**

| Component                      | Material               |
|:-------------------------------|:-----------------------|
| Tubes                          | SA-249-TP304L          |
| Shell                          | SA-516-70              |
| Channel                        | SA-240-304L            |
| Channel Head                   | SA-240-304L            |
| Tubesheet                      | SA-240-304L            |
| Girth Flange                   | SA-516-70/SA-105       |
| Support                        | SA-36                  |
| Anchor Bolts                   | SA-307-B Hot Dip Galv. |
| Internals (shell side)         | Carbon steel           |
| Internals (tube side)          | SA-240-304L            |
| Nozzle Flange (shell side)     | SA-105 Hot Dip Galv.   |
| Nozzle Flange (tube side)      | SA-105/SA-182F-304L    |
| Nozzle Neck (shell side)       | SA-53-B ERW            |
| Nozzle Neck (tube side)        | SA-312-TP304L          |
| Lap Ring (tube side)           | SA-240-304L            |
| Coupling (shell side)          | SA-105                 |
| Coupling (tube side)           | SA-182F-304L           |
| Bolts                          | SA-307-B Hot Dip Galv. |
| Nuts                           | SA-563-Gr.A Hot Dip Galv. |
| Gasket                         | 1.5 mm Garlock 3504    |

These material choices are aligned with the design codes and Chemetics specifications to ensure optimal performance and longevity of the heat exchanger.
