# Control System Design Criteria (8-PRC-0017)

The **Control System Design Criteria** document (8-PRC-0017) is a critical reference used during the design phase of a project. It establishes the fundamental principles and requirements for the control system.

**Document ID:** 8-PRC-0017
**Usage:** Design

**Content Requirements:**
The Control System Design Criteria **MUST** contain the following information:
*   Basic operating philosophy, including the quantity of operator stations and engineering stations.
*   Applicable statutory requirements.
*   Reference to the appropriate Aker Kvaerner Chemetics standard.
*   Aker Kvaerner Chemetics general requirements for control system design.
*   Owner requirements specific to the project.
