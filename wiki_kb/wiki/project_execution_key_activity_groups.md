# Project Execution Key Activity Groups (PEM)

[[0-prc-2101_project_execution_model_gate_reviews_overview|Project Execution Model (PEM) Milestone Gate Reviews]] assess project performance against specific requirements within various Project Execution Key Activity Groups. These groups represent critical areas of project delivery.

**Key Activity Groups**
*   Concept Execution
*   HSE in Design
*   System Engineering
*   Procurement
*   Layout & 3D Model
*   Sub-contracting
*   Fabrication / Construction
*   Civil works and buildings
*   Completion
