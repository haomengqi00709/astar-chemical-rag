# Vendor Document Requirements Template (0-VDR-0XXX)

Document **0-VDR-0XXX: [Template] Vendor Document Requirements** serves as a standardized template for creating specific [[vendor_document_requirements_preparation|Vendor Document Requirements (VDRs)]]. This template is issued to Vendors to ensure consistency in the format and content of documentation requirements across different equipment types and bulk materials. Utilizing this template helps streamline the process of defining and communicating documentation expectations to Vendors.
