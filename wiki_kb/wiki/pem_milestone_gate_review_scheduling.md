# PEM Milestone Gate Review Scheduling and Integration

The scheduling of [[0-prc-2101_project_execution_model_gate_reviews_overview|Project Execution Model (PEM) Milestone Gate Reviews]] is a fundamental aspect of project planning, ensuring these critical checkpoints are integrated from the outset.

**Establishment and Publication**
*   Dates for PEM Milestone Gate Reviews **will** be established from the start for each individual project.
*   These dates **will** be published to all relevant stakeholders.

**Project Schedule Integration**
*   The PEM **will** be fully integrated into the overall [[project_schedule_and_milestones|project schedule]].
*   Integration is achieved by coding individual activities within the schedule to reflect the specific PEM Control Level Stage(s) in which they occur.
*   The project schedule **will** include a distinct milestone for each applicable PEM stage.
*   Milestone Gate Review dates **will** be published as part of the [[0-dat-3001_project_schedule|0-DAT-3001: Project Schedule]].

**Establishment and Publication**
*   Dates for PEM Milestone Gate Reviews will be established from the start for each individual project and will be published.

**Integration**
*   The PEM will be fully integrated into the project schedule.
*   Integration is achieved by coding individual activities to reflect the PEM Control Level Stage(s) in which they occur.
*   The schedule will include a milestone for each applicable PEM stage.
