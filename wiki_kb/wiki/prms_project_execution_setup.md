# PRMS Project Execution Setup

At the onset of a project, the master copy of the Project Resource Management System (PRMS) **must** be populated with project-specific data to prepare it for execution. This initial input involves manual data entry into cells highlighted in green.

**Required Information for Initial Input:**
To prepare the PRMS for project execution, the following information is required:
*   A basic procurement plan, including a list of expected Purchase Orders (PO’s).
*   An equipment list.
*   An instrument list.
*   An electrical equipment list.
*   A comprehensive documents list.
*   A simple project schedule.

**Step-by-Step Setup for Project Execution:**

1.  **"Totals" Worksheet (Project Execution):**
    *   Enter the current date.

2.  **Cost Code Worksheets (Project Execution):**
    *   Fill out each worksheet with the "work objects," which primarily consist of deliverables relevant to the project.

3.  **"Admin" Worksheet (Project Execution):**
    *   Open the "admin" worksheet.
    *   Distribute the administration budgeted hours between the various disciplines involved in the project.

4.  **"EMF" Worksheet (Project Execution - Manpower Forecasting):**
    *   Unprotect the sheet.
    *   Unhide column F.
    *   Input dates in weekly intervals at the top of the EMF (row 5).
    *   Distribute the budgeted hours over time. The sum of this distribution (column F) **must** equal the budgeted hours for the department (column E).
    *   The worksheet **must** be protected again after the distribution is complete to prevent unintended changes.

This comprehensive setup ensures that the PRMS is accurately configured with project-specific data, providing a robust foundation for ongoing resource management and forecasting throughout the project lifecycle.
