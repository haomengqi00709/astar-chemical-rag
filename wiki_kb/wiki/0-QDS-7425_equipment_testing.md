# Fan or Blower Equipment Testing

Equipment Testing is a mandatory item or activity for the Fan or Blower equipment specified under Quality Data Sheet **0-QDS-7425**.

The following tests are required:
*   **Balancing:** This **is required** as [[0-QDS-7425_quality_record_definitions|FP]] (Included in Quality Assurance Documentation Package). Chemetics **will Witness** the balancing procedure.
*   **Run Test:** This is an item or activity that **must** be performed.
*   **Performance Test:** This is an item or activity that **must** be performed.
*   **Noise Data:** This **is required** as [[0-QDS-7425_quality_record_definitions|FP]] (Included in Quality Assurance Documentation Package). Chemetics **will Witness** the collection of Noise Data.
*   **Motor Test:** This is an item or activity that **must** be performed.

These tests ensure the operational integrity, performance, and compliance with noise specifications for the Fan or Blower unit.
