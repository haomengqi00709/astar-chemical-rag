# Document Publishing Procedure Overview (0-PRC-0005)

This procedure, 0-PRC-0005, outlines the methods and requirements for publishing project documents within Aker Kvaerner Chemetics, and prior to their external issue. The primary objective of publishing is to create an unalterable record of a document, which can then be certified by authorized personnel through attached signatures.

The procedure details two permitted methods for document publishing: Digital Publishing and Paper Publishing. Digital publishing involves converting documents into Adobe Portable Document Format (PDF) and affixing digital signatures. Paper publishing entails printing documents, applying physical signatures in blue ink, and subsequently scanning these signed documents into PDF format.

Key related procedures that complement 0-PRC-0005 include:

*   [[control_of_project_documents_0_prc_0006]] (0-PRC-0006) for the overall control of project documentation and management of the project Document Control Database.
*   [[document_control_1_prc_0003]] (0-PRC-0003) for defining the structure of both the project electronic and paper files.
*   [[authorization_roles]] (0-PRC-2001) for the assignment of project responsibilities.
*   [[document_number_format_and_components]] (0-PRC-0002) for ensuring correct file naming conventions.

Upon completion of publication and any required checking and approval, the responsible Discipline Lead **must** advise Document Control. Document Control will then update the project Document Control Database accordingly.
