# Instrumentation and Control Document Structure (Major Work Subject 8)

The "8 Instrumentation and Control" major work subject is dedicated to all documentation concerning the design, specification, installation, and operation of the plant's instrumentation and control systems. This folder is critical for managing information related to process measurement, control, and automation.

The sub-folders and their contents within the 8-Instrumentation-and-Control folder are:

*   **CAL:** Control Valve Sizing. Calculations for the proper sizing of control valves.
*   **DST:** Instrument Data Sheets. Detailed technical data sheets for individual instruments. For more information, refer to [[instrument_data_sheets]].
*   **DTL:** Instrument Installation Details, JB Layouts. Detailed drawings for instrument installation and junction box layouts.
*   **GAD:** Instrument Location Drawings. Drawings showing the physical location of instruments within the plant.
*   **LOP:** Loop Drawings. Detailed wiring and functional diagrams for individual control loops.
*   **LST:** Instrument List, Cable Lists, Spare Parts Lists. Comprehensive lists of all instruments, control cables, and associated spare parts. Data available in SQL: LST files.
*   **PRC:** Project Specific Procedures. Procedures tailored to instrumentation and control system design, procurement, and installation.
*   **REQ:** Requisitions. Documents for requesting bids or proposals for instruments and control system components.
*   **SCM:** SAMA Diagrams, Logic Diagrams. Diagrams representing control logic and sequence of operations. For more information, see [[logic_diagrams]].
*   **SPC:** Specifications. Technical specifications for instruments, control systems, and installation standards. Data available in SQL: SPC files.
*   **TAB:** Bid Tabulations. Records of bids received for instruments and control system components.
*   **VDR:** Vendor Document Requirements. Documents outlining the requirements for vendor-supplied instrumentation and control documentation.
*   **VEN:** Vendors Documents. All documentation provided by instrument and control system vendors, such as manuals, drawings, and software details.

This structure ensures that all instrumentation and control documents, from design calculations to vendor submissions, are systematically organized and easily retrievable. For an overview of the entire project documentation structure, refer to [[document_control_1_prc_0003]]. The definitions of major work subjects are outlined in [[major_work_division_codes]].
