# Factory Acceptance Test (FAT)

The **Factory Acceptance Test (FAT)** is a crucial stage in the control system project lifecycle, performed to verify that the control system meets its specified requirements before shipment to the project site.

**Typical Document Number:** ----------
**Usage:** Design

**Purpose:**
The Factory Acceptance Test is conducted to ensure that the control system hardware and software components function correctly and meet the design and specification criteria outlined in documents such as the [[basic_control_system_specification]]. This testing phase helps identify and resolve issues early, reducing potential problems during site installation and commissioning.
