# 0-QDS-7431 Inspection and Documentation Requirements

This page details the specific inspection activities and documentation requirements for Acid Brick & Lining, as outlined in [[0-QDS-7431_acid_brick_lining_quality_data_sheet_administration]]. All listed items require Chemetics surveillance (Complete), as per [[0-QDS-7431_chemetics_surveillance_level]].

**Required Documents and Reports:**
*   **Chemical Analysis Report:** Required as FP ([[0-QDS-7431_quality_record_definitions]]). Chemetics surveillance is required (Complete).
*   **MSDS Sheets:** Required as FP ([[0-QDS-7431_quality_record_definitions]]). Chemetics surveillance is required (Complete).
*   **Certificate of Compliance:** Required as FP ([[0-QDS-7431_quality_record_definitions]]). Chemetics surveillance is required (Complete).
*   **Dimensional/Size Report:** Required as FP ([[0-QDS-7431_quality_record_definitions]]). Chemetics surveillance is required (Complete).
*   **Quantities Report:** Required as FP ([[0-QDS-7431_quality_record_definitions]]). Chemetics surveillance is required (Complete).
*   **Packing List:** Required as AP ([[0-QDS-7431_quality_record_definitions]]). Chemetics surveillance is required (Complete).

**Required Activities and Inspections:**
*   **Review QA Documentation:** Chemetics surveillance is required (Complete).
*   **Packaging/Tagging:** Chemetics surveillance is required (Complete).
*   **Material Verification:** This is a required item or activity.
*   **Final Inspection:** This is a required item or activity.
*   **Packing/Crating:** This is a required item or activity.

For general inspection and documentation requirements across various projects, refer to documents such as [[0-QDS-7404-1_inspection_and_documentation_requirements]].

The following documentation and activities are required, with their respective quality record definitions and Chemetics surveillance (Complete):

*   **Chemical Analysis Report:** Required as FP ("Included in Quality Assurance Documentation Package").
*   **MSDS Sheets:** Required as FP ("Included in Quality Assurance Documentation Package").
*   **Certificate of Compliance:** Required as FP ("Included in Quality Assurance Documentation Package").
*   **Dimensional/Size report:** Required as FP ("Included in Quality Assurance Documentation Package").
*   **Quantities report:** Required as FP ("Included in Quality Assurance Documentation Package").
*   **Review QA Documentation:** Requires Chemetics surveillance.
*   **Packaging/Tagging:** Requires Chemetics surveillance.
*   **Packing List:** Required as AP ("As Prepared").
