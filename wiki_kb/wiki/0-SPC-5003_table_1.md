# Purchase Order Price Adjustment Indexes (0-SPC-5003 Table 1)

This page describes the content of Table 1 within document **0-SPC-5003**.

[[0-SPC-5003_table_1]] is a mandatory table that **must** be included in the [[purchase_order_commercial_and_contractual_terms|Purchase Order]]. It specifies the relevant indexes for each category of Goods and Services, which are crucial for calculating [[0-SPC-5003_price_adjustment|price adjustments]]. This table provides the baseline data (Base Date Index 'B') and the latest available indexes ('P') required for the Price Adjustment Factor calculation, as detailed in the [[0-SPC-5003_price_adjustment]] section.
