# Formal Change Order

A Formal Change Order is a critical document issued during the [[project_change_implementation|Project Change Implementation]] phase of the [[0-PRC-4003-R1_project_change_management_flow_diagram|Project Change Management Flow Diagram]]. It serves as the official and legally binding authorization to modify the original project contract and scope.

Once a proposed change has undergone thorough [[project_change_evaluation|evaluation]] and received all necessary [[project_change_approval|approvals]] from stakeholders, including the Client Project Manager, the Formal Change Order is prepared and issued.

Key aspects of a Formal Change Order include:
*   **Legal Authority**: It provides the legal basis for altering the terms and conditions of the existing project contract.
*   **Scope Adjustment**: It explicitly defines the adjustments to the project scope, detailing what new work is to be performed, what existing work is to be modified or removed, and any changes to deliverables.
*   **Financial Impact**: It specifies the agreed-upon financial adjustments, including changes to the project budget, payment terms, and any associated costs or savings.
*   **Schedule Impact**: It outlines any revisions to the project schedule, including new milestones, revised completion dates, or changes to critical path activities.

The issuance of a Formal Change Order is a mandatory step to ensure that all parties are in agreement with the modifications and that the project proceeds with a clear, updated contractual basis. This document is a key component of the [[change_management_document_types]] suite and is meticulously tracked in the [[change_log]].
