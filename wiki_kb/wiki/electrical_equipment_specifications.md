# Electrical Equipment Specifications

Electrical Equipment Specifications provide detailed technical requirements for the construction, materials, and operation of electrical equipment. These specifications are crucial for ensuring that purchased equipment meets project standards and are generally generic rather than project-specific.

**General Content Requirements**
Equipment specifications **shall** contain:
*   Standard design requirements not typically included on the [[electrical_equipment_data_sheets]].
*   Interpretation of design codes, rules, and criteria.
*   A description of the equipment's construction, including enclosure materials and arrangement.

The description of the equipment in specifications **shall** be generic and not project-specific. Specifications **shall not** favor or insist on features supplied by only one or two vendors, to avoid excluding others. Equipment specifications may be the plant Owner’s specifications, modified as necessary.

Electrical equipment specifications are required for most electrical equipment purchased for the project.

**Specific Equipment Specification Requirements**

*   **Transformer/Rectifier Specifications:**
    *   Detailed description of the transformer and rectifier.
    *   Detailed description of the T/R control panel.
    *   Detailed description of the cooling system.
    *   Detailed description of the DC current measuring system.
    *   Detailed description of wiring.
    *   Detailed description of the rectifier enclosure.
    *   Detailed description of the control system, including alarms, trips, and interlocks.
*   **CPU Specifications:**
    *   Detailed description of the transformer and rectifier.
    *   Detailed description of the cooling system.
    *   Detailed description of the control system, including alarms, trips, and interlocks.
*   **Bus Bars Specifications:**
    *   Detailed description of components and their assembly.
*   **MV Switchgear Specifications:**
    *   Detailed description of the enclosure.
    *   Detailed description of bus work.
    *   Detailed description of the incoming circuit breaker.
    *   Detailed description of tie circuit breakers.
    *   Detailed description of feeder circuit breakers.
    *   Detailed description of load interrupter switches.
    *   Detailed description of protective relaying for all circuit breakers.
    *   Detailed description of accessories such as space heaters and cable entrance hardware.
*   **MCCs Specifications:**
    *   Detailed description of each component.
    *   Detailed description of bus bars.
    *   Detailed description of the incoming circuit breaker.
    *   Detailed description of motor starters.
    *   Detailed description of feeder circuit breakers.
    *   Detailed description of metering equipment.
    *   Detailed description of current transformers.
    *   Detailed description of metering transducers.
*   **Power Transformers Specifications:**
    *   Detailed description of the cooling method.
    *   Detailed description of windings.
    *   Detailed description of the primary terminal box.
    *   Detailed description of the secondary terminal box.
    *   Detailed description of meters.
    *   Detailed description of protective devices.
    *   Detailed description of the enclosure.
    *   Detailed description of the control box.
    *   Detailed description of accessories.
*   **LV Power Distribution Centre Specifications:**
    *   Detailed description of the enclosure.
    *   Detailed description of bus work.
    *   Detailed description of the incoming circuit breaker or disconnect switch.
    *   Detailed description of feeder circuit breakers.
    *   Detailed description of protective relaying.
*   **Motors Specifications:**
    *   Detailed description of the motor type (induction, wound rotor, or synchronous).
    *   Detailed description of construction materials.
    *   List of accessories according to motor size.
    *   List of accessories according to mechanical life expectancy of specific components.
*   **Emergency Generator Specifications:**
    *   Detailed description of the engine.
    *   Detailed description of the generator.
    *   Detailed description of the cooling system.
    *   Detailed description of the fuel system.
    *   Detailed description of the exhaust system.
    *   Detailed description of the automatic starting system.
    *   Detailed description of the generator control panel.
    *   Detailed description of the circuit breaker.
    *   Detailed description of nameplates.
*   **Emergency Transfer Switch Specifications:**
    *   Detailed description of the operation.
    *   Detailed description of the components.
*   **UPS Specifications:**
    *   Detailed description of various major components.
    *   Detailed description of the physical arrangement.
    *   Detailed description of the operation of components under normal and emergency conditions.
*   **Harmonic Filter Equipment Specifications:**
    *   Description of components.
    *   Description of arrangement.
    *   Description of the purpose of the equipment.

**Document Numbering and Usage**
Specifications **shall** be numbered according to 9-LST-0001, List Electrical Document Numbering Standard. The number for each piece of electrical equipment will be found in 9-PRC-0001, Procedure Electrical Equipment Identification.
