# Roles and Documentation Management

Effective documentation and clear assignment of responsibilities are crucial for the Chloralkali Plant project. The plant design **will** follow Aker Kvaerner Chemetics' standard design procedures, which are described in documents stored on the company's quality drive Q and specific project directory.

**Key Responsibilities:**

*   **Aker Kvaerner Chemetics Retained Subcontractor:**
    *   Preparation of the [[instrument_index_and_tagging|Instrument Index]].
    *   Preparation of the DCS I/O List.
    *   Preparation of [[instrument_calibration_and_testing|Instrument Specification Sheets]].
    *   Management of instrumentation procurement documentation.
    *   Compilation of instrumentation manuals.

*   **Aker Kvaerner Chemetics Process Department:**
    *   Responsibility for the creation and control of all Process Data Lists.

*   **Aker Kvaerner Chemetics Detail Engineering Subcontractor:**
    *   Preparation of all applicable documents related to the installation, wiring, and control logic of field devices, including field control panels for the process.
    *   **Documents prepared include:**
        *   Installation Details
        *   Instrument Locations
        *   Marshalling Panels
        *   Analog and Discrete Junction Boxes
        *   Instrument Cable Trays
        *   Cable Schedule
        *   Loop Diagrams
        *   Control Logic
        *   DCS Configuration (associated with the Chloralkali plant process only)

**As-Built Documentation:**
Documents required for future operations, maintenance, and project expansion **shall** be revised to "as-built" status. This mandatory requirement applies to:
*   Instrument Loop Diagrams
*   Instrument Specification Sheets
*   Instrument Index
*   Instrument I/O List

**Supplier Documentation Requirements:**
All necessary documentation from suppliers, including full maintenance documents, **will** be provided in correct, clear, and concise English. There **will** be no exceptions to the standard and type of documentation supplied.

Supplier documentation **is to include**:
*   Item catalogues
*   Technical servicing documentation
*   Full and correct circuit diagrams

**Electronic Documentation:**
Documentation **will** be provided in an acceptable form for quality reproduction. One copy of all documentation **will** be provided in an approved electronic format. Where vendor documentation cannot be directly obtained in an approved electronic format, it **will** be scanned and provided in PDF format.

For further details on specific document types, refer to [[instrument_documentation_general|Instrument Documentation - General]].
