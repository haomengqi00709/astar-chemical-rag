# Piping Specialty Item Identification Codes (Table 1)

This page describes the content of Table 1, which is referenced in procedure 5-PRC-0006. This table provides a comprehensive listing of standard identification codes for both Type A and Type B piping specialty items, along with their corresponding designations.

The table serves as a critical reference for engineers and project personnel to ensure consistent and accurate identification of various components throughout project documentation, including [[line_list|line lists]] and [[equipment_data_sheets_4_dst_xxxx|equipment data sheets]].

**Table Content Overview:**

*   **Device Type A Codes:** Lists the single-letter or abbreviated codes used for Type A items, such as 'RO' for Restriction Orifice, 'PSI' for Piping Specialty Item, and 'SP' for Spectacle.
*   **Device Type B Codes:** Details the two-letter abbreviated codes for Type B items, including 'EJ' for Expansion Joint, 'FH' for Flexible Hose, 'ST' for Strainer or Filter, and 'SP' for both Spacer and Spectacle Flange.

**Type A Device Type Codes**
The following codes are used for Type A Piping Specialty Items:
*   **RO**: Restriction orifice
*   **PSI**: Piping specialty item
*   **SP**: Spectacle

**Type B Device Type Codes**
The following codes are used for Type B Piping Specialty Items:
*   **AV**: Air vent
*   **BF**: Back flow preventer
*   **EJ**: Expansion joint
*   **FH**: Flexible hose
*   **GD**: Grounding device
*   **HC**: Hose connection
*   **HS**: Hose station
*   **SG**: Sight glass
*   **SN**: Spray nozzle
*   **SP**: Spacer
*   **SP**: Spectacle flange
*   **ST**: Strainer or filter
*   **T**: Steam Trap
*   **TS**: Temporary strainer

*Note: The Device Type B code 'SP' designates both 'Spacer' and 'Spectacle flange'.*
