# Progressive Cavity Pump General Data

This page outlines the general data fields specified in the Progressive Cavity Pump Datasheet (Template `4-DST-XXXX-R0`). These fields provide essential identification and quantity information for the pump.

**General Equipment Data:**
*   **Tag No.:** A unique identifier for the specific pump.
*   **Location:** The designated physical location of the pump within the plant or facility.
*   **Pump Type:** Specifies the type of pump, which is a Progressive Cavity Pump.
*   **Joint Type:** Details the type of joint used in the pump's construction.

**Quantity Information:**
The datasheet includes fields to specify the number of pumps required:
*   **Quantity:** The total number of pumps specified.
*   **Operating quantity:** The number of pumps intended for active operation.
*   **Installed Spare quantity:** The number of spare pumps installed and ready for use.

For broader context on equipment data sheets, refer to [[equipment_data_sheets_4_dst_xxxx]].

*   **Quantity:** The total number of pumps required.
*   **Operating Quantity:** The number of pumps required for normal operation.
*   **Installed Spare Quantity:** The number of spare pumps installed.
*   **Pump Type:** The specific type of pump (e.g., Progressive Cavity).
*   **Joint Type:** The type of joint used in the pump construction.
*   **Location:** The physical location where the pump will be installed.
