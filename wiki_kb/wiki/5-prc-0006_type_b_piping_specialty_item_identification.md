# Type B Piping Specialty Item Identification

The identification system for Type B Piping Specialty Items utilizes a format that incorporates nominal diameter, device type, and a unique serial number to ensure precise identification of components.

**Number Format**
The standard identification number for a Type B Piping Specialty Item is structured as **X-EJ-9xxx**. This format is composed of four distinct parts:

*   **Nominal Diameter (X):** Represents the nominal diameter of the item in either inches or millimeters.
*   **Device Type (EJ):** A two-letter abbreviation indicating the specific type of device.
*   **Type B Code (9):** A single digit code, '9', specifically designates the item as a Type B piping specialty item.
*   **Serial Number (xxx):** A unique three-digit number assigned sequentially.

**Device Type B Codes**
The following codes are used to designate specific device types for Type B piping specialty items:

*   **EJ:** Expansion joint
*   **FH:** Flexible hose
*   **HC:** Hose connection
*   **HS:** Hose station
*   **SG:** Sight glass
*   **SN:** Spray nozzle
*   **SP:** Spacer
*   **ST:** Strainer or filter
*   **TS:** Temporary strainer
*   **SP:** Spectacle flange
*   **AV:** Air vent
*   **GD:** Grounding device
*   **BF:** Back flow preventer
*   **T:** Steam Trap

**Note on 'SP' Code:** It is important to note that the 'SP' device type B code is used to designate both 'Spacer' and 'Spectacle flange'. Contextual information or additional project-specific guidelines may be required to differentiate between these two items when only the code is present.

**Serial Number Assignment**
A unique three-digit number **must** be assigned as the serial number for each Type B piping specialty item. This ensures that every item has a distinct identifier.

For a comprehensive list of codes, refer to [[5-prc-0006_table_1_piping_specialty_item_codes]].
This identification system is part of the broader [[5-prc-0006_piping_specialty_item_identification_procedure_overview]].

**Number Format Breakdown**
The components of the Type B identification number are defined as follows:
*   **X**: Designates the Nominal Diameter in inches or millimeters.
*   **EJ**: Designates the Device Type.
*   **9**: A fixed code designating a Type B piping specialty item.
*   **xxx**: A three-digit serial number. A unique three-digit number is assigned for each Type B piping specialty item.
