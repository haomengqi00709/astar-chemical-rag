# Project Overview and Document Context

This document, **Standard-8-PRC-0002-R0**, titled "Instrument and Control Design Criteria," outlines the general requirements for instrumentation and control systems for the new Chloralkali Plant. It serves as a summary of instrumentation design requirements specifically for instrumentation designers.

The project is undertaken for **Aker Kvaerner Chemetics** at the **Rio Tercero, Cordoba, Argentina** location, specifically for the Chloralkali Plant situated at Atanor’s manufacturing site.
