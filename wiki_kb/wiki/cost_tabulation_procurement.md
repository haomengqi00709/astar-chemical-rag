# Cost Tabulation for Procurement

This page describes the process for preparing preliminary and final cost tabulations, as well as commercial bid tabulations, which are integral to the procurement process.

**Preliminary Cost Tabulation**
The preliminary cost tabulation has three levels of order value:
*   Order value < CAD 10 K.
*   Order value < CAD 200 K.
*   Order value > CAD 200 K.

The template "Cost Tabulation", 0-TAB-5XXX-1, **must** be used to generate the preliminary cost tabulation. For preliminary cost tabulation, order value less than CAD 200 K involves PE, and order value greater than CAD 200 K involves PE.

**Final Cost Tabulation**
The final cost tabulation **will** be prepared in accordance with Table 2. It **will** be derived from the preliminary cost tabulation, using the template "Cost Tabulation", 0-TAB-5XXX-1. For final cost tabulation, PM is involved.

**Commercial Bid Tabulation**
The commercial bid tabulation **will** be prepared in accordance with Table 2. The form "Commercial Bid Tabulation", 0-TAB-5XXX-3, **must** be completed. For commercial bid tabulation, PR and MPR are involved.
