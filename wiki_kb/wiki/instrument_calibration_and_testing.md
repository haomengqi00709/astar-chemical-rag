# Instrument Calibration and Testing

Ensuring the accuracy and operational readiness of all instrumentation is paramount. All instruments **shall** be supplied factory calibrated, set-up, and configured with all necessary parameters to be ready for immediate operation upon installation.

**Configuration Requirements:**
*   The tag number **shall** be included in the configured parameters of instruments.
*   The service description **shall** be included in the configured parameters of instruments.

**Calibration Certificates:**
Wherever possible, each instrument **will** be supplied with its own calibration certificate. This certificate **shall** include comprehensive details to ensure traceability and verification of performance.

**Mandatory Information on Calibration Certificates:**
*   Serial number of the instrument
*   Tag number
*   Purchase order data
*   Equipment name
*   Calibration details
*   Description of tests performed
*   Date of calibration test
*   Place of calibration
*   Signature of the person conducting the tests

Wherever possible, calibration certificates **will** be provided in the English language.

For details on the types of documentation, including the Instrument Test Specification, refer to [[instrument_documentation_general|Instrument Documentation - General]].
