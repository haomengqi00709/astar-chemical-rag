# Quality Assurance Documentation for UNS S30815 Fabrications

This page outlines the mandatory requirements for Quality Assurance (QA) documentation and records for UNS S30815 welded fabrications. Comprehensive and accurate documentation is crucial for demonstrating compliance with specifications and codes.

**Required Documentation and Reports**
*   The Fabricator **WILL** furnish a report containing all data pertaining to each vessel or item.
*   Prior to Chemetics' final inspection of each unit, the fabricator **WILL** have prepared three sets of Quality Assurance records in finished form (except for final test data).
*   The documentation package **MUST** include:
    *   Material mill test reports.
    *   Weld filler metal reports.
    *   Nameplate rubbing (if applicable).
    *   A copy of all inspection and test reports.
    *   A [[weld_map]] showing the location of major defects.
    *   A [[weld_map]] showing welder identification.
*   The inspector **WILL** be provided with the appropriate number of fully completed Q.A. documentation packages for each unit at the time of witnessing final tests.
