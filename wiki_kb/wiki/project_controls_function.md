# Project Controls Function

The Project Controls function is responsible for monitoring, analyzing, and reporting on various aspects of a project's performance, including schedule, cost, and change management. This function plays a critical role in providing data and insights for the [[0-rep-2001_monthly_progress_report_format|Monthly Progress Report]], specifically contributing to sections on engineering progress, schedule variance, cost reporting, man-hour tracking, and change control summaries.
