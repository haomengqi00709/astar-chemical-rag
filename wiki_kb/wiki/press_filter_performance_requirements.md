# Press Filter Performance Requirements

This page specifies the mandatory performance requirements for the Press Filter, as referenced in Document ID [[4-DST-XXXX-R0_template_plate_filter_datasheet_administration]]. These criteria define the expected operational output and efficiency of the equipment.

**Mandatory Performance Requirements**
The following performance metrics are **required** for the Press Filter:
*   **Discharge Solid Loading**: (units % w/w) - This specifies the desired solid content in the discharged material.
*   **Separation Efficiency for Particle Size Above**: (units microns, % Efficiency) - This defines the efficiency of separating particles larger than a specified micron size.
*   **Separation Efficiency for Particle Size Between**: (units microns, % Efficiency) - This defines the efficiency of separating particles within a specified range of micron sizes.
*   **Separation Efficiency for Particle Size Below**: (units microns, % Efficiency) - This defines the efficiency of separating particles smaller than a specified micron size.

These performance requirements are critical for ensuring the Press Filter meets its operational objectives within the overall process. For the input conditions that lead to these performance outputs, refer to [[plate_filter_operating_details]]. General equipment specifications can be found in [[plate_filter_general_equipment_fields]].
