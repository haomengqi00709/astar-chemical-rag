# HazOp Study Record Publishing

Upon the conclusion of each Hazard and Operability (HazOp) Study session, the record of that session **must** undergo a formal publishing, checking, and approval process.

**Publishing Process:**
*   The record of each HazOp Study session **shall** be published, checked, and approved.
*   The publishing of project documentation is governed by [[control_of_project_documents_0_prc_0006]].
*   The HazOp Study Leader **shall** check the record.
*   The Technology Manager **shall** approve the record.

**Record Structure:**
*   The HazOp record will exist as a number of discrete files.
*   These files will be numbered as sheets or sections of [[1-haz-0001_hazop_record_overview|1-HAZ-0001: HazOp Record]].

*   Publishing of Project Documentation is governed by [[0-prc-0006_project_documentation_publishing|0-PRC-0006]].

**HazOp Record Structure:**
*   The HazOp record will exist as a number of discrete files.
*   Files will be numbered as sheets / sections of 1-HAZ-0001: HazOp Record.
