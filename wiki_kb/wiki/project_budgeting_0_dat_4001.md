# Project Budgeting (0-DAT-4001)

Project Accounting is responsible for establishing the financial framework for the project, including cost code setup and budget preparation.

**Cost Code Setup:**
Immediately upon the initiation of the project (as described in Section 2 of 0-PRC-3001), Project Accounting **must** open all necessary engineering cost codes.

**Project Budget Preparation:**
Project Accounting **must** prepare the Project Budget in accordance with 0-PRC-4002: Project Budget and Cost Forecasting. They **must** create [[project_budget_0_dat_4001|0-DAT-4001: Project Budget]].
*   The prepared budget **must** be checked by the Project Manager.
*   The prepared budget **must** be approved by the Director of Projects.
