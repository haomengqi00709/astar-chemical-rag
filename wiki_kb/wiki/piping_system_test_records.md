# Piping System Test Records

Accurate and comprehensive record-keeping is a mandatory requirement for all piping system tests.

*   Records **will** be made for each piping system tested.
*   These records **must** be in accordance with [[ASME_b31_3_chemical_plant_and_petroleum_refinery_piping]] paragraph 346.
*   Additionally, records for piping systems **must** comply with [[ASME_b31_3_chemical_plant_and_petroleum_refinery_piping]] paragraph 345.2.7.
