# Document Numbering Procedure (0-PRC-0002)

The Document Numbering Procedure, identified as 0-PRC-0002, outlines the mandatory requirements for assigning numbers to all project and standard documents within the firm. This procedure ensures a consistent and traceable system for document identification.

**Scope and Application**
This procedure describes the requirements for the numbering of documents. The term "document" is generic and refers to drawings, specifications, procedures, lists, data sheets, and other similar records.

Where project documents are required to contain the Owner’s document numbers, these Owner numbers shall be used in conjunction with the numbering scheme described by this procedure.

**Exclusions**
Certain types of documents are not covered by this procedure and have their own specific numbering guidelines:
*   Correspondence, minutes of meetings, memoranda, and project reports are numbered in accordance with [[project_instructions_0_prc_2002]] and/or [[project_coordination_0_prc_2004]].
*   Purchase Orders are numbered in accordance with [[form_of_purchase_order_0_prc_5001]].
*   Owner-issued documents shall retain the Owner’s original document number and revision number.

**General Document Number Format**
The standard document number format is structured to provide comprehensive identification, exemplified as `98C12300-4-DTL-7801-5-R2`. This format is broken down into several distinct components, each providing specific information about the document. For a detailed breakdown of each component, refer to [[document_number_format_and_components]].

This procedure also allows for a single document number to be assigned to a set of drawings, such as those required for the fabrication of a vessel. For more details, see [[single_document_number_for_drawing_sets]].

Data related to document numbering, including specific codes and their descriptions, is available in [[0_prc_0002_table_1]].
