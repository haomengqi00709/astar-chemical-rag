# Post-Publication Workflow

Upon completion of document publication and any required checking and approval, the following steps integrate the published document into the broader document control system:

*   The responsible Discipline Lead will advise Document Control.
*   Document Control will then update the project Document Control Database. The project Document Control Database is further detailed in [[0_prc_0005_related_procedures_and_documents#0-PRC-0006_Control_of_Project_Documentation|0-PRC-0006]].
