# Construction Subcontract Price for Work Done to Date

The Construction Subcontract Price for Work Done to Date refers to the amount claimed by the Subcontractor for completed work, typically submitted as a monthly application for payment.

The Subcontractor **shall** submit the updated project schedule to [[aker_kvaerner_chemetics_obligations_0_spc_2201|Aker Kvaerner Chemetics]] at the same time as submitting this monthly application for payment, as outlined in [[construction_subcontract_schedule_management_and_reporting]]. This ensures that payment applications are accompanied by current progress documentation.
