# Line List Data Fields and Responsibilities Table (5-PRC-0004 Table 1)

This page describes the content of Table 1 from document 5-PRC-0004, which details the data fields, responsible disciplines for preparation, checking, and approval across the various stages of the Line List development.

The table provides a structured overview of:
*   **Line List Stage**: Indicates the development stage (e.g., Stage 1, Stage 2, Stage 3, Stage 4).
*   **Data Field**: The specific information required for the Line List at that stage.
*   **Prepared By**: The discipline responsible for inputting the data.
*   **Checked By**: The discipline responsible for verifying the data.
*   **Approved By**: The discipline responsible for final approval of the data.

This table is crucial for understanding the workflow and accountability in the [[line_list_development_stages_and_responsibilities|Line List development process]].

The table details the specific data fields, their source or responsible discipline, and the preparation, checking, and approval responsibilities for each stage:

*   **Stage 1 Line List:**
    *   **Data Fields:** P&ID reference, Line origin and destination, Fluid code, Line identifier, Preliminary material code, Estimated line size, Type of insulation and heat tracing.
    *   **Data Source:** All Stage 1 data fields are provided by Design from the Stage 2 P&ID.
    *   **Preparation:** Design
    *   **Checking:** Process
    *   **Approval:** Design

*   **Stage 2 Line List:**
    *   **Additional Data Fields:** Design flow rate, Fluid density, Velocity criteria, Estimated operating pressure - Maximum, Estimated operating pressure - Minimum, Operating temperature – Maximum, Operating temperature – Minimum.
    *   **Data Source:** All Stage 2 additional data fields are provided by Process.
    *   **Preparation:** Process
    *   **Checking:** Technology
    *   **Approval:** Process

*   **Stage 3 Line List:**
    *   **Additional Data Fields:** Line size, Final gasket material selection, Design pressure - Maximum, Design pressure – Minimum, Design temperature – Maximum, Design temperature – Minimum, B31.3 fluid code, Pressure relief device, Pressure relief setting, Insulation thickness.
    *   **Data Source:** All Stage 3 additional data fields are provided by Mechanical.
    *   **Preparation:** Mechanical
    *   **Checking:** Process
    *   **Approval:** Mechanical

*   **Stage 4 Line List:**
    *   **Additional Data Fields:** Test pressure, Test method, NDT requirements, Paint.
    *   **Data Source:** All Stage 4 additional data fields are provided by Mechanical.
    *   **Preparation:** Mechanical
    *   **Checking:** Project Engineer
    *   **Approval:** Mechanical
