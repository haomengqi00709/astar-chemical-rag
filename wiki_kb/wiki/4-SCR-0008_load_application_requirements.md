# Skirt Supported Vessel on Steel: Load Application Requirements (4-SCR-0008)

Document **4-SCR-0008** specifies a critical requirement for the application of loads to the skirt-supported vessel on steel.

**Mandatory Requirement:**
*   Loads **must** be applied at Datum.

This requirement ensures consistency in structural analysis and design calculations by establishing a standardized reference point for all applied forces and moments. Adherence to this directive is essential for accurate modeling of the vessel's behavior under various loading conditions.

For a comprehensive understanding of equipment support and load application principles, refer to [[equipment_support_criteria]].
