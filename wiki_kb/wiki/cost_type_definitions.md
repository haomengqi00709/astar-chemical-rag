# Cost Type Definitions

The Cost Type is a three-letter code that forms the second component of the [[cost_code_structure]], providing a high-level classification of expenditures. Each code represents a distinct category of work or resource. The defined Cost Types are:

*   **ENG (Engineering):** This code is used for all engineering-related activities. When applying engineering cost codes, work **shall** be coded by activity, rather than by the position or department of the individual performing the work. This ensures a consistent and activity-centric view of engineering costs.
*   **MAT (Materials):** This code is designated for all costs associated with the procurement and supply of materials required for a project.
*   **CST (Construction):** This code covers all expenses related to construction activities on a project site.
*   **FLD (Field Services):** This code is applied to costs incurred for services provided in the field, which may include site supervision, technical support, or specialized field operations.
*   **RES (Reserves):** This code is used for financial reserves allocated for unforeseen circumstances or contingencies within a project.

For a detailed breakdown of specific activities or items within each Cost Type, refer to the [[detail_code_listings_and_usage]].

*   **FLD (Field Services):** This code is used for costs associated with field services.
*   **RES (Reserves):** This code is used for costs related to reserves.
