# Inspection and Documentation Requirements for ESP Lead Lined Components

This section details the specific inspection and documentation requirements for Electrostatic Precipitator Lead Lined Components, including the required Quality Records and Chemetics' surveillance levels. Compliance with these requirements is mandatory for the Vendor.

**Inspection and Documentation Items:**

1.  **Material Verification:**
    *   **Requirement:** Material Verification is required in the Vendor I & T Plan.

2.  **Material Test Certificates:**
    *   **Quality Record:** [[0-QDS-7404-2_quality_record_definitions|FP]] (Included in Quality Assurance Documentation Package)
    *   **Chemetics Surveillance:** Complete

3.  **Coating/Lining Inspection:**
    *   This is a required inspection item.

4.  **Dye Penetrant Inspection:**
    *   **Application:** Applies to Lead lining.
    *   **Requirement:** Required in Vendor I & T Plan at level 1.0.
    *   **Quality Record:** [[0-QDS-7404-2_quality_record_definitions|FP]] (Included in Quality Assurance Documentation Package)
    *   **Chemetics Surveillance:** Complete

5.  **Halogen Leak Test:**
    *   **Quality Record:** [[0-QDS-7404-2_quality_record_definitions|FP]] (Included in Quality Assurance Documentation Package)
    *   **Chemetics Surveillance:** Complete

6.  **Final Inspection:**
    *   This is a required inspection item.

7.  **Dimensional Inspection:**
    *   **Quality Record:** [[0-QDS-7404-2_quality_record_definitions|FP]] (Included in Quality Assurance Documentation Package)
    *   **Chemetics Surveillance:** Complete

8.  **Surfaces Free From Defects:**
    *   **Chemetics Surveillance:** Complete

9.  **Cleanliness:**
    *   **Chemetics Surveillance:** Complete

10. **Review QA Documentation:**
    *   **Chemetics Surveillance:** Complete

11. **Packaging/Crating (Item 18.0):**
    *   This is a required item.
    *   **Chemetics Surveillance:** Complete

12. **Packing List:**
    *   **Quality Record:** [[0-QDS-7404-2_quality_record_definitions|AP]] (As Prepared)
    *   **Chemetics Surveillance:** Complete

All Chemetics surveillance activities **must** be conducted according to the specified [[0-QDS-7404-2_chemetics_surveillance_level|surveillance level]] and as detailed for each item.
