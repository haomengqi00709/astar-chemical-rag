# Mack Iron Strainer Data Table Summary

This page provides a summary of the "Mack Iron Strainer Data" table, which is a critical reference for the design and selection of Saramet strainers. The data within this table is sourced directly from the Mack Iron Catalogue and is referenced in the [[1-CAL-7842-R1_final_strainer_calculation_document_details]].

**Purpose and Content:**
The table provides comprehensive dimensional, area, and flow-related data for Saramet strainers across a range of nominal line sizes. This information is used by engineers to:
*   Determine appropriate strainer dimensions for specific applications.
*   Calculate filter areas and flow characteristics.
*   Evaluate performance ratios.

**Key Data Points Included:**
For each nominal line size, the table details:
*   **Casing Dimensions:** Internal and external diameters (ID, OD), and various specific dimensions (A, B, C, D, H, Q, R, O, P).
*   **Filter Characteristics:** Base filter area, lateral filter area, total filter area, and length-to-breadth (L/B) ratio.
*   **Flow and Area Ratios:** Pipe area, various calculated ratios, flow factors, and annular areas.

**Nominal Line Sizes Covered:**
The table includes data for nominal line sizes ranging from 2.0 inches (50.8 mm) up to 38.0 inches (965.1999999999999 mm), and potentially larger sizes up to 1000.0 mm as indicated by available nominal strainer sizes. A specific "Limit for Chemetics Pipe standard limit" is noted at 26.0 inches (660.4 mm).

**Data Availability:**
Due to the extensive nature of the data, the full table content is not reproduced here. The complete detailed data for each nominal line size, including all specific dimensions, areas, and ratios, is available in the source document, 1-Cal-7842-R1.

For a detailed breakdown of the column headers, refer to [[mack_iron_strainer_data_table_headers]]. The corresponding units for each data point are provided in [[mack_iron_strainer_data_table_units]].
