# Project Schedule Updates and Reporting

The Project Schedule **will** be updated at regular intervals to reflect current progress and any changes in project execution. The specific regular update intervals are set out in [[project_instructions_0_prc_2002]].

Updating the schedule requires several key inputs:
*   Additions or deletions of activities and dependencies to accurately reflect revised execution plans.
*   Actual activity start and completion dates.
*   Revised resource hours, based on the latest count of work quantities.

Percentage completion for various project components is derived from specific sources:
*   **Engineering activity % completion:** Derived from the Project Resource Management System.
*   **Procurement activity % completion:** Derived from Vendor schedules or expediting reports.
*   **Construction activity % completion:** Derived from Subcontractor schedules.
*   **Commissioning activity % completion:** Derived from the field checklists.

Immediately following each schedule update, standard schedule management reports are prepared. These reports are intended for inclusion into the Project Manager's reports and **will** be prepared in accordance with [[project_instructions_0_prc_2002]]. The [[project_schedule_detail_levels#level-2-schedule-control-schedule|Level 2 Schedule]] is the designated format for reporting to both the Owner and Aker Kvaerner Chemetics senior management.
