# Vendor Document Supply (0-SPC-0001)

Data available in SQL: 0-SPC-0001

The document 0-SPC-0001 R1, titled "Vendor Document Supply," establishes the general procedures and standards for the submission of documentation by all vendors to Aker Kvaerner Chemetics. This specification complements project-specific Vendor Document Requirements (VDRs) by providing overarching guidelines for document quality, format, and transmittal processes.

Key aspects covered in this general specification include:
*   **Document Control Procedures:** How vendor documents should be numbered, revised, and transmitted, ensuring compliance with Aker Kvaerner Chemetics' document control system.
*   **Electronic Submission Standards:** Requirements for file formats (e.g., PDF, native CAD files), naming conventions, and metadata for electronic document submissions.
*   **Hard Copy Requirements:** Specifications for paper size, binding, and stamping for any required hard copies.
*   **Transmittal Forms:** Use of standardized transmittal forms to accompany document submissions, ensuring proper tracking and receipt.
*   **Language:** The required language for all vendor documentation.
*   **Quality of Documents:** Expectations for the clarity, accuracy, and completeness of all submitted documents.

Vendors **must** supply documentation in accordance with the requirements set out in this specification, in addition to any project-specific VDRs like [[vendor_document_requirements_4_vdr_4005]]. This document is a key reference in Text Section 2: Documentation of Purchase Orders, ensuring a consistent and manageable flow of vendor information.

For an overview of how documentation requirements are integrated into procurement, refer to [[request_for_quotation_and_purchase_order_structure_and_content]].
